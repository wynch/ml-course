Build ML From Scratch — Then the Hugging Face Way

Learn to build machine-learning models, not just call them — from a scalar autograd engine all the way to fine-tuning and serving an LLM.

The trick of this course: you build everything twice. First from scratch, so you understand every moving part; then the Hugging Face way, so you can move fast and ship real work. You see every concept as a picture — loss surfaces, attention heatmaps, feature maps, denoising trajectories — because intuition comes from images, not equations alone. And you write the core algorithms in two languages: Python for reach and ecosystem, and Zig for understanding, where nothing is hidden and memory is explicit.

New: an optional prologue, Track 0 · Origins — the classic math behind modern ML, after Anil Ananthaswamy's Why Machines Learn. A perceptron with a proof, Bayes, k-NN, PCA, kernels, Hopfield memories and double descent, all at numpy level. Take it before the main line or alongside it.

Everything here runs client-side. The explorables and quizzes are single HTML files with no network calls and no backend: models, animations and grading all run locally in your browser, and quiz scores stay in this browser's localStorage. Nothing you do on this site is uploaded anywhere.

Prefer to run it locally? Clone the repo, serve the root with python3 -m http.server, and open http://localhost:8000/.
