# mlcourse-00c-kernels-hopfield (Python lane)

The from-scratch code for Module 00c. See the module [README](../README.md) for
the walkthrough.

Layout:

- `src/kernelmem/svm.py` — kernels, the exact projection onto {α ≥ 0, αᵀy = 0},
  and `DualSVM`, the dual solved by projected gradient ascent
- `src/kernelmem/lift.py` — the explicit quadratic feature map φ(x) = (x₁², √2x₁x₂, x₂²)
- `src/kernelmem/hopfield.py` — Hebbian storage, asynchronous recall, energy,
  the capacity sweep, and the modern softmax update
- `src/kernelmem/polyreg.py` — Legendre features, minimum-norm fits, the sweeps
- `scripts/` — figure-producing scripts, run with `uv run scripts/<name>.py`
- `tests/` — 21 tests including a cross-check of the SVM against `sklearn.svm.SVC`
- `explorable_data.json` — regenerated by `scripts/export_explorable.py`; the
  numbers the explorable inlines, so the browser and Python agree

Quick start:

```bash
uv run scripts/svm_margin.py
uv run scripts/kernel_lift.py
uv run scripts/hopfield_demo.py
uv run scripts/hopfield_capacity.py      # ~45 s
uv run scripts/attention_bridge.py
uv run scripts/double_descent.py
uv run pytest
```

`scikit-learn` is a dev dependency only — it appears in one test as an
independent check that the hand-written dual solver finds the same hyperplane.
Nothing in `src/` imports it.
