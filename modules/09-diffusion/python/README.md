# mlcourse-09-diffusion

Python project for module 09. See the [module README](../README.md) for the
full walkthrough. Quick start:

```bash
uv sync
uv run python run_toy2d.py      # 2D spiral diffusion (~1 min)
uv run python run_ddpm.py       # mini-DDPM on FashionMNIST (~4-5 min)
uv run python run_diffusers.py  # pretrained DDPM + DDIM via diffusers
uv run python run_roadmap.py    # road-to-SD schematic figures
```

Source in `src/`, exercises in `exercises/`, verified answers in `solutions/`.
