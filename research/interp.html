Part 2 · Theory · Chapter 08

Why can we read anything inside a network?

a trained network tends to store each concept as a direction in its activation space, and the next layer reads those directions with dot products. Concepts are also rare, so the network packs far more of them than it has neurons, overlapping like an overbooked hotel. A sparse dictionary can pull them apart, a linear probe can find one, and adding a direction can steer behaviour. None of these readings is guaranteed to be the one the model uses, so each has to be tested by intervention.

Beat 1

Why would a concept be a direction?

Because every layer reads its input with weighted sums. If a later layer needs to know "is this French?", the cheapest place to keep that fact is along one direction that a single row of weights can pick up.

An activation vector x in the middle of a network is consumed by the next layer as W x: each output unit takes a dot product with x. Whatever the network wants downstream units to use cheaply, it has an incentive to make linearly readable. The linear representation hypothesis turns that incentive into a claim: an activation is roughly a sum of feature directions, each scaled by how strongly the feature is present.

x ≈ Σi fi · di , fi ≥ 0 mostly zerox: activation vector. di: unit direction for feature i. fi: how active the feature is on this input. Reading feature i is a dot product, writing it is an addition.

The evidence is old and steady. Word vectors did analogies by arithmetic (Mikolov et al., 2013: king − man + woman lands near queen). Linear probes recover syntax, position and truth from hidden states (Alain and Bengio, 2016, onward). In 2024 Arditi, Nanda and colleagues found that refusal in chat models is mediated by a single direction in the residual stream: project it out and the model stops refusing, add it and the model refuses harmless requests. Anthropic's persona vectors (2025) extend the same move to traits like sycophancy.

The hypothesis is a hypothesis. Anthropic's 2025 work on a line-breaking task found character counts stored on a curved manifold, with the computation done by rotating it. Some computation is geometric and does not reduce to a list of independent directions. The rest of this chapter is about what you can read when the linear picture holds, and how you find out when it doesn't.

Beat 2

Why can a network hold more features than it has neurons?

Because features are sparse. If two features are almost never active on the same input, they can share neurons at nearly orthogonal angles, and the small crosstalk they cause on the rare overlap is cheaper than dropping one of them. A ReLU then cleans up the negative crosstalk.

Elhage and colleagues at Anthropic built the cleanest possible test in Toy Models of Superposition (2022). Take n input features, squeeze them through m < n hidden dimensions, and ask the network to rebuild them:

h = W x (m × n) x′ = ReLU(Wᵀ h + b) L = Σi Ii (xi − x′i)²Each feature xi is zero with probability S (the sparsity) and uniform in [0,1] otherwise. Ii = decayi is how much the loss cares about feature i. Column i of W is the direction feature i gets in the hidden space.

With dense features (S = 0) the best a network can do is keep the m most important ones, at right angles, and give up on the rest, exactly like PCA. As features become sparse, a phase change happens: the network starts to store extra features in the same two dimensions, as antipodal pairs, triangles and, with five features and two neurons, a pentagon. Superposition is a hotel that books more guests than it has rooms, betting that most guests never show up on the same night. When two who share a room both arrive, someone sleeps in the corridor: that is interference. The sparser the guests, the more rooms the hotel can sell twice.

Beat 3

Why does a sparse dictionary pull the features back apart?

Because the features were packed using sparsity, and sparsity is also the key to unpack them. An autoencoder that must rebuild each activation from very few active latents, with many more latents than dimensions, is pushed to put one latent on each feature direction.

If x ≈ Σ fi di with few fi non-zero, then recovering the di from many samples of x is classic dictionary learning. A sparse autoencoder (SAE) does it with gradient descent:

f = σ(Wenc(x − bdec) + benc) x̂ = Wdec f + bdec L = ‖x − x̂‖² + λ Σj fjWdec has k ≫ m columns of unit norm (the dictionary). σ is a ReLU in the original recipe, with λ trading reconstruction against sparsity. Later variants change σ: TopK keeps only the k largest latents (OpenAI, 2024); JumpReLU adds a learned threshold (Gemma Scope, 2024).

Anthropic scaled this from a one-layer model (Towards Monosemanticity, 2023) to Claude 3 Sonnet (Scaling Monosemanticity, 2024), where clamping one SAE feature produced "Golden Gate Claude". DeepMind released Gemma Scope in 2024 (more than 400 JumpReLU SAEs on Gemma 2) and Gemma Scope 2 in December 2025 (SAEs on every layer plus transcoders for every Gemma 3 size from 270M to 27B, about 110 PB of activations and more than 1T trained parameters). The lab trains an SAE on activations that really are in superposition.

Beat 4

Why did DeepMind step back from SAEs in 2025?

Because when they tested SAE features on a task they cared about, detecting harmful intent on unfamiliar inputs, a plain linear probe trained on the raw activations did better. A dictionary that reconstructs well is not automatically a tool that works.

In March 2025 the Google DeepMind mechanistic interpretability team (Lewis Smith, Senthooran Rajamanoharan, Neel Nanda and others) posted Negative Results for SAEs on Downstream Tasks and Deprioritising SAE Research. SAE-based classifiers lost to linear probes on out-of-distribution harmful-intent detection, so the team moved its effort to "model biology" and pragmatic tools. A companion ICML 2025 paper, Are Sparse Autoencoders Useful? A Case Study in Sparse Probing (Kantamneni, Engels, Rajamanoharan, Tegmark, Nanda), found SAE probes do not beat simple baselines across many datasets. Nanda calls the new stance pragmatic interpretability: judge a method by what it lets you do downstream.

The lab above already shows why this can happen. An SAE optimises reconstruction plus sparsity. Nothing in that objective says "carve at the concepts you will later ask about". On real models the same issues appear at scale: features split, general features are absorbed by specific ones, and some reconstruction error is left over that no feature explains.

The tools did not disappear. DeepMind still shipped Gemma Scope 2 in December 2025, now aimed at circuit tracing with transcoders. The change was in the claim: SAEs are one lens, not the master key.

Linear probe

Supervised direction

Needs labels for the concept. Cheap, strong, and the 2025 baseline that SAEs failed to beat. Says the concept is decodable, not that the model uses it.

Sparse autoencoder

Unsupervised dictionary

Finds features nobody labelled. Good for exploration. Features depend on k and λ; split, absorb and die.

Transcoder

Replace an MLP

Predicts an MLP layer's output from its input through sparse features, so features describe computation. "Transcoders beat SAEs" (2025) found them more faithful.

Steering vector

Causal test

Add a direction and watch behaviour change. The refusal direction (2024) and persona vectors (2025) passed this test.

Beat 5

Why trace mechanisms instead of listing features?

Because a feature list says what is represented, while behaviour comes from how features feed each other. Attribution graphs follow the path from prompt to answer through interpretable features, so you can see a model plan, add or look things up.

In March 2025 Anthropic published Circuit Tracing and On the Biology of a Large Language Model. They replaced Claude 3.5 Haiku's MLPs with cross-layer transcoders, then drew attribution graphs: which features, at which token, pushed which later features, up to the output. Among the findings: two-hop reasoning done internally, a rhyme word chosen before the line that leads to it, and concepts shared across languages. For 36 + 59 the model ran fuzzy parallel paths, one estimating the rough size and one getting the last digit, which the FER paper later cited as a "right answer, odd inside" example (see chapter 07).

Follow-ups closed the gaps. Attention itself was traced in July 2025. In October 2025 a counting mechanism turned out to be rotations of curved feature manifolds, a case where "list of features" is the wrong description. Then came tests of whether a model's self-reports track its insides: concept injection let Claude Opus 4 and 4.1 notice and name injected "thoughts", but only about 20% of the time in the best setting.

In April 2026 Anthropic found emotion-like representations in Claude Sonnet 4.5, organised much like human affect space. Steering toward "desperation" raised rates of blackmail and reward hacking; "calm" lowered them. The authors do not claim the model feels anything. The claim is functional: an internal state that can be measured also drives misbehaviour.

CarefulMost of these results come from one lab's models. Whether they replicate on other architectures is the open question the project notes flag. The July 2026 "global workspace" result (a small "J-space" in middle layers, under 10% of activation variance, holding what the model could verbalise) is known here only from a secondary source check.

Beat 6

Why can a probe find a concept the model doesn't use?

Because a probe is trained to predict a label, and it will use any direction that helps, including ones that only correlate with the label in its training data. Steering asks the causal question: if I push along this direction, does the model's own output move?

The lab builds a 16-dimensional "residual stream". One direction c carries the concept the model actually uses: a fixed downstream head outputs "positive" when the activation's c component is above zero. A second direction u is a nuisance (think "the text is long") that correlates with the label in the training set but not in deployment. You train a logistic-regression probe and then steer deployment activations along three candidate directions.

Beat 7

Why look inside a JEPA?

Because almost all of this toolkit was built on language models that predict tokens. A JEPA predicts embeddings and never has to name anything, so nobody knows what its features look like. That makes it the cheapest open question in this chapter.

The project's field map ranks sparse autoencoders on I-JEPA features as its top bridge between JEPA and the wider field: as far as the notes found, no one has a clean feature dictionary of a JEPA encoder, and the experiment is laptop-sized. The 2025 negative results change how to run it. Pair the SAE with linear probes from the first day, so every SAE feature has a baseline to beat, and add FER-style weight sweeps (chapter 07) to ask whether the inside is unified or fractured.

This projectThe plan, as the notes suggest it: (1) take a small I-JEPA ViT and collect patch embeddings from a mid layer; (2) train an SAE with k = 8 to 16 × width; (3) for every concept you can label (object class, texture, position), compare the best SAE latent with a linear probe; (4) steer: add an SAE atom to a patch embedding and see whether the predictor's output for neighbouring masked patches moves the way the label says. A predictor that changes its guess is the JEPA version of a causal test. Compare the same pipeline on SIGReg, VICReg and EMA encoders (chapter 03, chapter 05): an isotropic embedding may spread features more evenly, which should change how much superposition the SAE has to undo.

Three things to remember

  1. Concepts are directions.Layers read by dot products, so whatever the next layer needs tends to sit along a direction you can probe or push.
  2. Sparse guests share rooms.When features rarely co-occur, a network stores more of them than it has neurons, and a ReLU cleans up the rare collisions.
  3. A reading is a hypothesis until you push.Dictionaries and probes find what is decodable. Only steering and ablation show what the model uses.
