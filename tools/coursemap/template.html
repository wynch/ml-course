Start here

Everything runs locally on an Apple-silicon Mac, one uv script at a time.

git clone https://github.com/wynch/ml-course.git
cd ml-course/modules/01-autograd   # read README.md first
cd python && uv run scripts/train_moons.py

Do the modules in order — 01–03 are load-bearing for everything after them.

After the course

  1. Go deeper on post-training — LLM course ch. 11–12 and the project-based smol-course, both with certificates.
  2. Ship an agent — the Agents course and MCP course turn module 10 into something graded and deployed.
  3. Widen the breadth — the full CV course and Diffusion course pick up where 08 and 09 stop.
