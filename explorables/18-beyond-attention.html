To write its next token, a transformer looks back at every earlier token, so it keeps a key and a value for each of them: the KV cache, which grows with every step. A recurrent model keeps one fixed-size state instead and overwrites it at each step. Below: the two counted step by step with the module's own models and measurements, then a recurrence with two states small enough to read, where you set the decays and how much the input may choose them.

2 · A recurrence with two states: decay and gate

Each step: hi ← ai·hi + (1 − ai)·x, with ai = exp(−Δ·λi). λi sets how fast state i forgets. Δ is the step size. With the gate at 0, Δ is the same at every step: the layer is linear and time-invariant, like the first model of section 2. With the gate at 1, Δ comes from the input: large on the marked tokens (write and forget fast), near zero on the others (hold). That is what "selective" means. The task: the input is a run of noise with a few marked digits; the reader wants the last digit.
