Self-supervised learning and JEPA

Module 16 · How learning works ← All explorables

A JEPA (joint-embedding predictive architecture) learns with no labels: it encodes one view of an input, and a predictor must guess the encoding of another view. The loss compares two outputs of the same encoder, so it has a cheap way out: send every input to the same point. That is collapse. Below: a two-dimensional JEPA that trains live in your browser, where you can switch the guards against collapse on and off; then the same guards on CIFAR-10 in the module's runs; then what each objective's encoder keeps.

1 · A 2-D JEPA, trained live

256 points in four clusters. Each step draws two noisy views of every point (noise 0.2). The encoder (2 → 16 tanh → 2) maps view 1 to a latent; a linear predictor maps that latent to a guess of view 2's latent. Loss: the squared error of the guess. Full-batch gradient descent, rate 0.05, weight decay 0.01. Switch the guards, then press Reset to start from the same random weights.
