Geometry of representations

Module 15 · How learning works ← All explorables

A ReLU network cuts its input space into linear regions: inside each one no neuron changes sign, so the whole network is one linear map there. Real data fills only a thin, curved part of its space, with an intrinsic dimension far below the pixel count. Below: a 2-D network's regions, cut exactly, that you can probe with a segment; how the count along a line grows with width; intrinsic dimension at each layer; and how alike two networks' layers are. Every number comes from the module's own runs.

1 · The tiling: drag the segment, change the width

A network 2 → w → w → out. Its first layer draws w straight lines across the square; inside each piece the second layer is linear, so each of its w neurons cuts the piece once more. Each colour is one region (one on/off pattern of the 2w neurons). Drag the two round ends of the segment: the count beside it is the number of regions it passes through, found exactly, the way the module counts along lines between images.
