Two ways to see an image

Module 08 · Vision ← All explorables

A convolution assumes structure: features are local, and the same small weight grid slides everywhere. A Vision Transformer assumes almost nothing: it chops the image into patches, calls each one a token, and lets self-attention decide which patches matter. Two inductive biases, one image.

The image below is real — test image 0 of the AI-Lab-Makerere/beans dataset (angular_leaf_spot), the same dataset module 08 fine-tunes ViT-tiny on. Watch a kernel slide over it, then watch it become a sequence of tokens. Press space to play or pause the convolution.

1Convolution — a sliding weighted sum

The kernel is a small grid of weights. At each position, multiply it element-wise against the pixels underneath and add everything up; that single number is one pixel of the feature map. Nothing more. Zero padding at the border keeps the output the same size (same padding, as in module 08's conv2d).

2Patchify — the same image as a sequence of tokens

A ViT has no sliding window and no locality prior. It cuts the image into a grid of non-overlapping patches in raster order, flattens each one, projects it linearly to a d-dimensional vector, adds a learned position embedding, prepends a [CLS] token — and hands the result to exactly the encoder you built for text in module 05. What to notice

  • Switch between sobel_x and sobel_y. The same image produces two completely different feature maps: one lights up on vertical boundaries, the other on horizontal ones. All that changed is nine numbers.
  • identity is a sanity check — the feature map is the input, pixel for pixel. That is exactly the assertion module 08's conv.py runs on itself.
  • Compare gaussian blur (all weights positive, summing to 1 — a local average) with laplacian (weights summing to 0 — a difference, so flat regions go to zero and only edges survive). Sign structure, not magnitude, is what a kernel means.
  • The learned 5×5 filter was never told what an edge is. Its left half is positive and its right half negative, which is a vertical-edge detector by any other name. Gradient descent rediscovered Sobel.
  • Note the multiply–add counter: 2304 output pixels × 9 weights = 20,736 MACs for one 3×3 kernel — and every one of those 2304 positions reuses the same nine weights. That reuse is the convolutional inductive bias, and it is why CNNs learn from modest data.
  • In panel 2, switch to 16 px patches. The sequence gets 4× shorter and each token carries 4× more pixels — the classic ViT trade: attention cost falls with the square of the patch size, spatial detail falls with it.
  • Once patches are a sequence, nothing downstream knows they came from an image. That is why the position embedding is not optional: without it, shuffling the patches would not change a single logit.
