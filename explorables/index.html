ML course explorables

11 interactive pages Quizzes ← Course home

Eleven single-file, in-browser explainers — one per module plus the evaluation bridge. Nothing to install, no network calls: every animation, model and number runs locally in the page.

Where a module produced real artifacts — trained weights, merge lists, attention matrices, measured timings — the explorable inlines them, so what you drag and scrub is the same data your own runs produce. Each page has Play/Pause (space), light and dark themes, and a footer link back to its module.

Finished a module? The quizzes check what stuck — ten questions each, graded in the page.
