Learning without a backward pass

Module 30 · How learning works ← All explorables

Backprop runs the network forward, keeps what each layer computed, then runs a backward pass that sends the error down, layer by layer. Keeping those values costs memory. Four other rules learn without that pass: MeZO nudges every weight along one random direction and compares two losses; forward-forward and Mono-Forward give each layer a goal of its own; predictive coding lets the error spread down by local steps. Below: the five racing on a small task in your browser, then what the module measured.
