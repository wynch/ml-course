Module 23 · Using models well ← All explorables

Three ways to make a trained model smaller: store each weight in fewer bits (quantise), set the weights that matter least to zero (prune), or train a smaller model to copy the big one (distil). Section 1 quantises a real block of SmolLM2-360M's weights in this page, at the bits and group size you pick. The other sections replay what the module measured.
