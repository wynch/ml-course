Anatomy of a transformer

Module 05 · Transformers/LLMs ← All explorables

A decoder-only LLM is one small circuit repeated N times over a residual stream. Below, a pulse carries one token's vector up the stack: embed, then N blocks of norm → attention → add, norm → MLP → add, then a final norm and the unembedding to logits. Hover or click any component for what it does and its real tensor shapes — switch models to see the very same diagram at three scales (module 04's tiny char-GPT, SmolLM2-360M, SmolLM3-3B). Then watch the logit lens strip: what each layer would have predicted, from SmolLM2's real run on "The Eiffel Tower is located in the city of".

What to notice

  

    
    
      
  • The MLP is where the parameters are. Switch to SmolLM2 and read the budget bar:
        mlp 65.2%, attention 21.7%, embeddings 13.0%,
        norms 0.0% (62.4k of 361.8M). Attention gets the attention; the MLP gets the weights.
    • 
      
  • Depth, not width, changed most. tiny char-GPT → SmolLM2 → SmolLM3 goes
        128 → 960 → 2048 hidden and 3 → 32 → 36 layers, but the box diagram never changes shape.
        Only the tiny GPT still uses learned position embeddings and a LayerNorm with a bias;
        the two SmolLMs use RoPE and a weight-only RMSNorm.
    • 
      
  • GQA is visible in the shapes. Hover attention on SmolLM2: q_proj is
        960→960 but k_proj/v_proj are only 960→320 — 5 key/value heads shared
        across 15 query heads. That asymmetry is what makes the KV cache affordable (module 07).
    • 
      
  • Most of the depth is retrieval, not answering. The lens strip is bright (answer far from #1)
        for 26 layers of nonsense — ' psychiat', "('.//" — then
        ' Paris' snaps to rank 1 at layer 27 with 71% and holds to the end.
        The residual stream commits late.
    • 
      
  • Layer 0 is a mirror. Read straight off the embeddings, the "prediction" is
        ' of' at 100% — the last input token itself. The stack has to do work
        before the lens says anything interesting.
