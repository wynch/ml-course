Text by denoising

Module 33 · Breadth ← All explorables

A language model can write a line the way an image model draws a picture: start from noise and remove it step by step. For text the noise is [MASK]: start from a line of 128 masks and, at each step, let the model guess every hidden character and keep a few of its guesses. Everything here is the module's real data: module 04's small character model, trained on Shakespeare as a masked diffusion model, and its autoregressive twin. Nothing on this page runs a model; it replays recorded samples and draws the measured curves.

4 · One block at a time

Block diffusion writes the line in blocks, left to right, and denoises inside each block. Finished blocks never change, so their keys and values can be cached, as in an autoregressive model.
