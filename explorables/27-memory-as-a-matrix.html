Memory as a matrix

Module 27 · Other recipes ← All explorables

A recurrent layer can keep its state as a matrix S that stores values under keys: write a value v under a key k, and later S·k returns it. How it writes decides what survives. Linear attention adds v kᵀ on top of what is there. Decay first shrinks everything. The delta rule first removes what S already returns for k, then writes v. Below: a memory small enough to see, then one of the module's size, then what trained models and two real ones did.

1 · A memory you can see: keys of two numbers, values of one

The state is a 1 × 2 matrix, drawn as an arrow. A key is a direction (an angle), a value is a number from −1 to 1. Reading key k gives S·k: the curve shows what S returns for every direction. Two numbers can hold two independent keys exactly, never three. Click the chart to write a pair at that angle and height, or step through the preset list.
