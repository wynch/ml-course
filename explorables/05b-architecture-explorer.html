Every large language model on this page is the same idea: a residual stream that a stack of blocks reads from and adds to. What changes from model to model is what sits inside the block, how many times it repeats, and which layers differ. Pick a model to see its block drawn from its own config and papers, with the inside of its attention and feed-forward parts. Tap any part for a plain definition and the module that teaches it. Compare two models, or walk a family from parent to child and watch the block change.

    Module: 05 · The transformers library. Data: architectures/records/, one JSON file per model, written into this page by architectures/build.py.
    Each fact links its source: the model's own config.json (or a marked public copy of a gated one), weights index, model card, paper or the lab's post.
    Keyboard: the model list is the keyboard route to every model; the timeline dots repeat it for the mouse. Every part of a drawing is a tab stop; Enter or Space opens its definition.
    Sebastian Raschka's LLM Architecture Gallery inspired this page, and some records cite his gallery data as a secondary source. His diagrams, and anyone else's, are linked from each fact sheet, never copied. The drawings here are made from the records alone.
