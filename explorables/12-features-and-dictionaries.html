Features and dictionaries

Module 12 · Looking inside ← All explorables

A layer can hold more features than it has dimensions if the features are rare. A sparse autoencoder (SAE) tries to undo that packing: it rewrites each activation as a few directions out of a large dictionary. Below: the toy model where the packing happens, a feature browser for an SAE trained from scratch on module 04's char-GPT and for a published SAE on GPT-2 small, and a steering demo. Every number comes from the module's own runs.

1 · Toy superposition: move the sparsity

The toy model squeezes n features into m < n dimensions and reads them back through a ReLU. Each feature is zero with probability S. Left: 5 features in 2 dimensions, one arrow per feature.
