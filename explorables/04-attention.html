Attention, one query at a time

Module 04 · Attention ← All explorables

Self-attention is one formula: softmax(Q Kᵀ / √d_head) V. Every token emits a query ("what am I looking for?"), a key ("what am I?") and a value ("what do I contribute?"); the softmax over query·key turns a row of scores into a set of weights that sum to 1, and the output is that weighted average of values. Switch to real tiny-GPT heads to see the actual post-training numbers from module 04's 620k-parameter char model (3 layers × 4 heads), or stay in toy vectors to type your own tokens. Press space to sweep the query token down the sequence.

What to notice

  • Turn the causal mask off. The upper triangle lights up and every row changes — because the softmax renormalises over more keys. That is exactly why a decoder-only LM must mask: with the future visible, predicting the next token is trivial and the model learns nothing useful. (Module 04 exercise ex_b_ablate_causal_mask.py does this ablation for real.) Note token 0 is unaffected: it can only ever see itself.
  • Push temperature toward 0.1. The same scores collapse onto a single bright cell per row — attention becomes a hard lookup. Push it to 4 and every row flattens toward uniform 1/i, i.e. plain averaging. The √d_head in the formula is a fixed version of this knob: without it, dot products grow with dimension and the softmax saturates on its own.
  • Real heads specialise. Sweep layer/head on the real model: some rows are a bright diagonal (attend to self), some are a bright sub-diagonal (attend to the previous token — the bigram detector), and several put heavy mass on token 0, a "no-op / attention sink" parking spot. L2H3 on To be or not to be is a strong previous-token head; L1H0 is a sink.
  • Row 0 is always 1.000. With the mask on, the first query has exactly one legal key — itself — so its softmax is forced. Later rows have more choices, which is why attention entropy (shown in the readout) generally rises with position.
  • The output is a blend, not a pick. Watch the output bars in the right panel: they are Σⱼ wⱼ · Vⱼ. When one weight dominates, the output nearly equals that token's value vector; when weights are flat, the output is a mush near the mean — which is what an untrained head does before it learns anything.
