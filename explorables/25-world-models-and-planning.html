World models and planning

Module 25 · Acting and planning ← All explorables

A world model predicts what an action will do. A planner can then try actions in its head before it takes one. This page holds the module's two trained models of an 8 × 8 grid world: a one-hot model, which predicts the agent's next cell, and a JEPA, which predicts the next latent. Each one drives the same planner: try 64 random sequences of 8 actions in the model, take the first action of the one that looks closest to the goal, repeat.

1 · Draw an arena, run both planners

Click the left board to place walls, the agent or the goal. Step makes one decision for each planner; Run plays up to 20. The dotted line on each planner's board is the sequence it chose this step, as its model imagines it. The JEPA's imagined cells come from a linear probe that reads the goal's offset from the latent.
