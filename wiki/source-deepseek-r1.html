DeepSeek-R1

source created 2026-05-06 updated 2026-10-20 reasoning rl grpo deepseek post-training test-time-compute technical-report

Authors: DeepSeek-AI Date: January 2025 (arXiv 2501.12948); subsequently published in Nature (2025). Full text: raw/arxiv-2501-12948-deepseek-r1-incentivizing-reasoning-capability-in.md (v2 of 2026-01-04, captured 2026-10-20; v2 follows the Nature version's structure), cited below by section

Summary

The open-weights proof point that pure reinforcement learning on a base model can elicit o1-style long-form reasoning without any supervised reasoning traces. Trained on top of DeepSeek-V3 using GRPO with verifiable-reward signals (math, code), the paper releases two artefacts: R1-Zero (no SFT cold start, raw RL on the base model) and R1 (small SFT cold start then RL).

Key Claims

R1-Zero: RL straight on the base model

  • No supervised reasoning data. Just GRPO with rule-based rewards on math/code problems. (§2.1–§2.2)
  • Reasoning behaviours emerge spontaneously: long chains of thought, self-verification, "wait — let me reconsider" backtracking, dynamic strategy switching.
  • Two separate exhibits: a plot of average response length rising over RL steps, and an "aha moment" transcript where an intermediate checkpoint stops to re-check (arXiv 2501.12948). In v2 the length plot is Figure 1(b) and the "aha moment" is Table 2, described as "a sudden increase in the use of the word 'wait' during reflections" (§2.3; Appendix C).
  • Caveat: R1-Zero is hard to read (mixed languages, formatting issues) — hence the R1 variant. (§3)

R1: small cold-start SFT + RL

  • A few thousand curated long-CoT examples bootstrap readability, then GRPO continues from there.
    • Added 2026-10-20: v2 describes four stages, not two: thousands of cold-start examples, RL with a language-consistency reward, rejection sampling plus SFT on reasoning and non-reasoning data, then a second RL stage for helpfulness and harmlessness (§3, Figure 2).
  • Matches or approaches OpenAI o1 on AIME, MATH-500, Codeforces, GPQA — the first open replication of o1-class reasoning. (Appendix D.2)

GRPO (Group Relative Policy Optimization)

  • Introduced in DeepSeekMath (Shao et al., arXiv 2402.03300); R1 applies it.
  • PPO variant that drops the value/critic network: advantages are computed by sampling K completions per prompt and using the group's reward statistics as the baseline.
  • Cheaper memory and easier to scale than PPO. Has since become the default RL algorithm for reasoning models across the open ecosystem.

Distillation

  • The R1 model's reasoning traces are used as SFT data to distil reasoning into much smaller dense models (1.5B–70B Qwen / Llama bases). The distillation set is 800,000 samples generated with R1 (Appendix F).
  • The distilled 14B/32B variants beat substantially larger non-reasoning models — RL-as-amplification at the teacher, then plain SFT as the cheap delivery mechanism.

Why it matters

  • Wiki reading: it weakened the "you need o1's secret sauce" narrative; pure RL with verifiable rewards on a strong base model is sufficient.
  • Wiki reading: it made GRPO the common RL recipe for reasoning in open models.
  • Provided the canonical example for "RL sharpens what the base model already weakly knows" — connects to source-distribution-sharpening-power-sampling's claim that RL doesn't add capabilities, it amplifies existing modes.
  • The distillation result reframed reasoning models as a teacher problem: train one R1, distil into anything.
