Mamba: Selective State Spaces

source created 2026-05-06 updated 2026-10-09 state-space-models ssm architecture alternatives-to-attention long-context 2023

Albert Gu, Tri Dao — arXiv 2312.00752, 2023 (CMU / Princeton)

The first state-space model (SSM) architecture to credibly match transformers in the 1B–3B parameter regime on language modelling, while running in linear time and constant memory per step at inference. Mamba's central move is to make the SSM's transition parameters input-dependent (selective), restoring the content-based reasoning that prior linear-time SSMs (S4, H3) lacked.

Method

  • Selective SSM: the discrete-time recurrence
    • h_t = A_t h_{t-1} + B_t x_t, y_t = C_t h_t
    • has A_t, B_t, C_t depend on the input x_t (vs. fixed in S4). This breaks the clean global-convolution form but lets the model selectively propagate or forget information based on content — the missing ingredient for language.
  • Hardware-aware parallel scan: input-dependent A makes the recurrence non-LTI, so it can't be computed via FFT. The authors implement an FA-style fused kernel — selective scan in SRAM, recompute in backward — that hits ~3× the throughput of a naive PyTorch scan.
  • Mamba block: replaces transformer's "attention + MLP" with a single homogenous block: linear projection → 1D conv → selective SSM → gated output. No attention, no MLP separation.
  • No positional encodings: position is implicit in the recurrence's order.

Key numbers

  • 5× higher inference throughput than a transformer of the same size (linear in seq length vs. quadratic).
  • Matches or exceeds transformers (Pythia, RWKV) at 125M, 350M, 1.3B, 2.8B parameters on the Pile, with the gap widening at long context.
  • DNA modelling: scales to 1M-token context; audio: SOTA on long-form speech.

Why it matters

The most credible non-attention LM architecture to date. Mamba revived the SSM thread (S4 → H3 → Mamba) by solving its core failure mode — content-free state transitions — and demonstrated that a linear-time architecture can be competitive at moderate scale. Together with source-flashattention / source-flashattention (which set the bar by making exact attention nearly hardware-optimal), Mamba defines the modern long-context battleground.

It's the direct precursor to source-mamba-2-ssm-duality (which reveals SSMs and a structured form of attention are mathematically equivalent — turning Mamba into a generalised linear attention). The wiki's other recurrence-flavoured architectures sit in dialogue: source-olmo-hybrid-rnn-transformer (Allen AI's attention+linear-RNN hybrid validating that some attention is still helpful at 7B), source-m2rnn-matrix-valued-states (matrix-valued recurrences with non-linear transitions), and source-ttt-kv-binding-linear-attention (TTT ≡ linear attention).

Later evidence

Contradiction (partial): this page says Mamba matches transformers with "the gap widening at long context". source-memory-mosaics-at-scale argues that any model with a fixed-size state fails multi-document question answering by construction, since it must compress the documents before it reads the question. It cites RULER: at 2k, Mamba-2.8B scores 52.6 against Llama2-7B's 91.6; on Tacred in-context classification Mamba-2.8B scores 0 at 1 to 5 shots (raw/arxiv-2507-03285-memory-mosaics-at-scale.md, §5.2, Appendix D, Tables 7-8). Different measures (language-model loss here, retrieval there), unmatched model sizes, and the numbers are copied from other papers, not rerun. The wiki holds no raw copy of the Mamba paper, so "the gap widening at long context" is this page's wording. The paper itself grants that compressing models do "very well" on knowledge from training (same file, Appendix D).
