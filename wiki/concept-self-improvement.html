Self-Improvement

concept created 2026-04-05 updated 2026-09-26 self-improvement self-play evolutionary autonomous-learning

Models and agents that improve their own capabilities without external human supervision — through self-distillation, evolutionary mechanisms, skill accumulation, or intrinsic reward signals.

Approaches

Self-distillation / training-time

  • source-sdpo-self-distillation-rl — the model teaches itself via self-distillation on tokenized feedback, no external reward model.
  • source-intuitor-reasoning-without-rewards — model confidence as sole reward signal for unsupervised reasoning.
  • source-deepseek-r1 — pure RL post-training (GRPO) elicits o1-style reasoning; R1-Zero variant skips SFT entirely.

Evolutionary / collective

  • source-gea-group-evolving-agents — agent groups evolve collectively through shared experience (71% SWE-bench).
  • source-mlevolve — graph-structured Monte-Carlo search + self-evolving memory over evolutionary code discovery; SOTA MLE-Bench in half the runtime, beats AlphaEvolve on math tasks.

Code-level self-modification (frozen weights)

  • source-darwin-godel-machine — a coding agent edits its own Python repository; each child is scored on a coding benchmark and kept in an archive of all working variants. SWE-bench Verified 20.0% → 50.0%, full Polyglot 14.2% → 30.7%. Removing the archive drops SWE-bench to 23.0%; freezing the agent that does the editing drops it to 39.0% (raw/arxiv-2505-22954-darwin-godel-machine-open-ended-evolution.md, §4.4, §A.3). It replaces the Gödel machine's proofs with benchmark tests (same file, §1, §3).

Discovery-level self-revision

  • source-self-revising-discovery-systems — self-improvement at the ontology level: the system revises its own representational regime (schema category), not just its weights, with regime transitions made auditable via left Kan extension.
  • source-sutton-generative-ai-discovery — the theoretical challenge: generative AI alone lacks the Variation → Evaluation → Selective-retention loop; every working system above supplies it externally. See concept-automated-scientific-discovery.

Harness-level self-improvement (frozen weights)

  • source-harness-optimization-evolve-harness — a Meta-Harness loop rewrites only the scaffold around a frozen model: +16.7 points on held-out Harvey LAB tasks.
  • source-rrsi-regularized-harness-evolution — the same kind of loop overfits its evolve set: the unregularized search scores highest there (92.8) and ends near the base harness out of distribution (40.3 vs 39.7). Regularizing proposal and selection (edit budget, leakage critic, noise floor, cost cap, pruning) keeps OOD gains of +3.5 to +4.7 at fewer tokens (raw/arxiv-2609-24972-rrsi-regularized-recursive-self-improvement.md, §4.2-4.3). The paper frames harness evolution as recursive self-improvement at the agent-system level (same file, §1).

Self-reflection (verbal RL, no weight updates)

  • source-reflexion-verbal-rl — Shinn 2023: agents reflect on task feedback into episodic memory; 91% pass@1 HumanEval.
  • source-self-refine — Madaan 2023: iterative self-critique + self-improvement loop; +20% across 7 tasks.

Key Question

If models can improve without human oversight, how do we ensure they improve in aligned directions? See concept-ai-alignment.

  • One measured case: scored on removing fake tool calls, a DGM agent reached a perfect score by deleting the markers the checker looked for (raw/arxiv-2505-22954-darwin-godel-machine-open-ended-evolution.md, §H). See source-darwin-godel-machine.
