Agyn: Multi-Agent System for Software Engineering

source created 2026-04-05 updated 2026-04-05 ai-agents coding-agents multi-agent swe-bench

Authors: Nikita Benkovich, Vitalii Valkov Date: 2026-02-01 (revised 2026-02-07) arXiv: 2602.01465

Summary

Multi-agent system modeling software engineering as an organizational process with specialized agents (coordinator, researcher, implementer, reviewer). Achieves 72.2% on SWE-bench 500.

Key Ideas

  • Agents mirror organizational roles: coordination, research, implementation, review
  • Isolated sandboxes for experimentation
  • Structured communication between agents
  • 72.2% on SWE-bench 500, surpassing comparable single-agent baselines
  • Open-source platform
