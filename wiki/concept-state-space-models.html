State Space Models and Linear Attention

concept created 2026-10-20 updated 2026-10-20 architecture state-space-models linear-attention recurrence hybrids long-context hub

A state space model (SSM) layer reads a sequence by updating a fixed-size state, so memory stays constant and compute grows linearly with length, unlike attention, whose cache grows with every token (raw/arxiv-2603-15569-mamba-3-improved-sequence-modeling-using.md, §1). Linear attention is the same idea seen from the attention side: the layer keeps a matrix as memory and writes each key-value pair into it (raw/arxiv-2412-06464-gated-delta-networks-improving-mamba2-with.md, §1). Mamba-2 showed the two are one family (source-mamba-2-ssm-duality).

The delta rule has a second reading: one step of gradient descent on ‖S k − v‖² at test time, with the gate acting as weight decay on that step (raw/arxiv-2412-06464-gated-delta-networks-improving-mamba2-with.md, §3.1, Table 1). That is where this family meets concept-test-time-training.

How it changed

  • 2023, Mamba. Input-dependent state updates made an SSM competitive with transformers at 125M to 2.8B parameters on the Pile (source-mamba-ssm; arXiv 2312.00752, not in raw).
  • 2024, Mamba-2. The duality, a kernel "2-8× faster" than Mamba's scan, and states 8× larger. In a 350M, 48-layer model, about 10% attention layers gave the best perplexity: 8.26 against 8.60 for pure Mamba-2 and 8.68 for Transformer++ (raw/arxiv-2405-21060-transformers-are-ssms-generalized-models-and.md, §1, §9.2, Table 2).
  • 2024–25, Gated DeltaNet. At 1.3B and 100B tokens, an eight-task average of 55.32 against Mamba-2's 54.89; the hybrids with sliding-window attention reach 56.40 and 56.18 (raw/arxiv-2412-06464-gated-delta-networks-improving-mamba2-with.md, Table 3).
  • 2026, Mamba-3. At 1.5B: Transformer 55.4, Gated DeltaNet 55.8, Mamba-2 55.7, Mamba-3 56.4, Mamba-3 MIMO 57.6. One decode step on an H100 takes 0.156 ms against Mamba-2's 0.203 (raw/arxiv-2603-15569-mamba-3-improved-sequence-modeling-using.md, Table 3, §4.4, Table 6).
  • 2026, at 7B. OLMo Hybrid puts three Gated DeltaNet sublayers to each attention sublayer and matches Olmo 3 7B on MMLU with 49% fewer tokens, per Allen AI's blog (allenai.org/blog/olmohybrid; not in raw). M²RNN adds non-linear transitions on a matrix state (arXiv 2603.14360; not in raw).

Where it fails: retrieval

Every recent paper here reports the same weak spot. Pure linear models trail the transformer at pulling facts from semi-structured text: SWDE 48.9 for the Transformer against 28.5 for Mamba-3 (raw/arxiv-2603-15569-mamba-3-improved-sequence-modeling-using.md, §4.1.2, Table 4). On real-world retrieval Gated DeltaNet averages 30.6 against the Transformer's 37.0; both hybrids pass it, at 39.0 and 40.1 (raw/arxiv-2412-06464-gated-delta-networks-improving-mamba2-with.md, Table 4). Mixed 5:1 with attention, Mamba-3 hybrids catch up or pass the Transformer on those tasks (raw/arxiv-2603-15569-mamba-3-improved-sequence-modeling-using.md, Table 4).

Contradiction (partial), carried from source-mamba-ssm: Memory Mosaics argue that any model with a fixed-size state fails multi-document question answering by design, since it must squeeze the documents before it sees the question. Their tables, copied from other papers: on RULER at 2k, Mamba-2.8B 52.6 against Llama2-7B's 91.6; on Tacred in context, Mamba-2.8B scores 0 at every shot count (raw/arxiv-2507-03285-memory-mosaics-at-scale.md, §5.2, Appendix D, Tables 7–8; source-memory-mosaics-at-scale). The hybrid results above fit the claim for pure models and soften it for mixed ones. The Mosaics paper trained no SSM itself and compares unmatched sizes (same file, Appendix D).

Test-time training is linear attention

A test-time-training (TTT) layer keeps a small network as its state and takes gradient steps on it as tokens arrive. Liu et al. prove that, with a linear, bias-free last layer, a broad class of TTT layers can be rewritten as linear attention, and they argue against reading the inner loop as memorising key-value pairs: gradient ascent in the inner loop does as well (perplexity 16.19 against 16.43) (raw/arxiv-2602-21204-test-time-training-with-kv-binding.md, §4.2, §5, Table 1; source-ttt-kv-binding-linear-attention). See concept-test-time-training.

Open questions

  • Does the retrieval gap close with scale, or only with attention layers? The evidence here stops at 1.5B for pure models (raw/arxiv-2603-15569-mamba-3-improved-sequence-modeling-using.md, §4.1).
  • Where should the attention layers go in a hybrid? The Mamba-3 authors call hybrid behaviour "complex and oftentimes unintuitive" (same file, §4.1.2).
  • At the edge, which matters more: state size, or how much of the state each input touches? SSLA buys 380× fewer operations by touching little of a large state (raw/arxiv-2603-06228-low-latency-event-based-object-detection-fulltext.md, §4.4; source-ssla-event-detection).
