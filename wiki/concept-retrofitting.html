Retrofitting

concept created 2026-05-06 updated 2026-05-06 model-training self-distillation fine-tuning architecture-modification

Modifying both parameter values and the model architecture itself ("which parameters there are"). Strict superset of fine-tuning. Crystallised as a discipline in 2026 by source-retrofitting-models-minixhofer.

Four ingredients (per Minixhofer)

  1. Self-distillation — original model as teacher; on-policy beats off-policy beats none. Largest single lever.
  2. Architecture-space graduality — incremental interpolation, not hard swap.
  3. Expressivity matching — the new architecture must be able to represent comparable function classes.
  4. Data coverage — must match pretraining diversity; tail collapses otherwise.
