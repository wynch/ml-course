Program Synthesis

concept created 2026-10-20 updated 2026-10-20 program-synthesis library-learning neural-symbolic decompilation arc-agi hub

Program synthesis: find a program that meets a specification, most often a few input-output examples. The answer is code that can be run, read and checked, not a set of weights. In this wiki it appears in three forms: search for programs, growing a library of reusable parts, and turning trained networks into programs (decompilation). It is the symbolic end of concept-neural-symbolic-bridge.

Three forms

How it changed

  • 2020, DreamCoder. A wake-sleep loop: search for programs guided by a recognition model; refactor solved programs into new library entries; train the recognition model on replayed and sampled programs. From a handful of examples per task it rediscovers basics of functional programming, vector algebra and physics (raw/arxiv-2006-08381-dreamcoder-growing-generalizable-interpretable-knowledge-with.md, Abstract, "Wake/Sleep Program Learning", "Results").
  • 2023, FunSearch. A frozen LLM proposes Python functions; every one is run and scored; winners join an evolving population. It found larger cap sets in dimension 8 than any known (Nature 625, 2024; doi 10.1038/s41586-023-06924-6; not in raw).
  • 2023–24, LILO. An LLM replaces DreamCoder's neural search; Stitch, a symbolic compressor, finds the best abstractions in seconds on one CPU; an LLM names and documents each one (raw/arxiv-2310-19791-lilo-learning-interpretable-libraries-by-compressing.md, Abstract, §3).
  • 2025, AlphaEvolve. Gemini models drive an evolutionary loop over whole code files, scored by automated checkers. Results include a 4×4 complex matrix product with 48 scalar multiplications and a scheduling heuristic that recovers 0.7% of Google's fleet compute (raw/arxiv-2506-13131-alphaevolve-a-coding-agent-for-scientific.md, §3.1, §3.3).
  • 2026, decompilation. D-RASP proves that a GPT-2-style transformer whose layer norms act linearly has an equivalent RASP program, exponential in size, then prunes it by causal tests to a small program on small trained models (raw/arxiv-2602-08857-discovering-interpretable-algorithms-by-decompiling-transformers.md, §3.1, §3.2, §4). Tracr goes the other way, compiling RASP into weights (arXiv 2301.05062; not in raw).

ARC: the refinement loop

The ARC Prize 2025 report names the year's theme the refinement loop: per task, a program or a set of weights improved step by step against a feedback signal. It lists four kinds: test-time training of a pretrained model, training from scratch on one task, evolutionary program synthesis, and chains of thought refined against a verifier (raw/arxiv-2601-10904-arc-prize-2025-technical-report.md, §3, §3.1). Two runner-up papers evolve ARC programs, one in natural language, one in Python with a library of abstractions built as it goes; both explore many candidates, then check them against the training pairs, and repeat (same file, §3.1.1).

Contradiction (partial), carried from concept-arc-agi: program synthesis did not win ARC Prize 2025. The top Kaggle entry built on test-time training and the top paper trained a 7M network from scratch; program synthesis took the second paper award (SOAR, an LLM fine-tuned on its own search traces) and two runner-up places (same file, §2.2, §2.3, Table 2). The report itself treats program search in symbol space and training in weight space as two forms of one loop (§3.1.2). Symbolica's 85.28% on the ARC-AGI-2 public set comes from an LLM agent writing Python, but the same model alone scores 79.03% (raw/web-2026-symbolica-arcgentica-arc-agi-2.md, Figure 1 data; source-symbolica-arc-agi-2).

Local lines

Vincent's ARC lines were program-search or symbolic, and all were sunset on 2026-10-07: ORCHID-lite scored 0% on official ARC-AGI-1 (experiment-orchid-lite); CPE reached at best 28/1000 on the ARC-AGI-2 training split, with an untrained neural guide (experiment-cpe). The lesson kept on both pages: heuristic play and learned resources need leakage and transfer audits before a score is trusted (analysis-experiments-second-chance). Both scored programs by description length; see concept-minimum-description-length.

Open questions

  • Does a library pay off on ARC, where each task is new? Pang's runner-up builds one as it goes (raw/arxiv-2601-10904-arc-prize-2025-technical-report.md, §3.1.1); the report gives no ablation.
  • How much of an LLM-guided synthesis score is the model, and how much the search? Symbolica's table says mostly the model, for its strongest model.
  • Can decompilation reach a stock language model? D-RASP's readable programs come from small trained transformers only.
