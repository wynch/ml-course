The geometry of agent memory: a mostly negative result

source created 2026-10-23 updated 2026-10-23 agent-memory retrieval embeddings evaluation calibration negative-result 2026

Authors: Iliya Zhechev, Radoslav Ralev, Chris Coleman, Srijith Rajamohan, Jen Agarwal, Tyler Hutcherson, Simba Khadder (mostly Redis) Published: arXiv 2610.26433, v1 2026-10-19; a poster at the NeurIPS 2026 PALM workshop (R, header) Raw copy: raw/arxiv-2610-26433-the-geometry-of-agent-memory-forecasting.md (full text of v1 from the arXiv HTML; cited as R, with its section)

Terms

  • Agent memory. A store of texts a chat agent keeps from past conversations, searched by embedding similarity when a new question comes in (R, §1).
  • Geometric features. Distances between the embedded question, the stored memories and the original conversation turns, such as how close the nearest memory is (R, §3). 25 in all.
  • AUROC. The chance that a randomly chosen correct answer gets a higher predicted score than a randomly chosen wrong one; 0.5 is chance, 1.0 perfect.

The claim, plainly

Distances between a question and an agent's stored memories do predict, somewhat, whether the agent will answer correctly, but not much beyond knowing how hard the question is and which memory system is used. Over question difficulty alone, geometry adds +0.026 AUROC [0.010, 0.042]; once system identity is added too, the pooled gain is +0.002 and not established (R, Abstract, §5.6).

Key results

All on LongMemEval-small: 500 questions, five memory implementations, 2,367 question–system pairs, gpt-4o answering and judging, one 5-fold split grouped by question (R, §4).

  • Pooled prediction is weak. Geometry gives AUROC 0.640; a question-difficulty baseline (question type, length, and its embedding) gives 0.655; adding geometry to difficulty gives 0.681, a gain of +0.026 [0.010, 0.042] (R, §5.1, §5.6).
  • The best case is a confound. On one question type, geometry reaches 0.841, but knowing only which system answered reaches 0.826, and memory count alone 0.830 (R, §5.1, §5.6). One system made 41 of that type's 73 errors (R, §5.6).
  • Nothing added after controls. Difficulty plus system identity gives 0.679; adding geometry gives 0.681, a pooled difference of +0.002 with 95% interval [−0.010, 0.014]. On the best question type, geometry's paired gain over system identity is +0.015 [−0.020, 0.049], also not established (R, §5.6).
  • Choosing context by similarity matters a lot. With the same memory store, showing the answer model the 15 closest memories gives 0.790 accuracy with gpt-4o, against 0.091 for 15 random ones (R, §5.5, Table 5). The authors read this as ordinary retrieval relevance, not a new geometric effect (R, §5.5).
  • The model's own confidence ranks backwards here. For three systems, verbalised confidence and P(True), the model's stated probability that its answer is right, give AUROC about 0.43; for P(True) the interval is [0.393, 0.466], so below chance, while verbalised confidence is reported without an interval (R, §5.6). The authors note AUROC alone does not show miscalibration (R, §5.6).
  • Other data. On LoCoMo, nearest-turn similarity predicts single-hop correctness weakly (0.603) and is near chance for multi-hop, temporal and open-domain questions; 10 conversations, no intervals (R, §5.8, Table 6).

Caveats

The authors list them (R, §6, "Limitations"): two English benchmarks; five implementations in their own harness; one cross-validation split; preprocessing fitted on the full set; features chosen on the same benchmark with no separate test set; no check of whether the answer-bearing fact was stored or reached the prompt.
