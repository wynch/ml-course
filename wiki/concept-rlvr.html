RL with Verifiable Rewards (RLVR)

concept created 2026-10-20 updated 2026-10-20 training-methods reinforcement-learning rlvr grpo reasoning post-training hub

Reinforcement learning with verifiable rewards trains a language model on problems a program can grade: the model gets 1 when a checker says its final answer is right, or its code passes the tests, and 0 otherwise (raw/arxiv-2504-13837-does-reinforcement-learning-really-incentivize-reasoning.md, §2.1). No reward model and no human labels sit in the loop. It is how open reasoning models have been trained since DeepSeek-R1.

GRPO and its family

GRPO (Group Relative Policy Optimization, from DeepSeekMath) samples a group of answers per problem and scores each against the group's average, so it needs no value network; PPO needs one (raw/arxiv-2501-12948-deepseek-r1-incentivizing-reasoning-capability-in.md, §2.1, Figure 3). A problem the group always or never solves gives no gradient (raw/arxiv-2609-35426-frontier-learning-training-llm-reasoners-at.md, §1, §2).

How it changed

  • 2025-01, DeepSeek-R1. GRPO with rule-based rewards on maths and code, applied straight to a base model (R1-Zero), produced long chains of thought and self-checking with no supervised reasoning data (raw/arxiv-2501-12948-deepseek-r1-incentivizing-reasoning-capability-in.md, §2.1–§2.3; source-deepseek-r1).
  • 2025-04, the ceiling. Yue et al. compared each RL model with its own base at large k (pass@k: solved if any of k samples is right). RL wins at k = 1, the base wins at large k, on every benchmark and model family they tried. On AIME24 at k = 1024, 13.3% of problems are solved by the base only and 0.0% by the RL model only (raw/arxiv-2504-13837-does-reinforcement-learning-really-incentivize-reasoning.md, Abstract, §3, §4.1, Table 2).
  • 2025-05, the reply. ProRL ran RL for over 2,000 steps on 136K problems beyond maths. On boxnet, a task never trained on, the start solves nothing and the trained model does (pass@k 0.00 against 7.91); on maths it reports the same narrowing Yue et al. found (raw/arxiv-2505-24864-prorl-prolonged-reinforcement-learning-expands-reasoning.md, §4.2, §4.3, Table 3).
  • 2025-06, the control. Random rewards lift Qwen2.5-Math-7B by 21.4 points on MATH-500, against 29.1 for true rewards; on Llama and OLMo they give little or nothing. The cause is GRPO's clipping, which pushes up what the model already prefers; here, writing Python it cannot run (raw/arxiv-2506-10947-spurious-rewards-rethinking-training-signals-in.md, Abstract, §3, §4, §5.1; source-spurious-rewards).
  • 2025-09, forgetting. At equal accuracy on a new task, RL forgets less than supervised fine-tuning, because sampling from the model keeps it close to the base in KL (raw/arxiv-2509-04259-rl-s-razor-why-online-reinforcement.md, §1, §4, §5; source-rls-razor).
  • 2026-01, no training at all. Sampling the base model from a sharpened distribution, p(answer)^4, with no reward, matches or beats GRPO on HumanEval for two Qwen models; GRPO still leads on MATH500 for all three models tested (raw/arxiv-2601-21590-scalable-power-sampling-unlocking-efficient-training.md, Table 1; source-distribution-sharpening-power-sampling).

The debate: sharpening or new ability?

Contradiction (open), 2026-10-20: source-rl-reasoning-boundary-yue finds RLVR makes right answers more likely on problems the base model could already solve and adds none; source-prorl finds long RL from a distilled 1.5B model reaches problems the start never solved in 256 samples. They differ in the start (a pretrained base against a distilled model), the length (hundreds of steps against over 2,000) and the tasks (maths against puzzles and code). Both agree on maths (raw/arxiv-2504-13837-does-reinforcement-learning-really-incentivize-reasoning.md, §4.4, §4.6, §7; raw/arxiv-2505-24864-prorl-prolonged-reinforcement-learning-expands-reasoning.md, §2.3.1, §4.2). The spurious-reward and power-sampling results lean toward sharpening, for Qwen models on maths. The full argument sits in analysis-emergence-vs-distribution-sharpening.

Two cautions from the sources. Pass@k at k = 1024 measures coverage, not usefulness: nobody samples 1,024 answers without a checker (raw/arxiv-2504-13837-does-reinforcement-learning-really-incentivize-reasoning.md, §2.2). And a claim of RLVR gains should be checked on other model families and against random and format rewards (raw/arxiv-2506-10947-spurious-rewards-rethinking-training-signals-in.md, §1, §7).

Local result

Course module 26 (course/modules/26-rl-with-a-checker/README.md, §2–§3) trains a small char-GPT on 3-digit sums with a checker. GRPO, Dr. GRPO and RLOO lift pass@1 from 59.1% to 94–95%. There is no crossover, but the base already reaches 99.56% at k = 16, so the test had no room to show one. Coin-flip rewards wreck the model (pass@1 4.6% and 2.4%) instead of leaving it alone, unlike Qwen-Math in the spurious-rewards paper; the module records both of these as missed expectations.

Open questions

  • Does the crossover hold for long RL from a raw pretrained model, not a distilled one? Neither paper tests it.
  • Which gains survive on a model family other than Qwen? (raw/arxiv-2506-10947-spurious-rewards-rethinking-training-signals-in.md, §3).
  • Can a checker be built for tasks that lack one? RLSVR's answer is a game; its reward is still a proxy (raw/arxiv-2607-23802-from-rlvr-to-rlsvr-task-transformation-fulltext.md, §2, §4.2; source-rlsvr-spyrl).
