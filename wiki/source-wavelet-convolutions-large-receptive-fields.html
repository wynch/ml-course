Wavelet Convolutions For Large Receptive Fields

source created 2026-05-14 updated 2026-05-14 wavelets convolutional-networks computer-vision receptive-fields robustness efficient-architecture

Finder, Amoyal, Treister, Freifeld — ECCV 2024 / arXiv 2024

This is not a Mallat-authored paper, but it is a recent wavelet-neural architecture paper that fits the same broad direction: use multiscale wavelet structure to give convolutional networks larger effective receptive fields without a large parameter increase.

Main Claim

The proposed wavelet convolution layer can replace depthwise convolutions and scale to large receptive fields with trainable parameters growing only logarithmically with the receptive-field size. The authors report gains in classification and downstream tasks, plus robustness to corruptions and a stronger shape response relative to texture response.

Why It Matters

This paper is a useful counterpoint to pure scattering:

  • scattering uses mostly fixed wavelet filters
  • wavelet convolution keeps a learned network but changes its multiscale operator
  • both challenge the idea that early perception must be learned from unconstrained local kernels

For the wavelet-substrate experiment, this suggests a later comparison: fixed scattering front-end versus lightly trainable wavelet convolution.

Caveat

This is closer to an efficient convolutional-network layer than to a fixed substrate. It should not be mixed into the first benchmark unless the simpler scattering-versus-tiny-network comparison is already working.
