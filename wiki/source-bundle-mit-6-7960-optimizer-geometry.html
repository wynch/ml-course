Synthesis

An optimizer is a rule that turns a gradient into a weight change. The two lectures derive such rules from one recipe. Write the loss near the current weights as its slope term plus a penalty on the size of the step, measured in some norm (a norm is a way to measure the size of a vector or matrix). Then pick the step that minimises that model. Which norm you choose decides which optimizer you get (L7, slides 16–19).

  • Euclidean norm (square root of the sum of squares): plain gradient descent (L7, slide 17).
  • Infinity norm (the largest entry): sign descent, which moves every weight by the same amount in the direction of its gradient's sign (L7, slide 18).
  • Spectral norm on each weight matrix (its largest singular value, the most it can stretch any input vector): a step whose singular values are all set to one, the operation the slides call Shampoo's core and Muon approximates quickly (L23, slides 40–42).

The second point is about scale. A layer's job is to map input vectors to output vectors, so the useful size of a weight matrix, or of a change to it, is how much it can change its output. Measured that way, with a factor for the layer's input and output widths, "a step of size 1" sets the same upper bound on the output change in a narrow and a wide network; it means about the same change only if the bound is tight, which the theory assumes (L23, slide 29). Bernstein's claim is that setting the size of each layer's weights and updates in this norm stops the best learning rate from drifting as the network widens (L7, slides 24–25; L23, slide 30).

The third point is method. Build the optimization theory the way networks are built: give each layer type a norm and two sensitivity numbers, then combine them by fixed rules for layers in series and in parallel. The whole network then has a norm, the "modular norm", in which steepest descent can be computed layer by layer (L23, slides 14–23, 39).

Lecture 7: Scaling Rules for Optimization

Setting. Full-batch training only: no mini-batch noise (L7, slide 6). Loss L(w) is the average of an error ℓ(f(x, w), y) over N examples (L7, slide 4).

Second-order methods. Expand the loss to second order: L(w + Δw) ≈ L(w) + gᵀΔw + ½ ΔwᵀHΔw, with g the gradient and H the Hessian, the d × d matrix of second derivatives, which records how the slope itself changes (L7, slide 10). Minimising gives Newton's step Δw = −H⁻¹g, "pre-condition the gradient with the inverted Hessian" (L7, slide 11; the slide carries a λ that its boxed result drops, see the raw's note). Two problems: it can head for a maximum, which "cubic regularization" fixes, and with d weights H has d² entries, "too expensive even for 'small' networks" (L7, slide 12).

Gauss–Newton. The loss is an error ℓ composed with a network f. The chain and product rules split the Hessian into two terms: one carries the curvature of the error, the other the curvature of the network (L7, slide 13). For square loss the error's curvature is 1; dropping the network's curvature gives Δw = −[(∂f/∂w)ᵀ(∂f/∂w)]⁻¹ g. The lecture leaves two questions: it needs the extra derivatives ∂f/∂w, and "is it safe to ignore curvature of the model?" (L7, slides 14–15).

Steepest descent in a norm. Replace the second-order term by (λ/2)‖Δw‖², a guess at the curvature with sharpness λ (L7, slide 16):

  • Euclidean norm: g + λΔw = 0, so Δw = −g/λ, "vanilla gradient descent" (L7, slide 17).
  • Infinity norm: Δw = −(‖g‖₁/λ) sign(g), "sign gradient descent", where ‖g‖₁ is the sum of the gradient's absolute values; the derivation is left as homework (L7, slide 18).
  • Any norm: the minimiser splits into a step size ‖g‖†/λ and a direction, the unit vector t that maximises gᵀt; ‖·‖† is the dual norm, the largest value gᵀt takes over unit vectors t (L7, slide 19). The step goes in the minus direction (L23, slide 36, writes the minus sign).

Condition: each of these steps is optimal for the model, not for the true loss. It is safe only where the norm and λ make the model an upper bound on the loss; L23 turns this into the question of which norm makes the bound tight (L23, slide 9).

Which norm for a network. "Always ask: in which norm?" A network is built from weight matrices, so try a matrix norm: Frobenius, spectral, nuclear (L7, slide 21). Through the singular value decomposition (SVD), every matrix is a rotation, a per-direction stretch and another rotation (L7, slide 22). The spectral norm, ‖M‖ = max ‖Mv‖₂/‖v‖₂, is the largest stretch, which equals the largest singular value (L7, slide 23; the slide writes it ‖M‖*, a symbol other texts use for the nuclear norm). Measure vectors by their RMS norm, ‖v‖₂/√d, the typical size of one entry. The induced RMS→RMS norm bounds how much a matrix can change the RMS size of its input, and equals √(d_in/d_out) times the spectral norm (L7, slide 24, set as an exercise).

Width. A chart by Keller Jordan shows the best learning rate moving as width goes from 32 to 1024 (L7, slide 25). The claim: for every layer, initialise so that ‖W‖_RMS→RMS ~ 1 and scale updates so that ‖ΔW‖_RMS→RMS ~ 1; the proof is set as homework (L7, slide 25). Under the slide's notation, "~ 1" means the size does not grow or shrink with width; L23 sets the update's size to the learning rate (L23, slide 30).

Depth. A second chart shows deeper networks training worse at every learning rate (L7, slide 26). Since (1 + x/L)ᴸ tends to eˣ as L grows, the slide suggests a residual block x → x + (1/L)·layer(x), with L the number of layers, and marks it "needs more research" (L7, slide 26).

Modules. A module has a forward function, a backward function and a norm on its weights; composition gives forward by composing, backward by the chain rule, and leaves open how to combine the norms (L7, slides 28–30). References: Yang and Hu 2020 (infinite-width feature learning, the source of μP, the "maximal update" parameterization); Bordelon, Chaudhry and Pehlevan 2024; Large et al. 2024, "Scalable Optimization in the Modular Norm"; Streeter 2023 (L7, slide 31; none captured).

Lecture 23: Metrized Deep Learning

From a bound to a norm. Look for a norm and a sharpness λ with L(w + Δw) ≤ L(w) + ∇Lᵀ Δw + ½λ‖Δw‖², holding tightly; then minimise the right side (L23, slide 9). With the Gauss–Newton split, and a norm on the network's output, the curvature term is bounded by two properties of the network in the weight norm: it is "Lipschitz" (the output moves at most δ‖Δw‖² in squared size: ‖∇f Δw‖² ≤ δ‖Δw‖²) and "Lipschitz smooth" (the second-order change is at most α‖Δw‖²) (L23, slides 10–13). So the task is a weight norm that controls the network's own Taylor expansion (L23, slide 13).

Modules, formally. A module has input, weight and output spaces and four attributes: forward, a number "sensitivity", a number "mass" and a norm on its weights. It is well-normed if, with norms on its input and output, a weight change Δw moves the output by at most M.norm(Δw) and an input change Δx moves it by at most sensitivity × ‖Δx‖ (L23, slide 20). Atoms carry hand-declared attributes (Linear, Conv2d, Embed); bonds have no weights (ReLU, attention without weights); compounds are combinations, such as an MLP (L23, slide 18).

Mass sets how much of the total change each part of the network gets: "Feature learning is apportioned by mass" (L23, slide 22). Adding a scalar-multiply module and an add module gives residual blocks, a·Identity + b·M (L23, slide 17). Stated results: combination is associative and keeps well-normedness (L23, slide 22); second-derivative bounds (α, β, γ) also combine by fixed rules, so loss functions are Lipschitz smooth in the modular norm "with non-dimensional Lipschitz constants", "so long as the error measure is smooth in the module output" (L23, slide 24). The proofs are in Large et al. 2024, not in the slides.

Scaling thesis. If each module's constants do not depend on width or depth, and the bounds stay tight at every scale, then controlling M.norm(Δw) controls the output change, and the learning rate transfers (L23, slide 29). The single-layer version: √(fan-in/fan-out)·‖W‖_spectral = 1 and √(fan-in/fan-out)·‖ΔW‖_spectral = learning rate (L23, slide 30, citing Bernstein et al. 2020 and Yang, Simon and Bernstein 2023).

Evidence shown. GPT trained 10k steps on OpenWebText with Adam as the base optimizer. In the "normed Adam modulaGPT" runs, the curves for widths 32–1024 and for 2–64 blocks have their best loss at about the same learning rate; in the plain "Adam nanoGPT" runs the widths blow up at different learning rates. The middle panel, "Adam modulaGPT" (the modular architecture without normed updates), sits between: depth curves roughly line up, widths still diverge at high learning rates (read from the plot). The slide adds, from the paper, that the method "enables training GPT using SGD" and "transfers LR across context length" (L23, slide 34). One chart; no seeds or error bars shown.

Modular duality. "Gradient descent does not type check": the gradient lives in a different space from the weights, so subtracting it from the weights needs a map between them, the duality map, which returns the unit-norm direction that best aligns with the gradient (L23, slides 36–37). Proposal: solve that map for each layer, then combine the layers' maps by the same series and parallel rules (L23, slide 39).

Shampoo and Muon. Under the spectral norm, the duality map of a gradient matrix G is (GGᵀ)^(−1/4) G (GᵀG)^(−1/4), which keeps G's singular vectors and sets every singular value to one; the slide calls this Shampoo's "core primitive", "steepest descent under the spectral norm" (L23, slide 40). In code: compute the SVD G = USVᵀ and return UVᵀ (L23, slide 41). Keller Jordan's NanoGPT speed record uses a "Newton–Schulz" iteration, X ← aX − bXXᵀX + cXXᵀXXᵀX, a fixed polynomial repeated a few times, to approximate this map fast without an SVD (L23, slide 42; the slide does not give a, b, c). The slide's Shampoo algorithm box sums GGᵀ and GᵀG over past steps; the equality with the spectral step holds for one gradient on its own (the wiki's reading of slide 40). His chart, shown on the slide, has the Muon run reaching each validation loss soonest in wall-clock time among Adam, two Shampoo settings and SOAP, at 142 ms per step against Adam's 139 (L23, slide 42). The lecture names Muon only in chart legends. An earlier chart shows record runs reaching the target loss with 2.67B tokens against 10.25B for the llm.c baseline (L23, slide 7). These are speedrun records by a third party, not controlled studies.

Outlook. Robustness and low-precision training are "questions of module sensitivity" (L23, slide 47). Code: Modula, PyTorch and JAX versions (L23, slide 33).

Added 2026-10-23: lecture 13 of the same course names Muon outright. It writes the plain steepest-descent step under the spectral norm as ΔW = −(Tr(Σ)/λ)UVᵀ for G = UΣVᵀ, where Σ holds G's singular values (not a covariance), so that step's size is their sum (slide 2). Slide 3 gives no step-size rule for Muon itself; it lists Muon's extra tricks: momentum, low precision, a fast iteration for UVᵀ (raw/web-2024-mit-6-7960-lec13-architectural-bias-representations.md, slides 2–3; source-bundle-mit-6-7960-representation-learning).

What each component does, and how the maths ties to it

This section is the wiki's reading of the slides.

  • The optimizer step. The norm is the optimizer's assumption about which changes are cheap. Gradient descent treats all weights as one flat vector. The spectral step treats each weight matrix as a map: it changes the matrix's output by the same amount along every input direction the gradient touches, instead of letting the strongest direction take the whole step (L23, slides 40–41).
  • A linear layer. Its spectral norm bounds how much it can stretch an input; the √(fan-in/fan-out) factor converts that to RMS sizes, so the same number bounds the output change by the same amount at any width, and sets it if the bound is tight (L7, slide 24; L23, slides 21, 29).
  • Depth and residual blocks. In series, sensitivities multiply (L23, slide 23), so a deep stack can amplify small changes; the 1/L residual scaling on L7, slide 26 is one tentative way to keep the product bounded.

Ties, the wiki's reading

These links are the wiki's, not the lectures'.

  • Adam is close to sign descent. With β₁ = β₂ = 0 (no running averages) and ε = 0, Adam's step m/√v is g/|g| = sign(g), coordinate by coordinate: steepest descent in the infinity norm (L7, slide 18). concept-softmax-numerics describes the same behaviour: Adam turns tiny gradients into full-size steps unless they fall below ε (raw/arxiv-2610-31642-a-fix-for-softmax-and-cross.md, §4–5). The lectures do not discuss Adam's ε. The slingshot spikes also need β₂ > 0: the running average of squared gradients decays while gradients vanish and lags when they return (same file, §4).
  • Subspace Tuning and the spectral step. source-subspace-tuning found that projecting the gradient before Adam leaks 69% of the change back into protected directions, in a toy test (60 Adam steps, eight fixed examples, Qwen2.5-0.5B), because Adam rescales each coordinate (raw/arxiv-2610-22293-towards-continual-learning-mitigating-forgetting-with.md, §2.2, Appendix B.8). The spectral step UVᵀ keeps the column and row spaces of G, and so does each Newton–Schulz iterate, which is an odd polynomial in G. So if every gradient is projected onto a subspace of input and output directions, a Muon step built from them, momentum included, stays in that subspace in exact arithmetic. Untested; the paper projects the optimizer's final step instead (§2.2), and reports SST combined with Muon on Qwen3-8B (Appendix B.6, Table 4). Two caveats: it holds for the bare update only, since decoupled weight decay moves the weights along W itself, which has components in every direction; and common Muon setups update embeddings and the output head with Adam, so those matrices fall under Adam's behaviour (the wiki's note, not from these sources).

Open questions

  • Does learning-rate transfer hold with mini-batch noise? L7 studies full batch only (L7, slide 6); L23's evidence is one 10k-step GPT sweep (L23, slide 34).
  • How does the depth rule on L7, slide 26 compare with source-neural-depth-scaling, which finds loss falling as about 1/depth in trained LLMs (raw/arxiv-2602-05970-inverse-depth-scaling-from-most-layers.md, §2)? The two are about different things (step scaling against loss scaling); no source joins them.
  • μP is asymptotic and "does not explain its own success at finite width" (source-learning-mechanics, §2.4). The modular norm aims at bounds that are tight at every width (L23, slide 29); the slides show no measure of how tight.
