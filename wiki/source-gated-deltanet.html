Gated DeltaNet

Summary

A linear-attention layer keeps a matrix as its memory and writes each key-value pair into it. Such a matrix can hold only as many clean pairs as it has dimensions; past that, pairs collide and exact recall fails (R, §1).

Two earlier fixes each solve half the problem (R, §1):

  • Gating (Mamba-2). Every step multiplies the whole memory by a learned factor α between 0 and 1. It can wipe memory fast, but it fades every pair equally.
  • Delta rule (DeltaNet). Each step reads what the memory already says for the key and replaces that one value. The update is precise, but it cannot clear old content quickly.

The gated delta rule does both: S_t = S_{t-1} α_t (I − β_t k_t k_tᵀ) + β_t v_t k_tᵀ. With α near 0 it clears memory; with α near 1 it is the plain delta rule (R, §1, §3.1, Eq. 10). Read as learning, the delta rule is one step of gradient descent on ‖S k − v‖² at test time, and α adds weight decay to that step (R, §3.1, Table 1). The paper extends DeltaNet's chunked parallel algorithm so the layer trains fast on GPUs (R, §3.3).

The block follows Llama's layout, with SwiGLU layers between token mixers; q, k and v pass through a short convolution and SiLU, with L2 norm on q and k; the output is normed and gated (R, §3.4). Two hybrids add attention over a 2K sliding window (SWA): H1 is Gated DeltaNet plus SWA; H2 stacks Mamba-2, Gated DeltaNet and SWA (R, §3.4).

Key results

All models: 1.3B parameters, 100B FineWeb-Edu tokens, 4K training context, same recipe (R, §4 Setup).

  • Needle in a haystack (synthetic). Gating helps when the haystack is real text, the delta rule helps when the needle is complex: on the UUID task at 2K, Gated DeltaNet 84.2, DeltaNet 47.0, Mamba-2 47.6. Plain decay hurts long retention: on pass-key retrieval at 8K, Mamba-2 falls to 30.4 while DeltaNet holds 98.8 and Gated DeltaNet 91.8 (R, §3.2, Table 2).
  • Language modelling. Average over eight zero-shot tasks: Gated DeltaNet 55.32, Mamba-2 54.89, DeltaNet 52.14, Transformer++ 52.25; hybrids H1 56.40, H2 56.18 (R, Table 3). The text reports 400M models too, but the v3 table holds only the 1.3B rows (R, §4, Table 3).
  • Real-world retrieval. Pure recurrent models trail the Transformer (average 30.6 for Gated DeltaNet against 37.0); both hybrids pass it (39.0 and 40.1) (R, Table 4). The gap to DeltaNet and Mamba-2 is smaller here than on the synthetic tasks; the authors blame repetition errors in small models without instruction tuning (R, §4).
  • Long context. On 14 LongBench tasks, average 16.6 for Gated DeltaNet, 13.5 for Mamba-2, 11.0 for Transformer++; hybrids 17.8 and 18.4 (R, Table 5).
  • Training speed. About the same as DeltaNet, slightly slower than Mamba-2 (2–3K tokens per second less) on one H100; the SWA hybrids train faster than the pure recurrent layer (R, §4, Figure 3).
  • Ablations (400M, 15B tokens). Removing the short convolution or the output gate hurts; L2 norm on q and k matters more than the choice of activation; head size 128 is the chosen trade-off (R, Appendix B.2, Table S.1). Of four hybrid orders, Mamba-2 then Gated DeltaNet then SWA scores best (R, Table S.2).

Caveats

  • One scale (1.3B, 100B tokens) for the main tables; the hybrids use a 2K window, half the 4K training length (R, §4).
  • Length extrapolation to 20K is "mixed"; Gated DeltaNet has the lowest perplexity among recurrent models only "overall" (R, §4, Figure 2).
  • The Transformer++ baseline scores lowest on LongBench (11.0), below every recurrent model, which is worth keeping in mind when reading the gains (R, Table 5).
