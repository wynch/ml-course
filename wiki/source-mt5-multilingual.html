mT5 — Multilingual T5

source created 2026-05-07 updated 2026-05-07 multilingual transformer pretraining t5 2020

Xue, Constant, Roberts, Kale, Al-Rfou, Siddhant, Barua, Raffel — arXiv 2010.11934, NAACL 2021 (Google Research)

The multilingual counterpart to T5. mT5 pretrains a single text-to-text transformer on mC4, a Common Crawl–derived corpus spanning 101 languages, using the same span-corruption objective as the original T5. The same architecture and code work across all languages; the surprise was how evenly multilingual training scales when the recipe is right.

Method

  • Architecture: T5 encoder–decoder transformer, sizes Small (300M) through XXL (13B).
  • Pretraining objective: span corruption — mask contiguous spans of input tokens, ask the decoder to emit them as <sentinel> predictions. No language ID prompts; the model figures out the language from context.
  • Vocabulary: SentencePiece with 250k tokens, trained on a temperature-sampled mix of mC4 — α=0.3 sampling preferred high-resource languages somewhat but kept low-resource representation viable.
  • mC4: filtered Common Crawl, ~6T tokens across 101 languages, with quality filters per language.
  • Crucial detail: no parallel data, no translation pairs — monolingual data in each language plus a shared model.

Key numbers

  • mT5-XXL (13B) is competitive with or beats mBERT, XLM-R, mBART on XTREME (40-language understanding benchmark), XQuAD, MLQA, TyDiQA, PAWS-X, XNLI.
  • Cross-lingual transfer: train on English task data, evaluate in 40 other languages — gains scale smoothly with model size.
  • Low-resource gains: languages with <100M tokens benefit disproportionately from shared parameters with high-resource neighbours.

Why it matters

mT5 is the canonical evidence that a single transformer can be a competent multilingual model without language-specific architectures, adapters, or translation pivots. Three durable contributions:

  1. Span corruption + a shared vocabulary is enough. No fancy alignment objectives, no parallel data, no language tags — the model learns cross-lingual representations purely from co-occurrence patterns in monolingual data, distributed across a shared embedding space. This validated the "just scale a clean recipe" hypothesis for multilinguality.
  2. The temperature-α sampling tradeoff is real. α=1 (proportional to corpus size) overfits to English; α=0 (uniform) wastes capacity on tiny languages; α≈0.3 is the empirical sweet spot. Every subsequent multilingual model — XLM-R, BLOOM, Aya, Llama-3 — wrestles with this same tradeoff.
  3. Established the "one model, all languages" deployment pattern. Modern frontier LLMs (Llama-3, GPT-4, Claude, Gemini) are all spiritually mT5-style: one model, multilingual by construction, no language-specific endpoints.

Sits in the concept-multimodal orbit through a stretched-definition reading: multilinguality is modal in the sense that different languages have different distributions, scripts, syntax, morphology, and the model must learn a shared substrate beneath them. The "shared latent for diverse modalities" intuition that drives CLIP (source-clip-radford), Whisper (source-whisper), and the JEPA family (source-ijepa-self-supervised-learning, source-vjepa-family) has its text-only multilingual counterpart in mT5.

mT5 also sets up the multilingual embedding question that source-bge-m3-embeddings later answers: if mT5 shows multilingual generation works, BGE-M3 shows multilingual retrieval works in a unified embedding space — closing the loop on the multilingual stack from pretraining (mT5) through retrieval (BGE-M3) to generation (modern LLMs).

Practical legacy: still one of the cheaper open multilingual encoder-decoders to fine-tune, and a common ancestor of FLAN-T5, ByT5, UL2, and Aya-101.
