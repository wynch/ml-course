Toolformer

source created 2026-04-13 updated 2026-04-13 agents tool-use self-supervised

Schick, Dwivedi-Yu, Dessì, Raileanu, Lomeli, Zettlemoyer, Cancedda, Scialom — NeurIPS 2023 (arXiv 2302.04761)

Self-supervised procedure where an LM inserts API calls into its own training data (calculator, QA, search, translate, calendar), keeping only calls that reduce perplexity on the continuation. Result: a model that invokes five symbolic tools inline during decoding, without human labels for when to call them.

Neural↔symbolic bridge

Each tool is a small symbolic oracle; the model learns when to hand off. The harness is minimal — a template [TOOL(args) -> result] — but the framing makes explicit that certain computations (arithmetic, dates, facts) should never be done in the neural weights. The model teaches itself the division of labor.
