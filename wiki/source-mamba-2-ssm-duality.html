Mamba-2 / Structured State Space Duality

source created 2026-05-06 updated 2026-05-06 state-space-models ssm attention architecture theory unification 2024

Tri Dao, Albert Gu — arXiv 2405.21060, ICML 2024 (Princeton / CMU)

The architectural unification paper. Establishes a structured state space duality (SSD) showing that a broad class of SSMs and a broad class of (structured) attention mechanisms are the same algorithm viewed two ways: a linear recurrence ↔ a structured matrix multiplication (a semiseparable matrix mixer). From this duality the authors derive Mamba-2, a redesign that is simpler, faster, and trains 2–8× more efficiently than source-mamba-ssm.

The duality, in one line

Any SSM with a scalar (per-channel) state transition can be written as Y = M · X where M is a 1-semiseparable matrix; this same matrix family arises as the kernel of masked, structured-decay linear attention. Two computational forms:

  • Linear/recurrent form: O(N) time, O(d_state) memory — the SSM view.
  • Quadratic/matmul form: O(N²) time but pure matmul on tensor cores — the attention view.

Training switches between them based on what's faster (matmul wins for short seqs, scan wins for long). Inference uses the recurrence.

Mamba-2 architecture changes

  • State expansion factor 8× (vs. 2× in Mamba-1): the duality makes large states cheap because the matmul form parallelises trivially.
  • Multi-input SSM (analogous to multi-head attention): split channels into heads sharing A, B, C structure.
  • Parallel projections of A, B, C, X (instead of sequential), enabling tensor-parallel training.
  • Drops the 1D conv at the input (subsumed by larger state) in some configs.
  • 2–8× faster training than Mamba-1 at matched quality, while being more interpretable as "linear attention with structured decay".

Key results

  • Mamba-2 matches or beats Mamba-1 and same-size transformers at 125M–2.7B.
  • Pure SSD blocks compete with attention; hybrids (a few attention layers + many SSD layers) consistently win at moderate scale.
  • The framework subsumes prior linear attentions (Linear Attention, RetNet, GLA) as special cases.

Why it matters

This is the architectural equivalent of "source-attention-is-all-you-need but for the linear-time camp": it makes attention and SSMs into one parameterised family rather than rival paradigms. Practical consequence: any future improvement (better state structure, better decay, better selectivity) can be expressed in the language of either view, and the whole community shares one set of tooling.

It also directly informs the hybrid debate. source-olmo-hybrid-rnn-transformer (Allen AI) and many subsequent designs include some attention layers because Mamba/SSD's structured mixing matrix lacks the unconstrained content addressing of full attention — but having the duality means the mix is a continuum, not a fork. Compare with source-ttt-kv-binding-linear-attention (TTT ≡ linear attention from a different angle) and source-m2rnn-matrix-valued-states (a sibling line that lifts state to a matrix and adds non-linear transitions).
