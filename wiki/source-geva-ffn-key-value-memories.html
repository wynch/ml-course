Transformer Feed-Forward Layers Are Key-Value Memories

source created 2026-05-06 updated 2026-10-09 interpretability ffn key-value-memory transformers foundational

Geva, Schuster, Berant, Levy — EMNLP 2021 (arXiv 2012.14913, December 2020).

The paper that gave the field its working mental model for what FFN layers actually do. Two-thirds of a transformer's parameters live in FFN blocks, and before this paper there was no agreed-upon story about them; attention got all the analytical attention.

The claim

A transformer FFN of the form out = W_V · σ(W_K · x) is reinterpretable as a key-value memory:

  • The first matrix W_K is a stack of keys. Each row is a pattern detector: it produces a high inner product with residual-stream vectors that represent specific textual patterns.
  • σ(·) (typically GeLU/ReLU) gates which keys fire.
  • The second matrix W_V is a stack of values. Each column is a distribution over output tokens — "if key i fires, push the residual stream toward this distribution over the vocabulary."

A single FFN neuron is therefore a (pattern → output distribution) memory cell, and the FFN as a whole is a learned associative memory that retrieves and composes thousands of these cells per forward pass.

Empirical findings

The authors instrument trained transformer LMs (specifically 16-layer LMs in the WikiText-103 / GPT-2-style regime) and inspect individual FFN neurons:

  • Keys are interpretable patterns. For most neurons, top-activating training examples share recognisable structure.
  • Lower layers detect shallow / surface patterns — n-grams, specific tokens, simple syntax.
  • Upper layers detect deeper semantic patterns — topical, semantic, sometimes task-relevant patterns.
  • Values point toward likely next tokens that match what historically followed the key's pattern. The value distribution becomes increasingly aligned with the actual output vocabulary in later layers.
  • Composition. The output of a single FFN block is a sum of per-neuron contributions. Across layers, the residual stream accumulates these contributions and refines its prediction; intermediate predictions shift toward the final answer in a roughly monotonic way.

Why it matters

This is the foundational source for the "FFN as memory" thread that runs through:

  • Localising and editing knowledge. source-rome-memit-factual-editing (ROME / MEMIT) takes Geva's frame literally — if FFN neurons store facts, you can edit a fact with a rank-one update to a specific neuron's value vector. Without "FFNs are key-value stores," ROME is unmotivated.
  • Modern FFN-as-retrieval. source-memoryllm-plug-n-play-ffn and the broader retrieval-augmented FFN line treat the value matrix as a swappable knowledge index — directly Geva's frame, productionised.
  • SAE motivation. SAEs (source-sae-monosemanticity-2023, source-sae-monosemanticity-2023) inherit the assumption that FFN neurons (or residual-stream directions) have semantic content worth decomposing. Geva is part of why people believed that in the first place.
  • Architecture choices. Engram (source-engram-deepseek), MoE-as-memory variants, and "U-shaped MoE/memory" laws all treat FFNs as retrieval rather than computation — same lineage.

Tensions and refinements

  • Polysemanticity. Geva treats neurons as roughly monosemantic. source-anthropic-mi-foundations shows this is approximate at best; superposition crams many features into the same neuron. SAEs were the field's response.
  • Distributional vs. localist reading. Geva supports a relatively localist view (per-neuron pattern, per-neuron output). The circuits programme has since moved toward viewing features as directions, not neurons — but the function (key-detect, value-write) survives the reframing.

Neural↔symbolic bridge

Reframes the FFN — ostensibly the most "neural" component of the transformer — as a fundamentally symbolic retrieval operation: detect a pattern, look up an associated distribution, write it to the residual stream. This is the wiki's neural-symbolic thesis (concept-neural-symbolic-bridge) being articulated inside the network: the symbolic substrate is not added by a harness, it's already there in W_V.

Later use

source-memory-mosaics-at-scale takes this reading as a design rule: its feed-forward block is the "persistent memory" for knowledge from training, beside two associative memories for the prompt. It cites Sukhbaatar et al. (2019) for the two being interchangeable (raw/arxiv-2507-03285-memory-mosaics-at-scale.md, §3.3, footnote 8).
