Qwen-VL — Open-Weight VLM with Strong OCR and Grounding

source created 2026-05-06 updated 2026-05-06 multimodal vision-language qwen alibaba ocr grounding

Bai, Bai, Yang, Wang, Tan, Wang, Lin, Zhou, Zhou (Alibaba) — arXiv 2308.12966, August 2023

Alibaba's first open-weight vision-language model, sitting between LLaVA's minimum-viable recipe and GPT-4V's closed-frontier capability. Qwen-VL emphasises three things LLaVA-1 explicitly skips: OCR / text reading, visual grounding (bounding-box outputs), and multilingual (English + Chinese) support out of the box. Comes in two flavours: base Qwen-VL and the chat-tuned Qwen-VL-Chat.

Architecture

Three modules stacked on a Qwen-7B language backbone:

  1. Visual receptor — ViT initialised from OpenCLIP's ViT-bigG, plus a position-aware vision-language adapter (single-layer cross-attention with learned queries, similar to BLIP-2's Q-Former) that compresses visual features to a fixed length of 256 tokens for the LLM.
  2. Input/output interface — special tokens delimit image regions, bounding boxes, and text spans. Images, text, and box coordinates are interleaved in a unified sequence so the model can both consume and emit spatial coordinates.
  3. Language model — Qwen-7B (Alibaba's open Chinese-English LLM).

Three-stage training pipeline

  1. Pretraining — frozen LLM, only ViT + adapter trained on 1.4B image-text pairs (English + Chinese) cleaned and deduplicated.
  2. Multi-task pretraining — ViT + adapter + LLM jointly trained on 7 task types: captioning, VQA, grounded captioning, referring-expression grounding, OCR, pure text, image-text interleaved.
  3. Supervised fine-tuning → Qwen-VL-Chat. Instruction-tuning with multimodal dialogue.

The grounding capability is achieved by embedding (x1,y1,x2,y2) tuples directly in the token stream as text — a clean reuse of the RT-2-style "actions/coords as tokens" trick.

Results

Sets new open-weight records (at release time) on captioning (Flickr30k, Nocaps), VQA (VQAv2, OK-VQA), referring expression comprehension (RefCOCO), and document/text VQA — the OCR-heavy benchmarks where LLaVA struggled. Beats Flamingo-9B and OpenFlamingo-9B on most few-shot settings.

Significance

Qwen-VL is the canonical "open-weight Asian-frontier" datapoint and the reference for any open VLM that needs to read text in images or return bounding boxes. The 256-token compressed adapter sits between Flamingo's heavy gated cross-attention and LLaVA's identity-shaped linear projection — a useful mid-point in the concept-multimodal adapter-simplification axis. The unified-token treatment of bounding boxes generalises into the modern coords-as-tokens / actions-as-tokens pattern that runs through RT-2, OpenVLA, and π0.
