Self-Revising Discovery Systems for Science

source created 2026-07-04 updated 2026-07-04 ai-agents scientific-discovery category-theory neural-symbolic self-improvement materials-science

Authors: Fiona Y. Wang, Markus J. Buehler / Date: 2026-05-31 / arXiv: 2606.01444 [cs.AI]

Summary

Wang and Buehler argue that scientific discovery is categorically different from answer generation: it requires revising the representational regime in which evidence, artifacts, operations, and verifiers are typed, not just searching within a fixed vocabulary. They formalize this with category theory. System state is a copresheaf I_t: S_b -> Set over a schema category S_b (the artifact types and admissible operations of the current "discovery regime"); realized provenance is the category of elements ∫ I_t (a typed artifact DAG). A discovery is a verified regime transition u: S_b -> S_b', where old artifacts are transported into the new vocabulary by a left Kan extension Lan_u I_t, and whatever falls outside the image of the comparison map is exactly the genuinely new empirical content the system had to acquire beyond mere functorial reinterpretation. This makes the distinction between retrieval, search, and discovery precise and, crucially, auditable.

The framework is instantiated in two working systems. Builder/Breaker revises symbolic protein-mechanics models: a Breaker selects stress-test proteins to expose failures, a Builder proposes DAG edits, and a Minimum Description Length (MDL) gate accepts a revision only when it shortens the combined description length of model plus evidence. Across 388 proposals only 25 survive (6.4%); the final regime transition costs 10.3 bits of model code but yields a 54.3-bit MDL gain, discovering a mode-conditioned-compliance law that requires the schema to admit a new product operation, not just a new instance. CategoryScienceClaw wraps an execution substrate (ScienceClaw: typed skills, immutable lineage-carrying artifacts, workflow mutation) plus a discourse layer (Infinite) into a proof-carrying knowledge-computation graph, demonstrated on fiber-network mechanics where an anisotropic stiffness surrogate beats an isotropic baseline by ΔAIC = 123.87 while the rejected model is preserved as an audit object.

Category theory is positioned as both a mathematical language and an engineering specification: verifiers, provenance auditing, and progress metrics all follow from typing the regime explicitly. The core polemic is that "scaling a fixed model is qualitatively different from building a system that can construct new representational commitments" — an argument that automated discovery must change its own ontology, not merely recombine within it.

Key Ideas

  • Discovery = verified regime transition (change the schema/vocabulary), distinct from retrieval (add expressible artifacts) and search (recombine within a fixed vocabulary).
  • Copresheaf I_t: S_b -> Set separates what types exist from what instances populate them; provenance recovered as the category of elements ∫ I_t.
  • Left Kan extension Lan_u I_t transports old artifacts across a transition; empty comma categories mark types with genuinely new empirical content. Novelty becomes a measurable Kan obstruction — the residual beyond the transported image — an objective criterion for "did the system actually discover something?", addressing the open-endedness evaluation problem without subjective judging.
  • MDL / AIC gates make revisions accountable: accept only when combined description length drops (protein case) or ΔAIC > 0 with passing diagnostics (fiber case); rejected models retained for audit.
  • Two instantiations — Builder/Breaker (protein mechanics; 25/388 proposals survive; +54.3-bit gain) and CategoryScienceClaw (fiber networks; ΔAIC = 123.87).
