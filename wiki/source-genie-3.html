Genie 3

Summary

Genie 3 is DeepMind's third "foundation world model": from a text prompt it generates a world a user can move through in real time, at 24 frames per second and 720p, staying consistent "for a few minutes" (R, opening). DeepMind calls it its first world model to allow real-time interaction, and says it improves on Genie 2's consistency and realism (R, "Towards world simulation").

It builds each frame in turn ("auto-regressive generation"), looking back over the whole path so far; returning to a place after a minute means recalling what was generated a minute ago, several times per second (R, "Pushing the frontier of real-time capabilities").

Key claims

  • Memory. Worlds "remain largely consistent for several minutes, with visual memory extending as far back as one minute ago" (R, "Environmental consistency over a long horizon").
  • Consistency is learned, not built in. DeepMind calls it "an emergent capability": unlike NeRFs or Gaussian splatting, there is no explicit 3D model (same section).
  • Promptable world events. Text can change a running world, such as the weather or a new character, which gives agents "what if" cases to learn from (R, "Promptable world events").
  • Agents inside it. A recent version of the SIMA agent pursued goals inside Genie 3 worlds by sending navigation actions; Genie 3 does not see the goal, only the actions (R, "Fueling embodied agent research").
  • Limits, by DeepMind's own list: few actions an agent can take directly; poor modelling of several agents together; real places not geographically accurate; legible text mostly when the prompt gives it; a few minutes of interaction, not hours (R, "Limitations").
  • Access: a limited research preview for "a small cohort of academics and creators" at launch (R, "Responsibility").

Caveats

  • A blog post, not a paper: no architecture, size, training data, compute or benchmark numbers. The wiki cannot say how Genie 3 differs from Genie 2 inside.
  • Every result is a chosen video or demo; consistency "for a few minutes" has no measure behind it in the post.
  • Not in raw: the public launch as "Project Genie" for US Google AI Ultra subscribers on 2026-01-29, with 60-second sessions (press reports). The captured page links to it.
