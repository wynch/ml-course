Self-Refine: Iterative Refinement with Self-Feedback

source created 2026-05-06 updated 2026-05-18 reasoning self-improvement scaffolding test-time-compute 2023 neurips

Madaan, Tandon, Gupta, Hallinan, Gao, Wiegreffe, Alon, Dziri, Prabhumoye, Yang, Welleck, Majumder, Gupta, Yazdanbakhsh, Clark — arXiv 2303.17651, March 2023 (NeurIPS 2023)

Same LLM plays three roles in a single inference loop: generator → feedback giver → refiner, repeating until a stopping condition. No supervised data, no extra model, no training — and yet on average it adds ~20 absolute percentage points across 7 diverse tasks. The minimal viable scaffold.

Method

The loop, in plain prose:

  1. The LLM produces an initial answer to the task prompt.
  2. The same LLM is re-prompted with the answer and asked to critique it (specific feedback: "the explanation is unclear here," "the code mishandles edge case X").
  3. The LLM is re-prompted with the original input + previous answer + feedback, and produces a refined answer.
  4. Repeat until self-feedback says "good enough" or a max-iteration budget is hit.

Crucially, prompts for the three roles are different, but the model is the same — the structure is purely in how the inference loop is wired.

Key numbers

  • Tested on 7 tasks spanning dialog response, code optimisation, code readability, math reasoning, sentiment reversal, acronym generation, constrained generation.
  • Average improvement: ~+20 absolute percentage points over single-shot baselines.
  • Tested on GPT-3.5, ChatGPT, GPT-4 — gains hold for the strongest model, refuting "this is just patching weak base models."
  • Outputs preferred by both human evaluators and automatic metrics across all task types.

Why it matters

Self-Refine is the simplest member of the 2023 scaffolding family — strictly less expressive than source-tree-of-thoughts (no branching) and source-reflexion-verbal-rl (no episodic memory across attempts), yet competitive on many tasks. That's the punchline: a huge amount of headroom is reachable by just asking the model to look at its own output and try again.

The paper anchors three threads in this wiki:

  • concept-test-time-compute — the canonical "spend more tokens, get better answers" instance after source-chain-of-thought-foundations and source-chain-of-thought-foundations.
  • concept-self-improvement — predates the gradient-free self-improvement work (source-sdpo-self-distillation-rl, source-randopt-gaussian-noise-llms).
  • concept-llm-reasoning — fuels the debate: if the model can already produce the right answer in iteration 3, why didn't it produce it in iteration 1? Either feedback is genuinely informative, or the model was capable but undersampled — the same question source-distribution-sharpening-power-sampling formalises as latent-distribution sharpening.

Self-Refine + source-reflexion-verbal-rl differ mainly in temporal scope: Self-Refine refines within a single attempt; Reflexion accumulates lessons across episodes. Tree-of-Thoughts (source-tree-of-thoughts) adds a branching topology. Together the three define the canonical 2023 scaffolding triad and seeded everything in concept-harness-as-symbolic-substrate that followed.
