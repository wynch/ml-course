Long Context

concept created 2026-04-05 updated 2026-10-09 context-window memory long-context scaling

Approaches to handling inputs that exceed or stress model context windows — a key bottleneck for practical LLM applications.

Approaches

  • source-recursive-language-models — recursive decomposition enables 100x beyond native context. Model calls itself on sub-segments.
  • source-lcm-lossless-context-management — deterministic, lossless context management outperforms Claude Code at all context lengths (32K-1M).
  • source-m2rnn-matrix-valued-states — recurrent approaches with superior long-context performance on LongBench.
  • source-memory-mosaics-at-scale — associative memories with no position encoding. Trained at 4k, the large model scores 59.3, 48.8 and 46.4 on RULER multi-document questions at 4k, 8k and 16k with no fine-tuning; the transformer gets no score past 4k. Fine-tuned at 32k: 53.4 against 41.1 (raw/arxiv-2507-03285-memory-mosaics-at-scale.md, §5.2, Tables 3-4). The paper calls the plain needle-in-a-haystack test too easy: every model scores 97.8 or more (same file, Appendix G, Table 13).
  • source-zhang-harness-blog — train on short tasks, generalize to long ones: an RLM trained with RL on short splits improves on splits 8–32× longer (MRCRv2 up to 2M tokens); the same model trained as a Transformer with YaRN stays flat (raw/web-2026-alexzhang-harness-compositional.md, §"RLMs can train on short tasks and generalize to longer, unseen tasks").

Key Insight

source-lcm-lossless-context-management frames itself as a vindication of recursive context manipulation — it outperforms systems with native file-system access, suggesting that structured context management matters more than raw context length.

source-zhang-harness-blog gives a reason: an append-only context drifts out of the training distribution ("context rot"), while an offloaded one keeps each call in-distribution. It also notes that production models spend much mid- and post-training on ever longer data, and applications still outgrow it (raw/web-2026-alexzhang-harness-compositional.md, §"The capacity for compositional generalization can live in the harness"; §"RLMs can train on short tasks…").
