MLEvolve

source created 2026-07-04 updated 2026-07-04 self-improvement evolutionary ai-agents coding-agents graph-search memory

Authors: Shangheng Du, Xiangchao Yan, Jinxin Shi, Zongsheng Cao, Shiyang Feng, Zichen Liang, Boyuan Sun, Tianshuo Peng, Yifan Zhou, Xin Li, Jie Zhou, Liang He, Bo Zhang, Lei Bai (InternScience) / Date: 2026-06-04 / arXiv: 2606.06473

Summary

MLEvolve is an LLM-driven evolutionary framework for long-horizon machine-learning-engineering (MLE) algorithm discovery — the AlphaEvolve/FunSearch lineage, but built to sustain self-evolution across extended optimization horizons. The authors diagnose three failure modes in prior evolutionary code search: information compartmentalized across search branches, stateless (memoryless) exploration, and no hierarchical governance over which changes to attempt. MLEvolve addresses each with a distinct mechanism.

The core structural move is Progressive MCGS (Monte-Carlo Graph Search): instead of a strict evolutionary tree, MLEvolve adds reference edges that turn the search into a directed graph, letting knowledge flow across branches, and uses an entropy-inspired schedule to shift progressively from exploration to exploitation. On top of this sits a Retrospective Memory — a static cold-start domain knowledge base fused with a dynamic global memory that auto-accumulates and retrieves task-specific experience. Finally, it decouples strategic planning (what/why to modify) from coding (how), adaptively picking among three coding modes based on search state for stability over long runs.

Reported results: state-of-the-art average medal rate and valid-submission rate on MLE-Bench within 12 hours (half the standard runtime), and it beats source-alphaevolve on mathematical algorithm-optimization tasks. Flagged by Robert T. Lange (Sakana AI, author of ShinkaEvolve / The AI Scientist).

Key Ideas

  • Graph, not tree. Reference edges create cross-branch knowledge flow — a departure from the archive-database and single-tree structures of prior evolutionary search.
  • Progressive explore→exploit via an entropy-inspired schedule inside Monte-Carlo Graph Search.
  • Self-evolving memory. Cold-start domain KB + dynamic global memory that accumulates and retrieves task experience — contrasted explicitly with "archive databases or memoryless search."
  • Plan/code decoupling with three adaptively-selected coding modes, for stability over long horizons.
  • Efficiency. SOTA on MLE-Bench in 50% of standard runtime; outperforms AlphaEvolve on math-algorithm tasks.
