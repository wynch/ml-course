Test-Time Compute Through the Wiki

thread created 2026-05-07 updated 2026-10-03 thread test-time-compute reasoning inference cross-cutting

A cross-cutting trace of one of the wiki's strongest threads: the idea that spending compute at inference time can substitute for training-time compute has gone from a prompting trick (2022) to a frontier-model architecture (2024–25) to a unifying theoretical claim (2026). This page walks the thread chronologically.

2022 — Prompting tricks reveal latent capability

source-chain-of-thought-foundations (Wei + Wang, both 2022).

  • Wei's CoT: prompt the model to show its work. GSM8K 17.9% → 56.9% on PaLM 540B. No training change.
  • Wang's Self-Consistency: sample N CoTs and majority-vote. Same model, same prompt. GSM8K → 74.4%.

The seed observation: more inference tokens = more capability. Reasoning is a property of the distribution, not of any single trace.

2023 — Search and self-feedback scaffolds

source-tree-of-thoughts (Yao 2023). BFS/DFS over self-evaluated thoughts. Game of 24: 4% → 74%.

source-reflexion-verbal-rl (Shinn 2023). Verbal RL: agent reflects on task feedback into an episodic memory buffer. 91% pass@1 HumanEval vs GPT-4's 80%.

source-self-refine (Madaan 2023). Iterative self-critique + self-improvement loop with no extra training. +20% absolute across 7 tasks.

Common shape: spend more compute at inference time on structured deliberation. The "training-vs-inference compute" trade-off becomes a research direction.

2024 — Test-time compute scales

source-snell-test-time-compute-scaling (Snell 2024). The empirical paper: scaling test-time compute can be more compute-efficient than scaling parameters for many problems. Maps the trade-off explicitly.

source-pdr-rethinking-thinking-tokens (Parallel-Distill-Refine, 2024). Generate diverse drafts → distill into bounded workspace → refine. +11% on AIME 2024.

source-recursive-language-models — recursive self-calls extend context 100x at inference time. Architectural variant of the same bet.

2024 — Productionised reasoning models

source-openai-o1-system-card (Sep 2024). Hidden chain-of-thought + RL-trained reasoning + deliberative alignment. The first frontier model where test-time compute is the product, not a clever trick.

This is the inflection: every later frontier reasoning release (o3, R1, Gemini Thinking, Claude Extended Thinking) is some variation of this pattern.

2025 — Pure-RL elicits reasoning

source-deepseek-r1 (Jan 2025). Pure RL post-training (GRPO) elicits o1-style reasoning. The R1-Zero variant skips SFT entirely — base model + RL alone produces frontier reasoning.

If R1-Zero works, the reasoning capability was already latent in the base model. RL surfaces it; it doesn't install it.

2026 — The unifying theoretical claim

source-distribution-sharpening-power-sampling (2026). Inference-time power sampling matches GRPO post-training on math/code/QA. The headline framing: RL is "just" distribution sharpening — and inference-time methods can substitute for it.

If this is right, the entire 2022–2025 thread is one phenomenon — distribution sharpening — surfacing under different mechanisms (sampling, search, RL, verifier-guided decoding).

See analysis-emergence-vs-distribution-sharpening for the full synthesis.

Side branches

  • source-ttt-kv-binding-linear-attention — test-time training with KV binding ≡ linear attention. The architecture-vs-inference boundary is fuzzier than it looked.
  • source-language-models-as-scaffolds — the thesis paper: scaffolding existing models > pure scaling. Lives at the same junction.
  • source-zhang-harness-blog — the sequel moves the scaffold into training: RL through an RLM harness teaches a strategy that transfers to 8–32× longer tasks and new domains (raw/web-2026-alexzhang-harness-compositional.md, §"RLMs can train on short tasks…"). One partial answer to the question below: some of what is "not latent" may be reachable by recomposing what is.
  • source-claude-code-sandboxing + source-rap-reasoning-planning + source-lats-tree-search-agents — agent-level test-time compute (the harness pays for deliberation).
  • source-pause-tokens (2023) — the earliest latent branch: blank <pause> tokens give the model extra positions to compute in before it answers; the gain needs pause-pretraining (raw/arxiv-2310-02226-think-before-you-speak-pause-tokens.md, §4.3).
  • source-coconut-continuous-latent-reasoning (2024) — the model reasons in its own hidden states instead of words; written chains still teach it, stage by stage (raw/arxiv-2412-06769-coconut-reason-in-continuous-latent-space.md, §3).
  • source-recurrent-depth-latent-reasoning (2025) — test-time compute as more loops of one block, pretrained at 3.5B parameters; no written reasoning at train or test time (raw/arxiv-2502-05171-recurrent-depth-latent-reasoning.md, §2, §5).
  • source-soft-tokens-hard-truths (2025) — continuous chains trained by RL instead of written examples; at test time the model still writes normal tokens (raw/arxiv-2509-19170-soft-tokens-hard-truths.md, §4).
  • source-abstract-token-curriculum — test-time compute as latent passes rather than text: continuous thoughts learned from answers alone; the latest thought carries the state (raw/arxiv-2609-19717-learn-your-own-thoughts-abstract-token-curriculum.md, §6.2, §6.4).
  • source-continuous-cot-two-regimes (2026) — continuous chains that compress a written one work on short structured maths and fail on realistic chains of hundreds of tokens (raw/arxiv-2607-16972-continuous-cot-tale-of-two-regimes.md, §4.5).
  • source-loopcd-decoding-looped-transformers (2026) — a decoding rule for looped models: push the last loop's guess away from the first loop's. No training; at half the loops it matches full depth on multiple choice for 22.5% to 48.2% fewer FLOPs (raw/arxiv-2610-02185-decoding-looped-transformers-better-for-almost.md, §4.3).
  • source-randopt-gaussian-noise-llms — even simpler than distribution sharpening: noise + ensembling matches GRPO. Same family.

The big question this thread leaves open

Test-time compute is bounded by what's latent in the base model. What's NOT in the latent distribution that more training (or genuinely-new RL) would add?

source-arc-agi-3 (<1% frontier model performance on novel interactive reasoning) is the strongest current counter-evidence to the "test-time compute is enough" position. If sharpening could reach there, the curve would already be smoother.

This is the heart of analysis-emergence-vs-distribution-sharpening and one of the most consequential open debates in the field.
