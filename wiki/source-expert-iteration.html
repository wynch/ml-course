Expert Iteration (ExIt): search teaches the network, the network guides search

source created 2026-10-23 updated 2026-10-23 reinforcement-learning tree-search mcts imitation-learning policy-improvement games hex 2017

Authors: Thomas Anthony, Zheng Tian, David Barber (University College London) Published: arXiv 1705.08439, v1 2017-05-23, v4 2017-12-03 Raw copy: raw/arxiv-1705-08439-thinking-fast-and-slow-with-deep.md (full text of v4 from the arXiv HTML; cited as R, with its section)

Terms

  • Expert and apprentice. The expert is a slow tree search that looks ahead with the exact game rules; the apprentice is a fast neural network that picks moves without lookahead (R, §1, §3.1). The authors liken them to slow and fast thinking.
  • MCTS (Monte Carlo tree search). A search that runs many simulated games from the current position, grows a tree toward promising moves, and plays the most visited move (R, §4.1).
  • Imitation learning. Training a network to copy an expert's choices (R, §2.2).
  • Tree-policy target (TPT). Instead of copying only the move the search picked, the network copies the share of simulations the search gave each move, n(s,a)/n(s). Close calls are then penalised less than clear mistakes, which the authors call cost-sensitive (R, §4.2).

The claim, plainly

Split learning a game into two jobs: a tree search finds strong moves from each position, and a network learns to imitate those moves across all positions. Then use the improved network to guide the next round of search, so search and network improve each other; this learns faster and more stably than policy-gradient RL and, on 9×9 Hex, beats the strongest public program (R, Abstract, §3, §6).

How it works

Each iteration (R, §3, Algorithm 1):

  1. The apprentice plays itself to produce positions.
  2. The expert searches each position; its result becomes the training target.
  3. A new apprentice is trained on those targets.
  4. The expert is rebuilt with the new apprentice inside it.

The apprentice helps the search in two ways: its move probabilities bias which branches the search explores (a bonus added to the selection formula), and a value head estimates who is winning, so the search needs fewer random playouts (R, §5.1, §5.2). The online version keeps all earlier data instead of starting each round afresh; removing the expert-improvement step from it gives DAgger, a standard imitation-learning method (R, §3.3).

Targets, precisely: the policy head learns the search's visit shares (TPT). The value head learns the game result of games the apprentice plays, not a search value, because enough expert games for a value target were too costly (R, §5.2).

Key results

All on 9×9 Hex (R, §4.1).

  • The soft target helps. TPT and copying only the chosen move predict the search's move about equally well (top-1 error 47.7% and 47.0%), but the TPT network plays 50 ± 13 Elo stronger (R, §4.3).
  • The network makes search stronger. MCTS guided by the policy network wins 97% of games against plain MCTS, at twice the time per move; doubling plain MCTS's simulations wins only 56% (R, §5.1).
  • Faster and steadier than policy gradient. Starting from the same network, ExIt reaches higher Elo sooner than REINFORCE as used for AlphaGo's policy network, over 5 runs each, with little run-to-run variation; the online version beats the batch version (R, §6.1, Figure 2).
  • A value head adds more. Policy-and-value ExIt clearly beats policy-only ExIt run for the same time (R, §6.2, Figure 3).
  • Against MoHex 1.0, the strongest publicly released Hex program, ExIt with 10,000 simulations per move wins 75.3% against MoHex at 10,000 simulations, 59.3% at 100,000, and 55.6% at 4 seconds per move with its solver on (R, §6.3). MoHex runs about 50% faster per simulation on their machine (R, §6.3).

Relation to AlphaGo Zero

Developed independently and at the same time; both train the policy on the search's visit shares. AlphaGo Zero trains its value head on results of games played with search, uses about 100,000 times more computation, a far deeper network, root noise for exploration, and a check that each new expert beats the old one (R, §7, Appendix A).

Caveats

  • One game, one board size (9×9 Hex).
  • The search uses the exact game rules; ExIt as tested needs a perfect simulator.
  • Most comparisons are learning curves; the raw keeps their captions only.
