Reflexion: Language Agents with Verbal Reinforcement Learning

source created 2026-05-06 updated 2026-05-18 reasoning agents reinforcement-learning self-improvement scaffolding 2023 neurips

Shinn, Cassano, Berman, Gopinath, Narasimhan, Yao — arXiv 2303.11366, March 2023 (NeurIPS 2023)

Frames reflection as a lightweight substitute for gradient-based RL: instead of updating weights from a reward signal, the agent writes a natural-language self-critique after each failed episode and stores it in a memory buffer. The next episode is conditioned on those reflections. No fine-tuning, no PPO — just words feeding back into context.

Method

The agent loop has three components:

  1. Actor — an LLM (or LLM-tool agent à la ReAct, source-react-reasoning-acting) that produces actions for an episode.
  2. Evaluator — converts the trajectory + outcome into a scalar / textual reward (unit tests, env signal, or LLM judge).
  3. Self-Reflection model — given the trajectory and reward, generates a short natural-language reflection ("the test failed because I assumed X; next time I should check Y").

Reflections accumulate in an episodic memory buffer; the actor is re-invoked with the buffer in context. The "RL" is purely linguistic — verbal reinforcement — and the policy update is the next episode's prompt.

Key numbers

  • HumanEval (Python): 91% pass@1 with GPT-4 + Reflexion, vs 80% for GPT-4 alone. State-of-the-art at submission.
  • AlfWorld (decision-making, text-based household tasks): from ~75% → 97% success with reflection.
  • HotPotQA (language reasoning): substantial improvement over ReAct baseline (source-react-reasoning-acting).

The main empirical claim: reflection produces measurable gains across sequential decision-making, coding, and language reasoning without any weight updates.

Why it matters

Reflexion is the earliest clean instance of a recurring pattern in this wiki: failure → natural-language critique → richer prompt → improved behaviour, with no gradient flow. It crystallised three ideas:

  1. Verbal RL as a primitive — predates and inspires the inference-time self-improvement work in concept-self-improvement.
  2. Episodic memory of reflections — a small, durable, symbolic store the LLM reads from. This is a concept-harness-as-symbolic-substrate artefact: the symbol is the lesson learned.
  3. Test-time learning loop without training — pairs naturally with source-self-refine (intra-episode refinement) and with the broader concept-test-time-compute family.

Direct lineage in the wiki: source-voyager-minecraft-skill-library turns Reflexion's "remember what failed" loop into a persistent skill library in Minecraft. source-gea-group-evolving-agents and source-agyn-multi-agent-swe scale the experience-sharing pattern to multi-agent organisations.

Reflexion's HumanEval result also became a touchstone in the concept-llm-reasoning debate: opponents argue the reflection text correlates with bug fixes only because the model already "knows" the right answer at high temperature; supporters argue verbal feedback is genuinely informative beyond random retries.
