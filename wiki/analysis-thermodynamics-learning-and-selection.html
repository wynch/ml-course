Thermodynamics: Learning, Memory and Selection

analysis created 2026-10-01 updated 2026-10-01 thermodynamics evolution learning memory resource-budgets

The useful opening is to ask what lets a learning system keep working, what it should retain, and when change earns its cost. These are our deductions from source-roddier-thermodynamics-evolution, not ML results reported in the talk.

R below means raw/youtube-6lNz5vmkefa-roddier-thermodynamics-evolution.md, §Transcript plus timestamps. Captions are automatic.

1. What selects the target?

Vincent asks: “What chooses the target, and when does it change?” (compass/log.jsonl, question dated 2026-09-26).

Roddier's account of selection invites a distinction between learning toward a given score and selection deciding which systems persist (R, 49:01–49:18). Our ML question: could an outer process choose learning targets while respecting limits on memory, computation and error? Continued operation alone does not specify which task is useful to us. The constraints and the selection rule would still need to be stated.

2. What deserves to stay in memory?

Roddier links retained information to an organism's operation (R, 51:53–53:01). Our proposed criterion: keep a representation when its later benefit covers the costs of learning, storing and using it. This connects to Vincent's Q3, “What did the objective never ask it to keep?” (compass/log.jsonl, 2026-09-05).

idea-neural-symbolic-ecology already asks whether reusable resources justify their costs; its evidence section leaves the general architecture unproven. Thermodynamic language adds no validation. Nor does software memory naturally disappear when it stops being useful: a deletion rule would be a design choice.

3. Which changes should be fast, and which slow?

Roddier contrasts genetic change with faster memory in brains (R, 1:02:02–1:02:31). Our analogy is a system with fast changes in its current context, slower changes in learned weights, and records it can pass between runs. This is not a one-to-one account of genes, brains and culture.

The question is when an observation should change only the current answer, enter memory, or change a general rule. Roddier's feedback account adds a further issue: actions can change the setting being learned (R, 53:23–55:40). A lower error could then reflect easier chosen observations rather than better learning.

4. When does sharing beat learning alone?

Roddier notes that giving information does not make the giver lose it (R, 52:09–52:32). Our deduction: a shared rule could save repeated discovery. Its benefit must cover communication, verification and the cost of wrong or stale advice. Compare shared and separate learners at the same total budget. This is a question, not evidence for the project's old federation designs.

One question worth keeping open

Under the same total budget, when should a learner update, reuse a memory, or forget it?

A possible later test would compare a fixed predictor, an always-updating predictor and one that chooses when to update, on the same changing stream. Count the choice mechanism's cost too. Score predictions before revealing their answers; compare later unseen data, recovery after changes and retention of earlier skills. Lower error at the same cost, or lower cost at the same error, would be a useful result.

Expectation to examine: choosing when to update may save work during stable periods while still recovering after a change. If the gain vanishes once overhead and easier inputs are controlled, that expectation fails. When attributing a gain to an update, also compare old and new predictors on the same data: the existing compression-progress source makes this distinction explicit (raw/arxiv-0812-4360-driven-by-compression-progress.md, §A.5–A.6).

This is a question sketch, not a registered experiment. Experiments remain parked.

Keep the quantities separate

Physical entropy, uncertainty over outcomes, prediction loss and energy in joules are different quantities. Calling an ML objective “energy” or “free energy” does not equate it with heat. Roddier's proposed maximization principle is stronger than the second law; he acknowledges debate over its claimed proof (R, 34:06–34:23). None of these project questions requires accepting that principle as a universal law.
