Test-Time Training with KV Binding Is Secretly Linear Attention

source created 2026-04-05 updated 2026-10-20 test-time-training linear-attention transformers nvidia

Authors: Junchen Liu, Sven Elflein, Or Litany, Zan Gojcic, Ruilong Li (NVIDIA, per the project page) · arXiv 2602.21204 (v1 2026-02-24, v4 2026-05-12) · ICML 2026 (arXiv comments) Institution: NVIDIA (Scene Intelligence Lab) Project page: research.nvidia.com/labs/sil/projects/tttla Full text: raw/arxiv-2602-21204-test-time-training-with-kv-binding.md (v4, captured 2026-10-20), cited below by section as R

Summary

Reveals a connection between test-time training (TTT) with key-value binding and linear attention mechanisms, showing they are fundamentally the same operation.

Key Ideas

  • TTT with KV binding is equivalent to linear attention — unifying two seemingly different approaches
  • Bridges test-time compute (adaptation at inference) with architectural choices (attention variants)
  • From the abstract: evidence contradicts reading TTT as online memorisation of key-value pairs; a broad class of TTT layers can be rewritten as a learned linear attention operator, which allows simpler architectures and fully parallel forms (arXiv 2602.21204). The paper is not in raw; the gradient-ascent result in the review plan is not in the abstract and is left out until the full text is captured.

Added 2026-10-20, from the full text

  • Four results against memorisation, on LaCT (language and novel-view synthesis) and ViTTT (image classification). More inner-loop steps fit the keys and values better yet make the task worse (R, §4.1, Figure 1). Gradient ascent in the inner loop, retrained from scratch, does as well or slightly better: perplexity 16.19 against 16.43, PSNR 25.85 against 25.94, top-1 79.61% against 79.34% (R, §4.2, Table 1). Queries and keys sit in different distributions, so the inner function is read out of distribution (R, §4.3). Using the keys in place of the queries changes little (16.18, 25.95, 79.18%) (R, §4.4, Table 1).
  • The rewrite. With a linear, bias-free final layer, a broad class of TTT layers, including multi-layer MLPs and momentum, can be written as linear attention: the inner loop sets a learned mix of queries, keys and values, not a memory (R, §5, Theorems 5.1–5.3).
  • What it buys. Updating only the last inner layer gave the best scores on all three tasks (15.93 perplexity). Stripping the rest down to plain linear attention costs +0.4 perplexity and −0.2 dB. A parallel prefix-scan form runs the TTT layer up to 4.0× faster at inference and trains 1.19× faster end to end (R, §6.1–§6.2, Table 2, Figure 4).
  • Limits. Proofs need a linear, bias-free final inner layer; experiments cover two open models only (R, §7).
