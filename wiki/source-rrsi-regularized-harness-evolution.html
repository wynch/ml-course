Summary

Harness evolution loops (Meta-Harness and its kin) let an LLM rewrite the prompts, control flow, tools, memory and context rules around a frozen model, and keep an edit when it raises a score on an evolve set. The paper calls this recursive self-improvement at the agent-system level (R, §1). Because the loop re-reads the same finite evolve set every round, it overfits: gains on the evolve set shrink or vanish on other benchmarks (R, §1, §2 "Harness Evolution").

RRSI keeps the edit space open (any component may change) and instead constrains the search (R, §3.1):

Key results

Policy, proposer, analyst and critic are all Claude Opus 4.8 unless noted (R, §4.1). Each domain evolves on one suite and runs unchanged elsewhere.

  • Agentic workspace (evolve on Harvey LAB, 120 tasks; 40-task in-distribution held-out; JobBench, GDPval, APEX-Agents out of distribution). RRSI: evolve 90.5, ID held-out 89.2, OOD mean 43.6 vs base 39.7. Meta-Harness: highest evolve score (93.0) but OOD mean only +0.9 over base; AHE and TTHE finish below the base out of distribution (R, §4.2, Table 1).
  • All held-out splits improve, none regress: SWE-bench Verified +1.8 (evolved on Terminal-Bench 2.1, +6.0); OOD agentic +3.5 to +4.7; Frontier-Eng +4.3 Medal points (evolved on EngDesign, +4.9) (R, §4.2).
  • Ablation: with both regularizer groups removed, the evolve score is highest (92.8) and the OOD mean falls to 40.3, near base, at 3.80 M policy tokens per trial vs RRSI's 2.42 M and base 1.56 M (R, §4.3, Table 2).
  • Policy robustness: evolving with Gemini 3.5 Flash lifts Terminal-Bench 2.1 from 64.6 to 78.7 (+14.1) and SWE-bench Verified +2.2. The same harness run with Gemini 3.1 Flash Lite, which never took part in the search, goes 11.2 → 14.6 (R, §4.3, Tables 3-4).
  • Cost: RRSI's harness is the cheapest evolved one; AHE uses 58% more tokens for 4.4 fewer OOD points. No evolved harness is as cheap as the base, so part of every gain is bought with test-time compute (R, §4.3, Figure 4).
  • Case study: a pre-completion verification audit was accepted (+3.93); a similar edit with +1.69 at +26.1% cost was rejected; a cheaper edit at −2.81 was rejected by the floor (R, Appendix E, Table 6).

Caveats

  • Gains sit close to the noise band: on the agentic instance δ = 0.004, i.e. 0.4 points (60 criteria of about 14,100), and the Harvey LAB evolve gain is 1.1 points, under three times δ (R, Appendix D.1, Table 5; §4.2). The paper reports single numbers, no seeds or intervals for held-out splits.
  • §4.3 calls the cost-acceptance rule "the L1-style budget"; §3.3 names the same rule Ridge/L2-style. Treat §3.3 as the definition.
  • Three of the OOD agentic benchmarks use a judge model; the authors answer this with the simulator-graded engineering domain (R, §4.2).
  • Frozen weights only; hyperparameters (δ, β, windows) are tuned on the evolve set (R, Limitations; Appendix D.1).
