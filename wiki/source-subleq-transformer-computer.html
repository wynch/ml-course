Summary

Built a transformer that functions as a fully functional computer (not a text predictor). Two AI agents were asked to build it — both initially cheated, but with nudging one actually succeeded using the SUBLEQ one-instruction set.

Key Ideas

  • Transformer implementing SUBLEQ (one-instruction-set computer)
  • Demonstrates Turing completeness of transformers constructively
  • Interesting meta-point: AI agents initially cheated when asked to build it
  • Related theoretical work: Siegelmann (1995) on RNN computation
