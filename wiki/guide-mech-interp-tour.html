Mech Interp — Reading Tour

guide created 2026-05-07 updated 2026-05-07 guide reading-list mechanistic-interpretability tour

Eight stops through the wiki's mech interp coverage, in roughly the order someone new to the field should encounter them. Each stop builds on the prior. Concept overview lives at concept-mechanistic-interpretability; this is the linear path.

Stop 1 — The manifesto

source-olah-2020-zoom-in-circuits (Olah et al., Distill 2020). The original "circuits" framing: features, neurons, and the universality hypothesis. Pre-transformer; vision models. Sets up the entire programme as "reverse-engineer learned algorithms."

Stop 2 — Anthropic foundations (2021–22)

source-anthropic-mi-foundations (grouped: Elhage 2021 math framework + Elhage 2022 toy models of superposition + Olsson 2022 induction heads).

The mathematical scaffolding: attention-only transformers as sums of QK/OV paths; features as linear directions in superposition; induction heads as the mechanistic origin of in-context learning. If you only read three Anthropic papers, read these — together they're the conceptual basis for everything that follows.

Stop 3 — FFN as key-value memory

source-geva-ffn-key-value-memories (Geva 2020). The other major architectural reading: feed-forward layers act as key-value lookups; keys detect patterns, values produce output distributions. Foundational for the "where does knowledge live" question and the precursor of ROME/MEMIT.

Stop 4 — Worked examples of full algorithmic readouts

source-nanda-2023-grokking-modular-addition — modular addition fully distilled to a DFT algorithm. source-wang-2022-ioi-circuit-gpt2 — IOI as 7 typed-head classes in GPT-2 Small.

Read these to see what a "complete circuit" looks like in 2022–23 terms. Tiny tasks, but the algorithms are extracted in full.

Stop 5 — The SAE pivot (2023)

source-sae-monosemanticity-2023 (grouped: Bricken + Cunningham). Two concurrent papers showing that sparse autoencoders trained on activations recover monosemantic features at scale. Read both as one paper — independent confirmation.

This is the methodological pivot of the field. Post-2023, almost all interpretability work uses SAE features as the unit of analysis.

Stop 6 — Scaling the SAE recipe

source-sae-scaling-trilogy (grouped: Templeton 2024 / Matryoshka / Gemma Scope 2). Scale SAEs to Claude 3 Sonnet ("Golden Gate Claude"), add hierarchical feature dictionaries, deploy a full-stack transcoder suite on Gemma-3.

Stop 7 — Attribution graphs and circuit tracing

source-circuit-tracing-methods-anthropic — cross-layer transcoders + attribution graphs. source-lindsey-2025-biology-of-llm — biology of Claude 3.5 Haiku case studies (multi-hop reasoning, forward planning in poetry).

The current frontier of "given an SAE dictionary, trace which features cause which behaviour."

Stop 8 — Whole-model readouts and decompilation

source-tensorlens-attention-tensors — collapse the whole transformer into a single high-order tensor; modular projection back to any circuit. source-decompiling-transformers-to-rasp + source-weights-to-code-discrete-transformer — decompile transformers to RASP / Python. source-formal-circuit-discovery — circuit discovery with verified soundness.

The endgame: don't just label features, recover the program the model is running.

Side branches worth knowing about

  • Surveys: source-mech-interp-surveys (Rai 2024 + Shu 2025) — meta-index over everything above.
  • Alternative direction — patterning: source-patterning-dual-of-interpretability + source-steering-generalization-alignment argues for data-side control instead of weight-side reading.
  • Alternative direction — self-explanation: source-introspective-interpretability, source-self-explanation-transluce, source-predictive-concept-decoders — train models to explain themselves.
  • CoT-faithfulness: source-measuring-cot-monitorability — is what the model says it's doing actually what it's doing?
  • Steering: source-conditional-activation-steering-cast — conditional control via SAE features.
  • Associative-memory framing: source-hopfield-is-all-you-need — modern Hopfield update ≡ softmax attention.

What's NOT here

The wiki's mech interp coverage is heavily Anthropic-flavoured by intent. Other angles you'll need to look elsewhere for:

  • Mechanistic neuroscience (we have source-visual-cortex-dimensionality as a brush-up, not deep)
  • Probing classifiers / linear readouts at frontier scale (covered indirectly via source-rome-memit-factual-editing)
  • Modular addition / arithmetic circuits beyond grokking — see concept-mechanistic-interpretability's open questions
