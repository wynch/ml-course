Outrageously Large Neural Networks (Sparsely-Gated MoE)

source created 2026-05-06 updated 2026-05-06 moe mixture-of-experts sparsity conditional-compute foundational 2017

Noam Shazeer, Azalia Mirhoseini, Krzysztof Maziarz, Andy Davis, Quoc Le, Geoffrey Hinton, Jeff Dean — arXiv 1701.06538, ICLR 2017 (Google Brain)

The paper that introduced sparsely-gated mixture-of-experts (MoE) as a practical conditional-compute mechanism. First demonstration that you can put >100 billion parameters into a single neural network and still train it efficiently, by routing each input through only a small subset of those parameters per step. Every modern MoE — including source-switch-transformer and the Mixtral / DeepSeek lineage — is a descendant of this layer.

Method

  • MoE layer: a set of N expert networks (small FFNs) and a trainable gating network. For each input x, the gate produces sparse weights G(x) ∈ R^N (top-k softmax), and the layer output is the weighted sum of the k chosen experts' outputs.
  • Noisy top-k gating: G(x) = softmax(KeepTopK(x · W_g + ε · softplus(x · W_noise))). Adding learned per-expert noise during training improves load balancing and exploration; KeepTopK keeps only the top k entries (k=2 or 4 typically), zeroing the rest.
  • Two auxiliary losses: an "importance" loss (CV² of total gate mass per expert) and a "load" loss (CV² of expected number of examples per expert) — both encourage balanced expert usage.
  • Hierarchical MoE: a two-level gating tree to scale to thousands of experts without O(N) gate compute.
  • Inserted between stacked LSTM layers in the experiments — pre-transformer.

Key results

  • A 137B-parameter LSTM language model trained at lower cost than dense baselines, with ~24% relative perplexity reduction on the 1B-Word benchmark.
  • Translation: outperforms GNMT on WMT'14 EN→FR / EN→DE while using less compute per inference step.
  • First credible demonstration that conditional compute (activating ~1% of params per step) beats dense scaling on FLOPs-vs-quality.

Why it matters

The original. This is where "trillion-param model with billion-param compute" was first articulated as something you could actually train. Every choice in modern MoE — top-k routing, load-balancing loss, expert parallelism — is here in proto-form. source-switch-transformer simplified to top-1 and ported it to transformers; subsequent work (GShard, GLaM, Mixtral, DeepSeek-V2/V3) refined the routing and expert-parallel infrastructure but kept the Shazeer 2017 conceptual frame intact.

In wiki context, this is the ancestor node for the entire conditional-compute thread: contrast with source-engram-deepseek (deterministic O(1) N-gram conditional memory as a competing form of conditional compute, with a U-shaped MoE-vs-memory trade-off) and with source-openai-privacy-filter (an encoder-MoE for PII detection that revives this design pattern in a 2024 production setting). The author Noam Shazeer also co-wrote source-attention-is-all-you-need the same year — a remarkable two-paper run.
