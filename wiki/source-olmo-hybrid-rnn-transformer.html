OLMo Hybrid: Attention + Linear RNN

source created 2026-04-05 updated 2026-10-20 architecture hybrid-models rnn transformers open-source

By: Allen AI Via: @alphasignalai on X

Summary

Open-source 7B model. Gated DeltaNet layers replace Olmo 3's sliding-window attention layers, three DeltaNet sublayers to each attention sublayer; 6T training tokens. Against Olmo 3 7B it matches MMLU with 49% fewer tokens and reaches parity on a Common Crawl slice with 35% fewer. RULER at 64k: 85.0 (with DRoPE) vs 70.9 (Olmo 3 with YaRN). Projected token savings grow from ~1.3× at 1B to ~1.9× at 70B (scaling-law fits, not measured). Released 2026-03-05 (https://allenai.org/blog/olmohybrid; report https://allenai.org/papers/olmo-hybrid; not in raw). (Rewritten 2026-10-19 from the blog; "a serious transformer rival" was the X post's words.)

Key Ideas

  • Hybrid architecture: standard attention + linear RNN layers
  • 7B model outperforms pure-transformer equivalent
  • Open-source from Allen AI
  • Demonstrates that hybrid approaches can surpass pure transformers
