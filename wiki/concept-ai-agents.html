Context & Memory

Agent performance is closely tied to context management:

  • source-lcm-lossless-context-management — deterministic context management outperforms Claude Code
  • source-zhang-harness-blog — Claude Code, Codex, ReAct and CodeAct append every observation to one growing context, which drifts out of distribution. Keeping inputs and sub-agent results in REPL variables keeps each call in-distribution. Even training a ReAct agent on these tasks was hard for a 30B model on 8×H100 because of context bloat (raw/web-2026-alexzhang-harness-compositional.md, §"The capacity for compositional generalization can live in the harness" for Claude Code and Codex; §"RLMs can train on short tasks…" for ReAct and CodeAct; §"RLMs can generalize to unseen tasks…", cost paragraph).
