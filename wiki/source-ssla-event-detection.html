Low-Latency Event-Based Object Detection with Spatially-Sparse Linear Attention

source created 2026-09-10 updated 2026-09-10 event-cameras linear-attention object-detection low-latency sparsity edge-inference sequence-models

Authors: Haiqing Hao, Zhipeng Sui, Rong Zou, Zijia Dai, Nikola Zubić, Davide Scaramuzza, Wenhui Wang (Tsinghua University; Robotics and Perception Group, University of Zurich) · arXiv: 2603.06228v4 · Date: 2026-03-06, revised 2026-08-26

Summary

An event camera reports per-pixel brightness changes as they happen, not frames on a clock, so its data is sparse in space and very fine in time. To keep that latency advantage a model must update event by event. Recurrent networks can do that but train slowly on long sequences. Linear attention (attention rewritten so it has both a parallel training form and a recurrent inference form — the family that includes state-space models) fixes training, but its state update touches every element of the state, so per-event cost grows with state size. Detection needs a large, fine-grained state to localize boxes, so the trade-off has been bad. SSLA cuts the state into one substate per overlapping P×P patch of the sensor plane; an event updates only the P² patches that contain it, and its output is the sum of those patches' outputs, which keeps the sequence length fixed so sparsity survives into deep layers. A position-aware projection re-projects the event by its offset inside each patch. Training stays parallel through a scatter-compute-gather trick: duplicate each event into its patches, run one weight-shared linear attention over the per-patch subsequences in parallel, then gather back into event order. SSLA-Det is the detector built on this.

Key claims

  • Best asynchronous accuracy at far lower cost. Gen1 automotive: SSLA-L reaches 0.375 mAP (mean average precision — the standard detection score) at 0.724 MFLOPS per event, against DAGr-L's 0.321 at 17.4 — over 20× fewer operations. The smallest model, SSLA-S, already beats DAGr-L (0.334) at 0.102 MFLOPS/ev, about 171× cheaper.
  • Same ordering on N-Caltech101. SSLA-L: 0.515 mAP, 0.743 AP₅₀, 0.926 MFLOPS/ev, versus DAGr-L's 0.732 AP₅₀ at 18.9.
  • Per-event latency under 10 µs. A recurrent C++ build on one core of an AMD Ryzen 9 9950X3D: 3.43 µs (S), 2.44 µs (B), 6.02 µs (M), 7.20 µs (L) on Gen1 — below the roughly 200 µs the sensor itself takes to transmit. Per-event cost is O(P²D²) and so independent of sensor resolution.
  • Parallel training pays. Against an LSTM at matched hidden size, SSLA-S cuts epoch time from 1.05 h to 0.25 h (4.2×) on 4 A800 GPUs; SSLA-B matches the LSTM's mAP (0.351 vs 0.353) with higher AP₅₀ (0.655 vs 0.631) at 3.8× less time.
  • The sparsity is the mechanism, and they isolated it. Replacing SSLA with a dense variant that keeps the same patch decomposition and projection costs 388 MFLOPS/ev at the same 0.370 mAP — a 380× saving from sparse activation alone. Plain linear attention at matched FLOPs fails outright; SSLA-S carries a state 380× larger for the same cost.
  • Not all of the saving is free. Temporal dropout supplies a further 10× reduction but costs accuracy: 0.370 mAP → 0.335. Sparse pooling changes no FLOPs but is load-bearing — remove it and mAP falls to 0.014.

Admitted limitations

  • The stated ceiling: synchronous detectors that accumulate events into frames exceed 0.5 mAP on Gen1 against SSLA-L's 0.375. The authors argue this is the accuracy-latency trade-off, not a defect, since synchronous models get image pretraining, larger parameter counts, and millisecond latency.
  • CPU latency does not track the FLOP savings — smaller is not always faster (SSLA-B, the larger model, is quicker than SSLA-S), because vectorization and memory access dominate. FPGAs or neuromorphic chips are named as future work, not measured.
  • Hybrid event-plus-image models, the current trend, are left to future work; only compatibility is asserted.
  • Reported failure cases: missed objects when camera and target do not move relative to each other, so no events fire, and false positives that are really missing annotations.

Relevance

  • A concrete data point for experiment-edge-autoresearch-and-ane: the cost that matters at the edge is not model size but per-input work and the shape of the graph. Here 380× is bought by never touching most of the state, and the accuracy price is zero — the opposite outcome to the local finding that int8 quantization bought no speed on an attention-bound video encoder (../ml-lab/levjepa-mobile/REPORT.md, the port covered in source-levjepa).
  • Linear attention here plays the same parallel-train / recurrent-infer duality that the wiki records for state-space models in source-mamba-ssm and source-mamba-2-ssm-duality. This paper adds a third axis those do not have: spatial sparsity in the state, routed geometrically rather than by a learned router.
  • For concept-transformer-architecture, it is a clean case of dropping softmax attention because the deployment demands a recurrent form, then paying for the lost state capacity with structure instead of parameters.
  • One caution on names. experiment-event-first-systems uses "event" in the agent sense — observations turned into beliefs and questions — not the sensor sense used here. The shared instinct is real (process change, not frames) but no result transfers between them.
