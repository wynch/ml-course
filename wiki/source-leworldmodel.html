Summary

LeWM learns a world model from recorded pixels and actions, with no rewards: an encoder turns each frame into a vector, and a predictor guesses the next frame's vector from the current one and the action (R, §3.1). Trained on prediction error alone, the encoder would map every frame to the same vector and score perfectly; that is collapse (R, §3.1).

Earlier latent world models avoided collapse with a frozen pretrained encoder (DINO-WM uses DINOv2) or with many loss terms (PLDM has seven, from VICReg) (R, §2, §4.1). LeWM uses two terms: the prediction error, plus SIGReg, the regularizer from source-lejepa that pushes the batch of embeddings towards an isotropic Gaussian, tested along 1,024 random directions (R, §3.1, Eq. 2–3). No stop-gradient, no moving-average target, no pretrained parts; everything trains together (R, §3.1). The authors call it the first JEPA trained stably end to end from raw pixels (R, Abstract, §1).

The model is small: a ViT-tiny encoder of about 5M parameters and a 6-layer transformer predictor of about 10M, with actions fed in through adaptive layer norm (R, §3.1). One frame becomes one 192-dimensional vector, about 200× fewer tokens than DINO-WM's patch features (R, Figure 3, Appendix D).

To act, it plans: encode the current frame and a goal frame, try action sequences inside the model with the cross-entropy method (300 candidates, a 5-step horizon), and execute the best (R, §3.2, Appendix D).

Key results

  • Planning speed. Up to 48× faster than DINO-WM; a full plan takes under one second (R, §4.2, Figure 3).
  • Success. On Push-T, 96% over three seeds, against 92% for DINO-WM and 78% for PLDM (R, Appendix G, Table 5). LeWM beats both on Push-T and Reacher; DINO-WM leads slightly on the 3D OGBench-Cube; on the simple Two-Room, both baselines beat it (R, §4.2, Figure 6).
  • One knob. The SIGReg weight λ is the only setting that matters: success stays above 80% for λ from 0.01 to 0.2 on Push-T, and falls only at 0.5 (R, §3.1, Appendix G, Figure 16). The number of projections hardly matters (R, §4.3).
  • Reconstruction hurts. Adding a pixel-decoder loss lowers Push-T success from 96% to 86% (R, Appendix G, Table 7).
  • Physics in the latent. Linear probes recover agent and block position from LeWM's vector better than from PLDM's, about as well as from DINOv2's; block angle is harder (R, §5.1, Table 1). Rotations stay hard for all three on OGBench-Cube (R, Table 4).
  • Surprise. Prediction error spikes when an object teleports (p < 0.01 in all three environments) but not significantly when it only changes colour (R, §5.2, Figure 8).
  • Latent paths straighten over training without any term asking for it, more than PLDM's, which has such a term (R, §5.1, Appendix H).

Caveats

  • "15M parameters, trainable on a single GPU in a few hours" is in the abstract only; no GPU model or training time is given in the text (R, Abstract, Appendix D).
  • The planning horizon is short, 5 steps of 5 frames; long tasks would need a hierarchy (R, §6, Appendix D).
  • On low-variety data (Two-Room) SIGReg struggles: a high-dimensional Gaussian is hard to match when the world has few dimensions (R, §4.2, §6).
  • Datasets are 10,000 to 20,000 episodes per environment, simulated, with actions recorded (R, Appendix E); the authors list dependence on action labels as a limit (R, §6).
  • DINO-WM runs without its proprioceptive input unless stated (R, §4.1).
