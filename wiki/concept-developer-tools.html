Developer Tools

concept created 2026-04-05 updated 2026-07-04 developer-tools coding ide productivity mcp harness

AI-assisted development tools — IDEs, coding agents, harness layers, and productivity enhancers. Heavily overlaps with concept-harness-as-symbolic-substrate: many of these tools are the symbolic substrate around the LLM.

In the Wiki

Coding agents and platforms

  • source-cursor-scaling-agents — Cursor's experiments on scaling AI coding agents in production.
  • source-claude-code-sandboxing — Anthropic's OS-level sandbox for Claude Code's bash tool. Filesystem and network isolation via Seatbelt/bubblewrap.

Token-efficient harness

  • entity-rtk-token-killer — Rust CLI proxy that filters/dedups shell output before it reaches the LLM. ~80% token reduction reported.
  • entity-codedb — Zig MCP server providing structural code-intelligence to agents at sub-millisecond latency. Trigram search, symbol lookup, dependency graph.

Multi-agent orchestration

  • entity-agentcraft — RTS-game-style UI for orchestrating multiple AI coding agents (Claude Code, OpenCode, Cursor, OpenClaw). Spatial supervision over many parallel units.
  • source-loop-engineering-addy-osmani — the five loop primitives (automations / worktrees / skills / plugins / sub-agents) now ship natively in both Codex and Claude Code; leverage moved from prompting agents to designing the loops that prompt them.

Cross-cutting Theme

The harness/tooling layer is increasingly where productivity gains come from, not the underlying LLM. RTK and codedb both reduce token cost without changing the model; AgentCraft reframes supervision UX without changing the agents; Claude Code's sandbox reframes safety without retraining. This is the source-language-models-as-scaffolds thesis playing out in shipped tooling — see concept-harness-as-symbolic-substrate for the conceptual frame.
