Continual Learning

concept created 2026-10-03 updated 2026-10-20 continual-learning catastrophic-forgetting fine-tuning training

Definition. A model learns continually when it trains on one phase after another (pretraining, then fine-tuning, then more) and keeps what earlier phases taught. The failure is catastrophic forgetting: a new phase overwrites old skills (raw/arxiv-2610-02126-local-support-learning.md, §1).

A stub, made on 2026-10-03 because the overview named continual learning as a cluster with no page.

Key ideas

  • Why forgetting happens, per weight matrix. A gradient step changes the output for every input not orthogonal to the training input, so old inputs shift too (raw/arxiv-2610-02126-local-support-learning.md, §3).
  • The second failure: losing the ability to learn. See "Loss of plasticity" below.
  • Old fixes do not scale to pretraining. Replay buffers, data-dependent penalties and orthogonal updates need the old data or a picture of it; the first "task" is now trillions of tokens, often unavailable (same file, §2).
  • Four routes, the wiki's grouping: keep updates small (LoRA, which forgets less than full fine-tuning but still forgets; same file, §2); penalise or repair change toward the old model by distillation (Learning without Forgetting, same file, §2; Thinking Machines' on-policy distillation from the pre-fine-tune model, which brought Qwen3-8B's IF-eval back from 79% to 83% after document fine-tuning, raw/web-2025-thinkingmachines-on-policy-distillation.md, "On-policy distillation recovers post-training behavior"); gate the update so it acts only on its own data (LSL, same file, §4); or keep new knowledge outside the weights, in context or retrieval, the race experiment-weights-vs-context set up. A fifth, 2026-10-20: put new knowledge in weights that little else uses. Sparse memory finetuning trains only the few slots of a memory layer that a batch uses far more than ordinary text does; learning 1,000 facts in sequence, NaturalQuestions F1 drops 89% with full fine-tuning, 71% with LoRA and 11% with it, at the same learning (raw/arxiv-2510-15103-continual-learning-via-sparse-memory-finetuning.md, Abstract, §4). Its baselines use AdamW and it uses SGD, which accounts for part of the gap (same file, §5, Appendix A).
  • Train on your own samples. Updates on text the model wrote itself (on-policy) forget less than supervised fine-tuning on someone else's text. RL's Razor gives a reason and a gauge: forgetting tracks the forward KL from the base model to the tuned one, measured on the new task only (R² 0.96 on a toy MLP, 0.71 on Qwen2.5-3B), and on-policy training lands on the solution nearest the base model (raw/arxiv-2509-04259-rl-s-razor-why-online-reinforcement.md, §4, §5). The cause is the model's own samples, not negative examples (same file, §5.1). SDFT gets such updates from demonstrations alone: the model with a demonstration in its context is the teacher, the bare model the student. On Qwen2.5-7B, tuned on each of three skills, it keeps a six-benchmark average of 64.5–65.4 against a base of 65.5, where SFT drops to 53.4–60.2; tuned on the three in turn, it keeps the earlier skills (raw/arxiv-2601-19897-self-distillation-enables-continual-learning.md, §4.3, Table 5, Figure 3). It does not work at 3B (same file, §4.4).
  • Where the update can run. Learning from private data on a phone first needs a training step that fits. MeBP runs true backpropagation for LoRA adapters on an iPhone 15 Pro Max: Qwen2.5 and Gemma3 models from 0.5B to 4B take 320 MB to 1,029 MB per step at 256 tokens, by checkpointing per layer and keeping weights and saved activations memory-mapped (raw/arxiv-2510-03425-memory-efficient-backpropagation-for-fine-tuning.md, §3, Table 1). It says nothing about forgetting.

Loss of plasticity

Besides forgetting, a network trained on task after task can lose plasticity, the ability to learn anything new. On 2,000 binary ImageNet tasks a small CNN falls from 89% on an early task to 77%, about a linear model's level; the signs are dead units, growing weights and a shrinking effective rank (raw/arxiv-2306-13812-maintaining-plasticity-in-deep-continual-learning.md, Abstract, §2, §4). Adam and dropout make it worse; small weights plus injected randomness help (same file, §5).

The authors' fix, continual backpropagation, is ordinary SGD plus, at every step, resetting a small fraction of each layer's least useful hidden units; new units start with zero outgoing weights, so the function does not jump. Run to 5,000 ImageNet tasks, it does better on the last task than on the first, and beats L2 and shrink-and-perturb (same file, §6, Figure 7). A preliminary RL run points the same way: on a simulated ant whose ground friction changes every 10M steps, PPO degrades badly and PPO with continual backpropagation barely drops over 100M steps (same file, Appendix C, Figure 11). See source-loss-of-plasticity and entity-richard-sutton.

Pages

  • source-local-support-learning — gate each adapter with a Gaussian-mixture test of "is this input like my training data?"; in the paper's ablation the gate keeps 96.6% of the base model's scores, 98.8% with smoothing, on Qwen2.5-7B (raw/arxiv-2610-02126-local-support-learning.md, §4, §5.2).
  • source-rls-razor — RL forgets less than SFT at equal new-task accuracy; forward KL on the new task predicts forgetting better than weight change, activation change or update rank (raw/arxiv-2509-04259-rl-s-razor-why-online-reinforcement.md, §3, §6, Table 1).
  • source-sdft-self-distillation-continual — self-distillation from a demonstration-conditioned copy of the model; on-policy, no reward; beats SFT and SFT-then-repair on new skills and on new facts at 7B (raw/arxiv-2601-19897-self-distillation-enables-continual-learning.md, Table 1, Table 5).
  • source-sparse-memory-finetuning — Lin et al. (Meta FAIR), 2025: a 1.3B model with a 1M-slot memory layer; train only the slots a batch uses that pretraining text rarely does (TF-IDF ranking); fact learning with far less forgetting than full fine-tuning or LoRA (raw/arxiv-2510-15103-continual-learning-via-sparse-memory-finetuning.md, §4, §5.1, Figure 5).
  • source-on-policy-distillation — Lu (Thinking Machines), 2025: the student samples, the teacher grades every token by reverse KL; as a repair after fine-tuning on new documents, distilling from the earlier model restores most instruction following; no fine-tuning data mix kept it, and LoRA still forgot (raw/web-2025-thinkingmachines-on-policy-distillation.md, "Training on new knowledge degrades learned behavior", "On-policy distillation recovers post-training behavior"). Company blog.
  • source-inkling-thinking-machines — the same repair and LoRA Without Regret (source-lora-without-regret) as Tinker recipes.
  • experiment-weights-vs-context — Vincent's stopped race between weights, retrieval and context for new knowledge.
  • source-continual-interactive-causal-agents — one continual stream under one objective in place of a stack of training phases (blog; raw/love4all-continual-interactive-causal-agents.md).
  • source-loss-of-plasticity — Dohare et al., the arXiv version of the Nature 2024 paper: loss of plasticity shown on ImageNet, Permuted MNIST and a small regression task; continual backpropagation, which reinitializes a small fraction of the least useful units at every step, keeps plasticity to 5,000 tasks (raw/arxiv-2306-13812-maintaining-plasticity-in-deep-continual-learning.md, §6, Figure 7).
  • entity-richard-sutton — continual backpropagation, which reinitializes under-used neurons to keep plasticity (Dohare et al., "Loss of plasticity in deep continual learning", Nature 632, 2024; the journal text is not in raw, the arXiv text is: source-loss-of-plasticity).

What is open

  • Small models. SDFT needs in-context learning strong enough to make a good teacher; at 3B it trails SFT (raw/arxiv-2601-19897-self-distillation-enables-continual-learning.md, §4.4, §5).
  • Why. RL's Razor's authors have no mechanism for why a large KL shift on the new task damages old skills, and have not tested the law at frontier scale (raw/arxiv-2509-04259-rl-s-razor-why-online-reinforcement.md, §7).
  • Many phases. LSL's cost grows with each phase and it was tested on three; its authors name hundreds of phases, and test-time training, as future work (raw/arxiv-2610-02126-local-support-learning.md, §6).
  • Beyond facts. Sparse memory finetuning was tested only on fact learning at 1.3B; its authors name reasoning and coding as the harder case, where retrieval has no clear role (raw/arxiv-2510-15103-continual-learning-via-sparse-memory-finetuning.md, §7).
