Paving the Way for AI Agents in Biology

source created 2026-07-04 updated 2026-07-04 ai-agents biology scientific-discovery benchmarks harness-as-substrate anthropic evaluation

Author: Laura Luebbert et al. (Anthropic + collaborators) / Date: 2026-06-08

Summary

Anthropic's research team argues that the bottleneck for AI agents in biology is not model reasoning but infrastructure: biological data lacks the deterministic execution layers that software engineering takes for granted. Navigating biology databases is likened to "driving through an old city that was designed before cars" — idiosyncratic file formats, scattered databases, filtering logic that lives only in web UIs (not APIs), identifiers that drift across sources, and expert-only conventions opaque to machines. The claim is that this infrastructure gap limits agents more than their reasoning ability does.

To make the case quantitative they build VirBench, a benchmark of 120 realistic viral-sequence retrieval queries across 40 pathogens with manually verified ground truth (e.g. retrieve human-host, African, 2014 Orthoebolavirus zairense sequences meeting length and ambiguity thresholds, excluding lab-passaged samples). Tested on Claude Sonnet 4, Claude Opus 4.7, GPT-5.2-pro, GPT-5.55, Biomni OSS, and Edison Analysis, agents without deterministic tools scored 16.9%–91.3% and were wildly inconsistent across identical repeated queries — Claude Sonnet 4 returned 106, 15, then 5 sequences when 266 were expected. This is not a cosmetic failure: phylogenetic trees built from agent-retrieved 2014 West African Ebolavirus data placed the inferred outbreak origin anywhere from January 2014 (correct) to 1922 depending on the run, and antibody-epitope analyses flickered across runs — retrieval noise directly changes the biological conclusion.

The fix is gget virus, a deterministic retrieval layer built with NCBI researchers that coordinates REST / Datasets / E-utilities APIs, decides which filters belong in the API versus local post-processing, batches large corpora (SARS-CoV-2, Influenza A), pulls supplementary GenBank records, and returns standardized machine-readable output with retrieval logs. With gget virus in the loop, accuracy exceeded 90% across all agents (GPT-5.5 reached 99.7%), run-to-run variance largely vanished, and — importantly — the gap between strong and weak models collapsed, decoupling reliable results from having the newest, most expensive model. The authors generalize this to "context engines": reliable, deterministic, agent-accessible infrastructure (alongside ToolUniverse, Edison's Robin, Biomni). Even if models eventually navigate messy portals unaided, they argue the task "shouldn't be handled (and reinvented) by an agent every time" — cost, speed, auditability, and trust favor building the deterministic layer once.

Key Ideas

  • The binding constraint for scientific agents is deterministic tooling / data infrastructure, not raw model reasoning.
  • VirBench: 120 verified viral-sequence queries; without tools, accuracy 16.9%–91.3% with severe run-to-run nondeterminism (266 expected vs 106/15/5 returned).
  • Retrieval noise propagates to conclusions: inferred Ebolavirus outbreak origin ranged from 2014 (correct) to 1922 across runs.
  • gget virus (deterministic layer, built with NCBI) pushes all agents > 90% accuracy, GPT-5.5 to 99.7%, and narrows the inter-model gap — cheaper models become viable.
  • "Context engines": build the deterministic access layer once, for cost/speed/auditability, rather than making every agent re-solve messy portals.
