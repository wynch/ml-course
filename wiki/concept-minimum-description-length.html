Minimum Description Length

concept created 2026-10-20 updated 2026-10-20 mdl compression model-selection learning-theory program-synthesis stub

Stub. The minimum description length (MDL) principle picks the model that gives the shortest total code for the data: the bits to write down the model, plus the bits to write down the data with the model's help. A model that is too simple leaves the data costly to encode; one that is too complex costs too much to write down. Fit and simplicity are paid in one currency, bits.

The wiki holds no primary MDL text (Rissanen 1978; Grünwald, The Minimum Description Length Principle, MIT Press 2007; neither in raw). This page gathers how the idea is used in the sources that are in raw, and in Vincent's local work, where the term appears on 14 wiki pages.

Key ideas

  • A predictor is a compressor. A model that gives the next event a probability can encode it in about −log₂ p bits, so likely events cost few bits and unlikely ones many; a good predictor of a history is a short code for it (raw/arxiv-0812-4360-driven-by-compression-progress.md, Appendix A.1). This is the bridge to concept-prequential-evaluation: summing those bits over a stream, each event coded before the model sees it, gives a code length for the data.
  • Not the fastest learner. Schmidhuber notes that MDL-style prediction need not converge to the right predictions as fast as Solomonoff induction, though both converge in the limit (same file, Appendix A.1).
  • Deep networks. Blier and Ollivier (2018) coded datasets with a network trained as it goes, block by block (a prequential code), and got much shorter codes than variational codes for the same networks; they used this to argue that deep networks do compress their data (arXiv 1802.07044; not in raw).

Local lines

MDL was "the main anti-sprawl pressure" across ORCHID, Cortex, CPE, LATTICE and SAIB: an abstraction had to cut total description length or it was not promoted (analysis-local-project-acronyms). The lessons the local pages kept:

  • ORCHID-lite: MDL is useful only when computed over normalised, executable forms (experiment-orchid-lite).
  • Cortex: e-graphs and MDL are useful control surfaces for symbolic compression (experiment-cortex-archive).
  • Edge Organism review: "MDL never charged family search", so the search over model families came free and the score flattered the result (experiment-edge-compression-federation).
  • Edge federation: the wiki's gap in MDL sources is "not permission to treat hindsight expert minima as a codelength": the best expert picked after the fact is not a code anyone could have used (experiment-edge-federation).

None of these lines reached a benchmark result that survived; all were sunset on 2026-10-07 (analysis-experiments-second-chance).

Open questions

  • Overview gap 6 asks for older sources on MDL, prequential codes and online mixtures (overview). Rissanen, Grünwald, and Blier and Ollivier are the natural captures.
  • Does CompressARC's 20% come from the MDL objective or from the network's shape? The report gives no ablation (raw/arxiv-2601-10904-arc-prize-2025-technical-report.md, §3.2.2).
