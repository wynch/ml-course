LoRA: Low-Rank Adaptation of Large Language Models

source created 2026-05-06 updated 2026-10-03 lora peft fine-tuning parameter-efficient foundational 2021

Hu, Shen, Wallis, Allen-Zhu, Li, Wang, Wang, Chen — arXiv 2106.09685, Jun 2021 (Microsoft Research)

Parameter-efficient fine-tuning (PEFT): freeze the pretrained weights W, and learn a low-rank update ΔW = B·A (with rank r ≪ d_model) added at adaptation time. Trains <1% of the parameters of full fine-tuning, with no inference-time latency (the update can be merged into W after training), and matches or beats full fine-tuning on many tasks. Now the dominant adaptation primitive for open-weight LLMs.

Method

  • For a frozen weight matrix W ∈ ℝ^{d×k}, parameterise its update as ΔW = B A with B ∈ ℝ^{d×r}, A ∈ ℝ^{r×k}, rank r typically 4–64.
  • A is initialised Gaussian, B is initialised to zero, so the adapted model starts identical to the base.
  • Forward pass: h = Wx + (BA)x · α/r (α is a scaling hyperparameter).
  • Typically applied to the attention Q and V projections; some variants apply to all linear layers.
  • After training, ΔW = BA can be merged into W — zero extra latency at inference.

Key results

  • On GPT-3 175B with rank 8: trains 0.01% of parameters (~37M vs 175B), matches full-fine-tuning quality on GLUE, WikiSQL, SAMSum.
  • Up to 3× lower GPU memory during training (no optimiser state for frozen params).
  • No latency at inference (unlike adapter modules, which add layers).
  • Composable: multiple LoRA adapters per base model, swappable per request — the architectural primitive for serving 1000s of customised models from one base.
  • Robust across ranks; r = 4 often nearly as good as r = 64 (suggesting the adaptation manifold is intrinsically low-dimensional).

Why it matters

LoRA is the economic engine of the open-weight ecosystem:

  • Hugging Face has 100k+ LoRA adapters; serving stacks (vLLM, TGI, SGLang) hot-swap them per request.
  • It is the default for specialising base models to a domain, persona, language, or task without copying the base weights.
  • Stable Diffusion's entire fine-tuning culture runs on LoRA.

For this wiki, LoRA matters as the first large-scale empirical evidence that fine-tuning lives on a low-rank manifold — an empirical fact that feeds directly into the concept-retrofitting framing. source-retrofitting-models-minixhofer extends this insight: LoRA modifies parameter values without changing the architecture, but the same principles (graduality, expressivity matching, self-distillation) apply when you go further and modify the architecture itself (source-openai-privacy-filter is the deep retrofit case study). LoRA is the entry point on a continuum:

Full fine-tune ← LoRA ← Architectural retrofit ← From-scratch retrain.

It also informs concept-model-training (efficient post-training is now a default expectation, not a research project) and concept-mechanistic-interpretability (low-rank ΔW is a useful object to interpret — what direction in weight space does a task live on?). The "intrinsic low rank" of fine-tuning hints that task-specific behaviour occupies a tiny subspace of weight space, an idea that recurs in source-rome-memit-factual-editing (rank-one factual edits) and source-from-latent-to-weight-space (latent-to-weight-space mappings).
