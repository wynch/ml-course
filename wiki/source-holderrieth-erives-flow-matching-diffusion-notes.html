The claim, plainly

A generator can turn noise into data by following a velocity field over time, like particles carried by a current. You never need to know that field directly: pick a simple path from noise to each single data point, whose velocity you can write down, and train a network by plain regression to match those per-point velocities; the network then learns the average field that carries noise to the whole data distribution (N, §3). The same recipe gives score matching (diffusion models), classifier-free guidance, and, with token jumps instead of velocities, discrete diffusion for text, where training reduces to a per-position classifier (N, §4, §5, §7).

Terms

  • Vector field u_t(x): a velocity at every point x and time t; following it from t = 0 to 1 is solving an ODE, an ordinary differential equation (N, §2.1).
  • SDE: a stochastic differential equation, an ODE with random kicks added at each step, scaled by a diffusion coefficient σ_t (N, §2.2).
  • Probability path p_t: a chosen way to blend noise (t = 0) into data (t = 1). Conditional: toward one data point z. Marginal: averaged over all data points (N, §3.1).
  • Score: ∇log p(x), the direction in which the density rises fastest (N, §4.1).
  • CTMC: a continuous-time Markov chain, a process that jumps between discrete states at given rates; the discrete stand-in for an SDE (N, §7.1).

Key points

Generation as simulation (N, §2). A flow model is a network u_t^θ used as a velocity field; sampling draws X₀ from a Gaussian and integrates the ODE with small Euler steps, X_{t+h} = X_t + h·u_t^θ(X_t), returning X₁ (N, Algorithm 1). The network gives velocities, not the trajectory, so sampling costs one network call per step. A diffusion model adds noise at each step, the Euler–Maruyama scheme (N, eq. 9).

Flow matching (N, §3; lecture 2).

  1. Path. The standard choice is Gaussian: x = α_t z + β_t ε, with ε pure noise, α rising from 0 to 1 and β falling from 1 to 0 (N, Example 8). With α_t = t, β_t = 1 − t it is the "CondOT" path used, per the notes, by Stable Diffusion 3 and Meta's Movie Gen (N, §3.3).
  2. Per-point velocity. For that path, the velocity that carries noise to the single point z has a closed form (N, eq. 20); for CondOT it is simply z − ε.
  3. Marginalization trick. The field that carries noise to the whole data distribution is the average of the per-point velocities, weighted by how likely each data point is given the current noisy x, a posterior (N, Theorem 9, eq. 18). The proof uses the continuity equation, conservation of probability mass (N, Theorem 11).
  4. Training. That average is intractable, but regressing on the per-point velocity instead changes the loss only by a constant, so the gradients are the same (N, Theorem 12). For CondOT the loss is ‖u_t^θ(tz + (1 − t)ε) − (z − ε)‖², with t uniform on [0, 1] (N, Algorithm 3). No ODE is simulated during training: the notes call it "simulation-free" (N, §3.3). Condition: the minimizer equals the marginal field only for a network expressive enough, as the notes state (N, Theorem 12).

Score matching and SDE sampling (N, §4; lecture 3-A).

  • The marginal score is the same kind of posterior average of per-point scores (N, eq. 38). For the Gaussian path the per-point score is −(x − α_t z)/β_t², and vector field and score convert into each other by a linear formula, so learning one gives the other (N, eq. 40, Proposition 1). Both are reparameterizations of the posterior mean of z given x, the "denoiser" (N, Remark 16).
  • Any amount of noise can be added at sampling time without changing the marginals: drift u_t + (σ_t²/2)∇log p_t plus noise σ_t dW_t keeps X_t ∼ p_t for every σ_t ≥ 0 (N, Theorem 17, via the Fokker–Planck equation, Theorem 19). In practice a best σ_t exists only because of training and step-size error (N, §4.2, footnote 2).
  • Denoising score matching regresses on the per-point score, again equal up to a constant (N, Theorem 22). Reparameterized and reweighted (the 1/β_t² factor dropped), the network predicts the noise ε that was added: the DDPM loss ‖ε_t^θ(α_t z + β_t ε) − ε‖², adopted because the raw loss is unstable when β_t is near 0 (N, Example 23).

Classifier-free guidance (N, §5; lecture 3-B).

  • Vanilla guidance: give the prompt y to the network and train on (data, prompt) pairs (N, §5.1). In practice samples fit the prompt poorly (N, §5.2).
  • Classifier guidance: Bayes' rule splits the guided score into the unguided score plus ∇log p_t(y|x), the gradient of a classifier on noisy inputs; scaling that term by w > 1 strengthens the prompt (N, eq. 62).
  • Classifier-free guidance: the same scaling can be written without a classifier, ũ = (1 − w)·u(x|∅) + w·u(x|y), mixing the unguided and guided fields (N, eq. 65). One network learns both: during training the prompt is replaced by an empty label ∅ with some probability η (N, Algorithm 5).
  • Condition: for w ≠ 1 the result is no longer the true guided field, so the samples are not guaranteed to follow p_data(·|y), in the notes' words "not necessarily aligned" with it; w = 1 gives plain conditional sampling. The notes call guidance "a heuristic" justified by results, and say almost every AI-generated image or video they see relies on it with w ≥ 4 (N, §5.2).

Discrete diffusion (N, §7; lecture 5).

  • Text is a sequence of d tokens from a vocabulary of size V. A CTMC replaces the vector field with a rate matrix Q_t(y|x), the rate of jumping from state x to state y (N, eqs. 84–87). Sampling takes small steps: stay with probability about 1 − h·(total leaving rate), else jump (N, eq. 88).
  • The full state space has V^d states, so models are factorized: only one token may change per jump, and the network outputs a d × V table of rates; all positions are then updated in parallel, which agrees with the exact step to first order in h (N, §7.1, Algorithm 7).
  • Path: each token independently is the data token with probability κ_t and noise otherwise, the "factorized mixture path" (N, Example 35). As t grows, weight shifts from the noise distribution to the data token at each position; no mass travels along a direction, as it does on the Gaussian path (the wiki's wording of the notes' contrast in Example 35 and Figure 19).
  • Training: by the same marginalization trick (N, Theorem 36), the marginal rate for position j is a rescaled probability that the clean token is v given the whole noisy sequence (N, Theorem 38). So training is a per-position classifier with cross-entropy: L = Σ_j −log p^θ(z_j | x) (N, §7.2.3, Algorithm 8). "In the same way as continuous flow matching reduced to simple regression", discrete flow matching reduces to classification (N, §7.2.3).
  • Masked diffusion (MDLM): add a [mask] token and start from all-masks; generation unmasks positions over time (N, Example 39).

Which component it bears on

This section is the wiki's reading of the notes.

  • The network's output. In flow matching the network outputs a velocity; in score matching a score or the added noise; in discrete diffusion a distribution over the clean token at each position. For Gaussian paths the first three are linear rewrites of one quantity, the posterior mean of the clean data given the noisy input (N, Remark 16). Choosing which to predict is a choice of scaling, made for training stability (N, Example 23).
  • The training target. Every method regresses (or classifies) against a per-example target that is easy to compute, and the marginalization trick guarantees the average is the field you need. That is why training never runs the sampler.
  • The sampler. The number of Euler steps is the inference cost; σ_t is a free knob at sampling time (N, Theorem 17). Few-step methods such as flow maps attack this cost.
  • Guidance weight w trades faithfulness to the data distribution for fit to the prompt (N, eq. 65).

Caveats

  • Teaching notes, not a research result; the methods and theorems come from the papers the notes cite (Lipman et al., Liu et al., Albergo and Vanden-Eijnden, Song et al., Ho and Salimans, and others).
  • The usage claims (CondOT in Stable Diffusion 3 and Movie Gen; CFG with w ≥ 4 in "almost any" AI image) are the authors' statements, not checked here.
