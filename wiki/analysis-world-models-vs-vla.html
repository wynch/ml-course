World Models vs VLA — Four Answers to Embodied Intelligence

analysis created 2026-05-07 updated 2026-10-20 analysis world-models vla robotics embodied-ai active-inference

How should an agent's policy be structured? The wiki now covers four distinct answers, each with a flagship 2024–2025 result, each making a different bet about where to put the work.

The four positions

PositionWhere the work livesFlagship result
Generative world modelPredict pixels → plan or train inside dreamssource-genie-2-foundation-world-model (DeepMind Dec 2024): playable 3D worlds from a single image
Predictive world modelPredict task-relevant latents → plan in latent spacesource-vjepa-family V-JEPA 2-AC, post-trained on under 62 hours of unlabelled DROID video and then run zero-shot on Franka arms in two labs (arXiv 2506.09985), via image-goal MPC
Direct VLA policyCo-fine-tune a VLM with robot trajectories; emit actions directlysource-rt-2, source-openvla, source-pi-zero
Symbolic code policyLLM emits robot programs; interpreter executessource-code-as-policies

The wiki's organising tension runs between these — concept-world-models and concept-vla-robot-foundation-models are sibling concept pages precisely because the same engineering problem has split into four research traditions.

Position 1: Generative world models

Lineage: source-ha-schmidhuber-world-models (2018, V/M/C decomposition) → source-planet-latent-dynamics (RSSM + planning) → source-dreamer-v1 (actor-critic in imagination) → source-dreamerv3 (single-config across 150+ tasks, Nature 2025) → source-genie-interactive-environments (latent action codebook from unlabeled video) → source-genie-2-foundation-world-model (playable 3D from an image).

Bet: if your world model can render observations faithfully, you can train agents inside it without burning real-world data. The world model becomes a substrate for both planning and RL.

Cost: rendering wastes capacity on appearance details that don't matter for control. Genie 2's strength (playable 3D + emergent physics) is precisely the cost the JEPA programme rejects.

Position 2: Predictive world models (JEPA)

Lineage: source-lecun-path-autonomous-intelligence (2022 blueprint) → source-ijepa-self-supervised-learning → source-vjepa-family.

Bet: if you only need to predict what matters for the task, predicting in embedding space is dramatically cheaper than predicting pixels. V-JEPA 2-AC is the existence proof: trained on <62h of Droid videos with action conditioning, deployed zero-shot on Franka arms in two labs, ~80% pick-and-place success.

Cost: the latent's structure is determined by the SSL objective, not by the task. Whether the latent contains what a novel downstream task needs is unverifiable until you try.

Position 3: Direct VLA policies

Lineage: source-rt-2 (Google 2023, tokenised actions) → source-openvla (open VLA, LLaMA 2 + SigLIP + DINOv2 backbone, OpenX-Embodiment) → source-pi-zero (Physical Intelligence 2024, flow-matching action head).

Bet: train a big enough vision-language-action model on enough demonstrations and the policy generalises directly. No explicit world model. No planning. Just amortised behaviour.

Cost: demonstration data is expensive. Long-horizon behaviours still need an outer loop (LLM planner, MCTS) on top.

Position 4: Symbolic code policies

source-code-as-policies is the older pattern: LLM writes Python that calls primitive robot APIs; an interpreter runs it. The neural-symbolic ancestor of modern VLAs.

Bet: robot control is a programming problem. The LLM produces structured plans, the interpreter executes them, and the symbolic layer is debuggable, modifiable, and composable.

Cost: the LLM has to write correct code without seeing the consequences. Closes the loop only by re-prompting on failure. Hard to handle continuous control.

Two cross-cutting tensions

1. Learned vs specified generative model

Inside Position 1 + 2, source-dreamerv3 learns the world model across 150+ tasks and gets generality. source-why-learn-if-you-can-infer-active-inference (VERSES NeurIPS 2024) specifies the generative model by hand and gets sample efficiency on specific tasks. Same predict-then-plan engine — opposite epistemology. See source-active-inference-foundations for the AIF framework that makes the specified-model side principled.

2. Direct policy vs predict-then-plan

The deepest split in the wiki's robotics coverage:

  • Direct (Position 3): cheap at inference, expensive at training (demonstration data).
  • Predict-then-plan (Positions 1, 2): cheap to train (passive video), expensive at inference (search / MPC / rollout).

V-JEPA 2-AC is interesting because it sits at the seam: a predictive substrate used as a policy via image-goal MPC. It's the cleanest data point for the predict-then-plan side.

What recently-added papers do to this debate

The new Track 3 additions sharpen the picture:

  • source-diffusion-policy (Chi 2023) — generative action model, smaller scale than VLAs but with continuous-action quality VLAs struggle to match. Lives between Position 3 and a Position-2-for-actions sibling.
  • source-aloha-act (Zhao 2023) — action chunking with transformers; bi-manual fine manipulation. The "small focused model, careful demonstration" alternative to scaling VLAs.

These two undercut the assumption that only big VLAs win. For specific manipulation tasks, careful small models can be competitive.

Implications and open questions

  1. Embodiment scale. OpenX-Embodiment shows shared structure across robots, but real cross-robot transfer is still rough. The position that wins long-term may be the one that handles the embodiment gap best.
  2. Long-horizon vs reactive. All four positions are good at reactive control. None is great at multi-hour plans. Position 4 (code) handles long-horizon best in principle; Positions 1–3 still need an outer loop.
  3. What's the JEPA-equivalent for action? source-pi-zero's flow-matching action head is the closest current candidate — continuous, fast, not autoregressive over discrete tokens. Whether it scales the way the JEPA encoder does is unsettled.
  4. What changes if source-deepseek-r1-style pure RL works for robotics? The wiki has no clear robotic-RL analogue of R1-Zero. If a base VLA + pure RL elicits skilled manipulation, Position 3 displaces 1 and 2 outright. Superseded (in part), 2026-10-19: RL fine-tuning of VLAs now exists (SimpleVLA-RL, arXiv 2509.09674; π*0.6, arXiv 2511.14759; not in raw); whether it surfaces latent skill as R1-Zero did is untested.

Update 2026-10

Work since this page was written, none of it ingested yet (not in raw):

  • Position 1: Genie 3 (DeepMind, 2025-08-05): worlds from a text prompt, explorable in real time at 24 fps and 720p, consistent for "a few minutes"; opened to US AI Ultra users as "Project Genie" on 2026-01-29 (source-genie-3; raw/web-2025-deepmind-genie-3-world-models.md, opening; the Project Genie launch is not in raw). Dreamer 4 (arXiv 2509.24527) trains agents inside a world model learned from offline video. Now ingested as source-dreamer-4: on the same 2,541 hours of offline Minecraft data, its world-model agent reaches the iron pickaxe 29% of the time against 11% for a VLA baseline (Gemma 3 fine-tuned by the OpenVLA and π0.5 recipe), and imitation on the world model's features beats imitation on Gemma 3's (raw/arxiv-2509-24527-training-agents-inside-of-scalable-world.md, §4.1, Figures 3–4). One game, one baseline, but it is a direct Position 1 against Position 3 test on shared data.
  • Position 2: LeWorldModel (arXiv 2603.19312), now ingested as source-leworldmodel: a 15M-parameter JEPA world model trained from pixels with no rewards and no pretrained encoder; planning by latent search takes under one second, up to 48× faster than DINO-WM, which eases the "expensive at inference" cost of predict-then-plan above. Its tasks are simulated (Push-T, Reacher, OGBench-Cube, Two-Room) with plans 5 steps long (raw/arxiv-2603-19312-leworldmodel-stable-end-to-end-joint.md, §4.2, Appendix D, Appendix E).
  • Position 3: π0.5 (arXiv 2504.16054) adds web and multi-robot co-training; Gemini Robotics (arXiv 2503.20020). π0.5 is now ingested as source-pi-0-5: with only about 400 hours from its target robots, other robots' and web data let it clean kitchens and bedrooms in homes it never saw; its own subtask step, in words, stands in for an outer planner (raw/arxiv-2504-16054-pi-0-5-a-vision-language-action.md, §I, §V-A, §V-E).
  • RL on VLAs: SimpleVLA-RL (arXiv 2509.09674), π*0.6 (arXiv 2511.14759).
