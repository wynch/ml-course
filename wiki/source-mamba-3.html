Summary

A state space model (SSM) layer reads a sequence by updating a fixed-size state, so memory stays constant and compute grows linearly with length, unlike attention's growing cache (R, §1). The authors design Mamba-3 for inference first: decoding with Mamba-2 leaves the GPU mostly idle, waiting on memory (R, §1). Three changes on top of source-mamba-2-ssm-duality (R, §1, §3):

  1. Exponential-trapezoidal discretization. A better rule for turning the continuous-time model into steps. It shows Mamba-1 and -2's step rule was a special case ("exponential-Euler") and adds an implicit short convolution on the input. With new learned biases on B and C, the separate short convolution that recurrent language models carry can go (R, §1, §3.1, §3.4, Table 5a).
  2. Complex-valued state. Lets the state rotate, which plain decays cannot do; computed cheaply as a rotary embedding (RoPE) that depends on the data (R, §3.2, Propositions 2–4). This gives state tracking: Mamba-3 solves parity (100%) and modular arithmetic without brackets (98.5%), where Mamba-2 and Mamba-3 without RoPE score near zero (R, §4.2, Table 5b).
  3. Multi-input, multi-output (MIMO). The state update becomes a matrix multiplication instead of an outer product, so each decode step does more arithmetic per byte of memory read, with the same state size (R, §3.3). It costs slower training (R, §6).

The block follows Llama's layout, alternating Mamba-3 and SwiGLU layers, with RMS norm on B and C like QK-norm in transformers (R, §3.4).

Key results

All models trained on 100B FineWeb-Edu tokens at 2K context, same recipe; sizes 180M to 1.5B (R, §4.1, Appendix D).

  • Quality at 1.5B. Average over eight zero-shot tasks: Transformer 55.4, Gated DeltaNet 55.8, Mamba-2 55.7, Mamba-3 SISO 56.4, Mamba-3 MIMO 57.6. So +0.6 points over Gated DeltaNet for the single-input version, +1.8 with MIMO (R, Table 3, Abstract). Mamba-3 SISO leads at every size (R, Table 3).
  • Half the state. At 440M, Mamba-3 with half the state size beats Mamba-2's perplexity; MIMO shifts the curve further (R, §4.3, Figure 3). The introduction states it as MIMO at state 64 matching Mamba-2 at 128 (R, §1).
  • Speed. One decode step on an H100 (1.5B, bf16, state 128): Mamba-3 SISO 0.156 ms, Mamba-2 0.203, Gated DeltaNet 0.257; MIMO 0.179 (R, §4.4, Table 6). At 16,384 tokens prefilled and 16,384 decoded, batch 128, the table gives 140.61 for Mamba-3 SISO against 976.50 for Llama-3.2-1B on vLLM, with no unit stated; the vLLM figure is estimated from batch 16 times 8, since batch 128 did not fit in memory (R, Table 7, Appendix G.2).
  • Retrieval stays the weak spot. Pure linear models trail the Transformer on extracting facts from semi-structured text (SWDE: Transformer 48.9, Mamba-3 SISO 28.5) (R, §4.1.2, Table 4). Mixed 5:1 with attention layers, the hybrids catch up or pass the Transformer on those tasks (R, Table 4).
  • Hybrids need a norm back. In 5:1 hybrids, restoring a grouped RMS norm before the output gate lifts long needle-in-a-haystack retrieval (to 96.0 and 56.8 on the hardest settings, from 9.4 and 8.8) at a small cost on real-world retrieval (R, §4.1.2, Table 4).

Caveats

  • Scale stops at 1.5B and 100B tokens; context 2K in training (R, §4.1).
  • The Transformer baseline uses RoPE and fails needle-in-a-haystack beyond its training length, which the authors say may explain that gap (R, Table 4 caption).
  • On modular arithmetic with brackets, the state-tracking version of Gated DeltaNet still leads (93.5 vs 87.75) (R, Table 5b).
  • The authors call hybrid behaviour "complex and oftentimes unintuitive"; the best norm placement is open (R, §4.1.2, Appendix E).
  • Table 7 gives no units, and its longest vLLM point is extrapolated (R, Table 7, Appendix G.2).
