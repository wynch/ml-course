Wavelet Scattering And Substrate Source Bundle

This bundle condenses the Mallat / wavelet scattering cluster for the wiki. The cluster is useful because it gives a principled alternative to fully learned early perception: fixed multiscale operators first, learned composition later.

Synthesis

The useful pattern is:

signal -> multiscale stable operators -> compact coefficients or events -> small learner

This is different from both old feature engineering and current large learned front-ends. The operators have mathematical commitments: scale, locality, frequency, orientation, invariance, stability. The learner then spends capacity on task-specific questions:

  • which scales matter now?
  • what residual remains unexplained?
  • what event changed?
  • what composition or rule predicts the next state?
  • what should be adapted online?

  • With concept-self-supervised-learning, it asks whether some invariances should be built rather than discovered.

  • With experiment-scale-aware-entity-persistence, it offers lower-level event fields that higher-level entity rules could modulate.

Open Questions

  1. Does a scattering front-end actually beat a tiny convolutional network under equal latency and memory?
  2. Does it help most when samples are scarce, data are noisy, or on-device updates are needed?
  3. Does scattering erase geometry or identity needed for object persistence?
  4. Can a higher-level rule feed back into the substrate by changing scale, orientation, sparsity, or residual routing?
  5. Is a lightly adaptive wavelet substrate better than a fully fixed scattering transform?
  6. Can random path or coefficient selection make the substrate cheap enough for edge deployment without turning it into an unprincipled heuristic?
