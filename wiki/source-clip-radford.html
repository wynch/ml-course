CLIP — Learning Transferable Visual Models From Natural Language Supervision

source created 2026-05-06 updated 2026-05-06 multimodal vision-language contrastive-learning representation-learning zero-shot openai foundation-models

Authors: Alec Radford, Jong Wook Kim, Chris Hallacy, Aditya Ramesh, Gabriel Goh, Sandhini Agarwal, Girish Sastry, Amanda Askell, Pamela Mishkin, Jack Clark, Gretchen Krueger, Ilya Sutskever (OpenAI) Date: 2021-02-26 (ICML 2021) arXiv: 2103.00020

Summary

The foundational paper for vision-language alignment. CLIP (Contrastive Language-Image Pretraining) trains a dual-encoder model — a vision encoder and a text encoder — to project images and their associated captions into a shared embedding space, where matched pairs are pulled together and mismatched pairs pushed apart. Trained on 400M (image, text) pairs scraped from the internet (the WIT dataset). The result: a model whose zero-shot ImageNet classification accuracy matches a fully supervised ResNet-50 without ever seeing ImageNet labels — establishing natural-language supervision as a scalable alternative to per-task supervised training.

Architecture

  • Image encoder: ViT or modified ResNet, producing a single embedding per image.
  • Text encoder: a Transformer (12-layer, 8-head, 512-dim) producing a single embedding per caption.
  • Both encoders project into a shared embedding space via learned linear heads; embeddings are L2-normalized.
  • No cross-attention, no fusion: the modalities only "talk" via the contrastive objective.

Contrastive Objective

  • For a batch of N (image, text) pairs, compute the N×N matrix of cosine similarities.
  • Symmetric InfoNCE loss: each image's correct caption is the positive, the other N-1 captions are negatives (and vice versa).
  • This is the InfoNCE loss applied across modalities — efficient, simple, scales with batch size.
  • The largest CLIP model used a batch size of 32,768 to give the contrastive objective enough negatives.

Training Data: WIT-400M

  • 400M (image, caption) pairs scraped from the public web.
  • Constructed by querying for ~500K query terms (Wikipedia article titles, common bigrams) and balancing per-query.
  • Captions are noisy alt-text and surrounding text — no human-labelled data.
  • This dataset and dataset-construction approach is itself a contribution: it showed weak text supervision at internet scale beats curated supervised vision data.

Zero-Shot Recipe

To classify an image among K classes:

  1. Embed each class name via a prompt template (e.g. "a photo of a {class}").
  2. Embed the image.
  3. Pick the class whose text embedding has highest cosine similarity to the image embedding.

This is inference without fine-tuning — and crucially, the class names themselves can be arbitrary natural language.

Key Results

  • Zero-shot ImageNet: ViT-L/14 reaches ~76% top-1 — matching a fully supervised ResNet-50 trained on 1.28M labelled images.
  • 30+ benchmarks: zero-shot CLIP is competitive with supervised baselines on OCR, action recognition, geo-localization, fine-grained classification.
  • Robustness: large gains on ImageNet-A/R/Sketch/V2 over supervised baselines — text supervision yields more robust features than label supervision on the same distribution.
  • Linear probe: CLIP features are SOTA on most transfer benchmarks under linear evaluation.

Significance

CLIP became the default vision encoder for the entire post-2021 multimodal-LLM stack. Most VLMs (source-flamingo, source-llava-visual-instruction, BLIP, MiniGPT-4, GPT-4V's reported architecture) plug a CLIP-style ViT into a frozen or jointly-trained LLM. Its embedding space — coarse-grained, semantically aligned to language — is exactly what an LLM's word-embedding layer can consume after a small projector.

It also reframed self-supervised vs supervised learning: weak text supervision at internet scale outperforms ImageNet supervision. The "CLIP-killer" milestone in pure-vision SSL came later with source-dino-lineage, which matched CLIP on most visual benchmarks without text supervision at all — a major datapoint for the LeCun thesis (source-lecun-path-autonomous-intelligence) that vision can be learned without language.

The next-generation challenge to CLIP's contrastive recipe is source-vl-jepa (Dec 2025), which beats CLIP / SigLIP2 / Perception Encoder on 16 video benchmarks by predicting embeddings rather than aligning them contrastively — bringing the JEPA programme into vision-language.
