RT-2 — Vision-Language-Action Models from Web Data

source created 2026-05-06 updated 2026-05-06 robotics vla vision-language-action google-deepmind world-models imitation-learning

Brohan et al. (Google DeepMind / Google Research) — arXiv 2307.15818, July 2023

The paper that fuses VLMs with robot control by treating robot actions as text tokens and co-fine-tuning a frontier vision-language model on internet vision-language data and robot trajectories simultaneously. RT-2 launches the modern VLA (Vision-Language-Action) paradigm and is the direct ancestor of OpenVLA and π0.

The "actions as tokens" move

Robot end-effector deltas (x, y, z, roll, pitch, yaw, gripper) are discretised into 256 bins each and mapped to existing tokens in the language model's vocabulary. A robot trajectory becomes a string of tokens like 1 128 91 241 5 101 127. The VLM is then trained to predict these tokens conditioned on (image, instruction) — making robot control formally identical to language modelling, with all the downstream benefits of the existing VLM training stack.

Co-fine-tuning recipe

Two backbones evaluated: PaLI-X (5B & 55B) and PaLM-E (12B). Each is co-fine-tuned on:

  • Internet vision-language data (VQA, captioning, web image-text pairs).
  • Robot trajectory data from the RT-1 fleet (~13 robots, ~17 months, kitchen tasks).

The two streams are mixed in the same training batches; the same model emits text answers for VQA and action tokens for robot tasks.

Headline result: emergent generalisation

A 6,000-trial real-robot evaluation shows RT-2 inherits semantic generalisation from the VLM:

  • Novel objects and scenes — significantly higher success on unseen objects than RT-1.
  • Out-of-distribution instructions — "put the strawberry into the correct bowl" requires selecting the bowl with strawberries already in it (a fact never present in robot data).
  • Symbolic/numeric reasoning — picking up the smallest object, the object near a number, etc.
  • Chain-of-thought robotics — given CoT prompts, RT-2 can plan multi-step instructions ("I'm thirsty, so I should pick…").

Significance

RT-2 is the moment robotics joined the foundation-model stack. It establishes three things subsequent VLAs build on: (1) actions as tokens; (2) co-fine-tuning preserves the VLM's web knowledge while adding control; (3) emergent generalisation transfers from internet to physical action. The contrast with V-JEPA 2 is sharp: RT-2 is a generative-token VLA trained on labelled (instruction, trajectory) pairs; V-JEPA 2 is a predictive latent world model that learns from passive video and plans via latent-space MPC. Both achieve cross-embodiment generalisation; they represent the two poles of the modern robot-foundation-model design space.

The unified-token framing also closes the loop with the earlier symbolic robot-LLM line: where Code-as-Policies has the LLM emit Python that calls perception/control APIs, RT-2 has the LLM emit the action stream itself end-to-end.
