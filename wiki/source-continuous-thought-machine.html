Continuous Thought Machines (Sakana AI)

source created 2026-07-19 updated 2026-09-25 architecture temporal-dynamics recurrence adaptive-compute representation-learning

Darlow et al., Sakana AI, 2025. arXiv:2505.05522. An architecture that makes time inside the model a first-class citizen, via three mechanisms:

  1. Internal ticks ("thought dimension"). The model runs its own recurrent clock decoupled from data time — a static input receives T internal processing steps. Certainty-based adaptive compute: simple inputs stop early, hard ones think longer. Loss is aggregated across internal ticks (minimum-loss and maximum-certainty ticks), so a meaningful progression of thought emerges.
  2. Neuron-level models. Each neuron has private weights processing a FIFO history of its own pre-activations — every neuron is a learned temporal filter. Oscillation and timing diversity emerge rather than being designed in.
  3. Synchronization as representation. The latent driving attention and outputs is not the activation vector but the co-fluctuation structure: inner products between neurons' activation time-series (with learnable decays), sampled over random pairs for tractability. What fires together over internal time is the representation.

Results: ImageNet classification with interpretable multi-step "looking around", 2D maze solving with attention tracing paths (generalizes to longer mazes), parity, RL tasks; adaptive compute emerges from the certainty mechanism.
