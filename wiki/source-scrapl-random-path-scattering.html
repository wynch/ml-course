SCRAPL — Scattering Transform With Random Paths For Machine Learning

source created 2026-05-14 updated 2026-05-14 wavelet-scattering kymatio audio differentiable-loss iclr-2026 efficient-computation

Mitcheltree, Lostanlen, Benetos, Lagrange — ICLR 2026 / arXiv 2602.11145

SCRAPL uses random scattering paths to make scattering-based losses cheaper during stochastic optimization. The target use case is differentiable signal processing and perceptual-quality assessment, especially audio.

Main Claim

Full multivariable scattering transforms can be expensive when used as differentiable losses because there are many paths through the scattering tree. SCRAPL samples paths stochastically, reducing cost while preserving useful gradients. The paper implements the method for joint time-frequency scattering and applies it to unsupervised sound matching.

Why It Matters

This is directly relevant to the wavelet-substrate experiment because it attacks one of the likely practical blockers:

a fixed mathematical substrate can still be too expensive if all coefficients are computed or used all the time.

Random-path sampling suggests a principled version of sparse substrate use:

  • sample only some scales/frequency paths during training
  • use importance sampling based on signal content
  • treat scattering paths as a budgeted resource
  • measure whether sparse path use preserves the signal needed by the learner

Experiment Implication

For experiment-wavelet-substrate-network, this supports a later "sparse path" benchmark:

full scattering -> random-path scattering -> top-k event scattering

Compare accuracy, robustness, latency, and memory. This is cleaner than hand-designing a sparse event extractor first.

Caveat

SCRAPL is framed around losses and differentiable signal processing, not low-power classification. It informs the computational strategy but does not prove the edge-substrate hypothesis.
