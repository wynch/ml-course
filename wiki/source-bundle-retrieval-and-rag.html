Retrieval and RAG Source Bundle

source-bundle created 2026-05-14 updated 2026-09-26 source-bundle retrieval rag embeddings long-context harness

This bundle condenses the retrieval / RAG cluster. The through-line is the movement from static sparse retrieval to learned dense retrieval, token-level late interaction, retrieval inside the LM, and agentic self-critique around whether retrieval is needed.

Condensed Synthesis

Retrieval is the wiki's clearest example of memory outside weights. DPR proves semantic embedding search works; ColBERT shows single-vector compression loses token evidence; RETRO asks whether retrieval should be a model layer rather than an application wrapper; Self-RAG adds runtime control; BGE-M3 represents the production-infrastructure turn.

The conceptual split:

  • Retrieve-then-prompt: cheap and deployable; dominant in products.
  • Late interaction: higher fidelity; index and latency cost.
  • Architectural retrieval: strongest scientific statement; harder engineering path.
  • Self-regulated retrieval: retrieval as an action selected by the model or harness.

2026 addendum

  • source-pixelrag — pixel-native RAG: a continued-pretrained VLM embedder retrieves web pages as screenshots (~30M-image Wikipedia datastore), beating text RAG by +18.1% with up to 3× token savings. The retrieval lineage's first serious "skip text extraction entirely" datapoint.
  • source-willison-jev-decision-models — a reranking use, not a retrieval method: BM25 fetches 100 candidates, then Jev, a model that returns a number per question, scores each for relevance to the query (raw/web-2026-simonwillison-jev-decision-models.md, opening). The post gives no quality figures.
