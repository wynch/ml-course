Transformer Architecture

concept created 2026-04-05 updated 2026-10-09 architecture transformers attention deep-learning

The dominant architecture for language models and increasingly for other modalities. Originally introduced in source-attention-is-all-you-need (Vaswani et al., 2017), transformers use self-attention to process sequences in parallel.

Core Components

  • Self-attention — allows each token to attend to all others
  • Feed-forward networks (FFNs) — per-token transformations
  • Residual stream — additive skip connections carrying information between layers
  • Positional encodings — inject sequence order information

Emerging Understanding

The wiki covers several papers that deepen our understanding of how transformers work internally:

  • Mix-Compress-Refine theory — source-attention-sinks-compression-valleys shows LLMs organize computation through early broad mixing, middle compression, and late selective refinement. Attention sinks and compression valleys trace to massive activations in the residual stream.
  • Depth as ensemble — source-neural-depth-scaling reveals Loss~1/depth, suggesting layers act as ensemble averages of updates rather than sequential composition.
  • FFNs as memory — source-memoryllm-plug-n-play-ffn reframes FFNs as context-free token-wise retrieval memory that can be pre-computed.
  • Residual stream rethinking — source-residual-matrix-transformer replaces the vector residual stream with an outer product memory matrix, achieving 58% fewer FLOPs for equivalent loss.
  • Computational power — source-subleq-transformer-computer constructively demonstrates Turing completeness by building a SUBLEQ computer as a transformer.
  • Depth scaling unlocked — source-keel-post-ln-highway (ByteDance Seed) replaces the Pre-LN residual path with a Post-LN + Highway gate, training stably at >1000 layers with monotonically improving perplexity.
  • Conditional memory as new sparsity axis — source-engram-deepseek augments the backbone with a deterministic O(1) N-gram lookup table; the MoE-vs-memory trade-off follows a U-shaped scaling law.
  • Hopfield ≡ attention — source-hopfield-is-all-you-need (Ramsauer 2020): the modern Hopfield update rule equals softmax attention. Reframes transformers as exponential-capacity associative-memory networks.

Long-context efficiency

  • source-flashattention — Dao 2022: IO-aware exact attention via tiling + recompute; O(N) memory, 2–4× speed.
  • source-flashattention — Dao 2023: ~2× over v1 via better work partitioning; near-optimal GPU utilisation.
  • source-functional-attention — Xiao et al. (ICML 2026): recasts attention as a functional correspondence between adaptive bases (functional maps); spectral projection drops O(n²)→O(k²) and yields resolution-invariant operators for PDE/point-cloud tasks.

Alternatives & Hybrids

Pure transformers face challenges with long sequences and efficiency. Several alternatives are emerging:

  • source-mamba-ssm — Gu/Dao 2023: selective state-space model; linear-time; matches transformers at 1B-3B
  • source-mamba-2-ssm-duality — Dao/Gu 2024: SSM/transformer duality via structured matrices. Architectural unification.
  • source-m2rnn-matrix-valued-states — Matrix-valued RNN states with non-linear transitions, outperforming Gated DeltaNet
  • source-olmo-hybrid-rnn-transformer — Allen AI's hybrid attention + linear RNN beats pure transformer at 7B scale
  • source-ttt-kv-binding-linear-attention — Shows TTT with KV binding is equivalent to linear attention
  • source-recursive-language-models — Recursive self-calling for 100x context extension
  • source-memory-mosaics-at-scale — Zhang & Bottou (FAIR, NYU): attention replaced by associative memories (kernel regression over stored key-value pairs, no position encoding), split into short-term, long-term and persistent memory. At about 10B parameters and 1T tokens it ties a llama-style transformer on 19 common benchmarks (52.2 each) and leads on multi-document questions at 32k (53.4 against 41.1) (raw/arxiv-2507-03285-memory-mosaics-at-scale.md, §3, §5.1, §5.2, Tables 1, 4). Unlike state-space models it keeps every key-value pair; the authors say it is "neither a linearization of attention nor attention efficiency" (same file, §3.2, footnote 6).

Why recurrence keeps coming back: source-topological-trouble-transformers (Mozer et al., DeepMind) argues the feedforward stack has a structural limit on dynamic state tracking — each input step pushes evolving state one layer deeper until depth is exhausted — and recommends refocusing on implicit recurrence (state-space models, coarse-grained recurrence) over externalized thought traces. source-next-latent-prediction (NextLat) supplies a recurrent inductive bias via a self-supervised next-latent objective without changing the architecture.

Architecture Choices for Training

source-frontier-model-training provides practical guidance: dense models with GQA (2-8 groups) as robust default, document masking + RNoPE/YaRN for long contexts, MoE requiring careful load balancing. See also source-retrofitting-models-minixhofer for the post-hoc-architecture-modification literature ("retrofitting" as the strict superset of fine-tuning).

Open Questions

  • Is depth actually providing compositional reasoning, or just ensemble averaging?
    • Evidence against the Transformer alone: trained with RL on short tasks, Qwen3-30B-A3B-Instruct-2507 raised its train reward but not its eval on 8–32× longer or cross-domain versions; the same model inside an RLM harness transferred (raw/web-2026-alexzhang-harness-compositional.md, §"RLMs can train on short tasks…"; §"RLMs can generalize to unseen tasks that share latent structure observed in training"). The authors blame the Transformer's "2017 token-level inductive biases" (same file, §Intro). See source-zhang-harness-blog.
    • Evidence for adding sequential steps rather than depth: a 2-layer transformer answers graph reachability of up to 16 hops at 48.3% (chance 50%) without thoughts and 99.9% with learned continuous thoughts (raw/arxiv-2609-19717-learn-your-own-thoughts-abstract-token-curriculum.md, §6.2.2, Table 1). See source-abstract-token-curriculum.
    • Evidence for depth when it is recurrent: a looped model beats its non-looped twin trained the same way for 180B tokens (ARC-C 29.18 vs 26.96; GSM8k CoT 9.02 vs 1.82), and its gains sit in the loop, since at r = 1 it stops improving with more training (raw/arxiv-2502-05171-recurrent-depth-latent-reasoning.md, §5.3, Table 4). See source-recurrent-depth-latent-reasoning.
    • Across four looped families (Ouro, Huginn, Parcae, Looped-Qwen3), the guess after the first loop trails the last by 4.0 to 23.7 points on a seven-benchmark mean; that weaker guess can then steer decoding (raw/arxiv-2610-02185-decoding-looped-transformers-better-for-almost.md, §5.1). See source-loopcd-decoding-looped-transformers.
    • Width is not depth: <pause> tokens give each layer more positions but no extra sequential steps, while each written chain-of-thought token adds a full pass of L layers (raw/arxiv-2310-02226-think-before-you-speak-pause-tokens.md, §6, Appendix I.2). Their gains need pause-pretraining (same file, §4.3). See source-pause-tokens.
  • Will hybrid architectures (attention + recurrence) dominate pure transformers? (source-topological-trouble-transformers argues feedforward attention structurally can't do sequential state tracking.)
    • A third answer, neither: source-memory-mosaics-at-scale keeps full memory but changes its form, and argues that a fixed-size state cannot hold documents read before the question (raw/arxiv-2507-03285-memory-mosaics-at-scale.md, §5.2, Appendix D).
  • Can the residual stream be fundamentally redesigned (matrix-valued, etc.)?
  • What are the practical limits of non-linear features in the additive residual stream? (See source-nonlinear-feature-representations)
