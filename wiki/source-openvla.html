OpenVLA — Open-Source 7B VLA That Beats RT-2-X

source created 2026-05-06 updated 2026-05-06 robotics vla vision-language-action open-source llama dinov2 siglip openx

Kim, Pertsch, Karamcheti, Xiao, Balakrishna, Nair, Rafailov, Foster, Lam, Sanketi, Vuong, Kollar, Burchfiel, Tedrake, Sadigh, Levine, Liang, Finn — arXiv 2406.09246, June 2024

OpenVLA is the open-weights answer to RT-2. Same VLA paradigm — actions as tokens, co-trained with a vision-language backbone — but every component is published: weights, training code, data, fine-tuning recipes. At 7B parameters it outperforms the 55B RT-2-X by 16.5 absolute points across 29 tasks and ships LoRA fine-tuning that runs on a single consumer GPU.

Architecture

A clean modern open-source stack:

  • Vision encoder — fused features from two pretrained ViTs concatenated channel-wise:
    • SigLIP (CLIP-style, language-aligned semantics).
    • DINOv2 (pure-vision SSL, strong dense / spatial features).
  • Projector — MLP from concatenated visual features into the LLM token space (LLaVA-style).
  • Language model — Llama 2 7B.
  • Action head — actions are 7-DoF end-effector deltas, discretised to 256 bins per dimension; bins map to the least-frequent tokens in Llama's tokeniser, overwriting them so existing language tokens are preserved.

Training

  • Dataset — 970k real-robot trajectories from the Open X-Embodiment (OXE) collection: 22 embodiments, dozens of labs, hundreds of tasks. The largest open robot training corpus at release.
  • Compute — 64 A100s for 14 days for the 7B model.
  • Loss — straight cross-entropy on action tokens. No co-fine-tuning with web VL data in the main run (a divergence from RT-2; instead OpenVLA inherits VL knowledge from Llama 2 + SigLIP/DINOv2 frozen pretraining).

Results

  • +16.5 points absolute task success vs RT-2-X (55B) across 29 tasks on the OXE eval suite, with 7× fewer parameters.
  • Strong few-shot adaptation to new robots and new task domains via LoRA fine-tuning on consumer hardware.
  • Code, weights, data, fine-tuning notebooks all released.

Significance

OpenVLA is the open-source community's catch-up moment for VLAs and the practical reference implementation behind which most subsequent work iterates. Three architectural lessons it codifies for the VLM/world-model stack:

  1. Dual vision encoders (CLIP-style + DINOv2) outperform single encoders on spatial control tasks — concrete evidence for the multimodal-encoder-choice tension.
  2. Token-overwriting is a clean way to add an action vocabulary without growing the embedding matrix, generalising RT-2's bin-mapping trick.
  3. No co-fine-tuning needed when the language and vision backbones are already strong; the VLA loss alone suffices. (Compare RT-2, which insisted on co-fine-tuning.)

The contrast with V-JEPA 2 persists: OpenVLA learns from labelled (instruction, trajectory) pairs and emits actions autoregressively; V-JEPA 2 learns from unlabelled video and plans via latent-space MPC. OpenVLA is the dominant generative-VLA baseline that V-JEPA 2 is measured against.
